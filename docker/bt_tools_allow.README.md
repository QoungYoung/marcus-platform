## ⚠️ 两个实测踩过的坑
1. **文件不能有注释** ✗ —— 桥用 `_raw.split(/\s+/)` **按空白切**，
   注释里的字会被当成"工具名"（实测：我加了中文注释 ⇒ 「只注册 **68** 个」✗）
   ⇒ 本文件**只能是一行一个裸工具名** ✓
2. **`/root/.dsh` 不在卷上** ✗（只有 `sessions` 子目录在 ✗）
   ⇒ 写进容器 ⇒ **容器一重建就消失** ✗（2026-10-07 重建桥时丢过一次 ✓）
   ⇒ 所以：文件放仓库 ✓ ＋ compose 只读挂载 ✓（`docker-compose.yml` 的 dsh 服务 ✓）
