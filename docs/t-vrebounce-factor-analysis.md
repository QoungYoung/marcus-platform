# V反 短线信号：失败单共性因子分析（stk_factor_pro）

> 结论先行：V反 状态的失败单（2023-2026 回测 1071 触发 / 464 亏损）共性不是估值、换手或量能，
> 而是 **反弹过猛、偏离均线过远（追高）**。加入 "触发日收盘偏离 MA20 ≤ 3%" 过滤后，
> 全样本 2009-2026 PF 1.38 → 2.14，样本外 2025+ PF 1.65-1.75，<100亿 分桶 PF 2.27-2.51。

## 背景

- 做T账户 t-account 尚无任何真实交易（paper_trades/orders/positions 均为 0），
  因此"失败的股票操作"以回测失败单为分析对象。
- 分析窗口：2023-01-01 ~ 2026-06-26，600 只采样（seed=7，is_st=0），
  V反 状态触发 1071 笔（次日开盘进场 / TP8 / SL5 / 超时12交易日）：607 胜 / 464 负。
- 因子数据：tushare `stk_factor_pro`（doc_id=328），逐股拉取 2023+ 全量因子，
  按触发日（T日收盘）取因子值，与触发单拼接（466 只 / 380,631 行）。

## 共性结论

失败单 = **反弹把价格推到离均线过远的"过热追高"**：
- 超买过度：rsi6 71.7 vs 63.3、cci 139 vs 76、boll_pos 0.83 vs 0.63、wr 11.6 vs 19.7、kdj_k 68.5 vs 62.8；
- 偏离均线过远：bias20 +8.5% vs +1.3%、bias60 +5.0% vs -7.7%、roc +8.8 vs -2.5、
  brar_br 103 vs 83、cr 97.6 vs 77.8（盈利单是"贴近均线的温和 V 反"）。
