# 狼大不是只有一种“选点模式”：G/H 为什么没按位置偏好

> G/H 的“失败”不是因为他不按偏好，而是因为我们把**两种不同的决策模式**混成了一种。
> 他的点位选择先取决于**这次动作是什么类型**，再决定用哪类位置。

## 1. G：2025-12-11，3876.47

他的原话：

> 「现在是放量的 如果跌破昨天低点超过 3 个 15 分钟没有收回去 一旦反抽我就要减仓了。三买失败」

- **3876.47 = 12/10 的前一日低点**（数据：12/10 low 3876.47）。
- 这不是“多结构合流”的结构位，而是**当前这笔“三买”交易的失效线**：
  - 三买成立的前提是前低不破；
  - 破了前低、且 3 个 15min 收不回，就是三买失败；
  - 失败后不是立刻砍，而是**等反抽减仓**。

所以他选的是 **“这笔交易最近的那条失效线”**，不是“更高的已破结构线”。
agent 选了 3936.31（12/08 反抽高/10/09 前高），是按“结构位”选，但 G 的动作类型是 **盘中确认/三买失败**，不是结构性破位。

## 2. H：2026-01-14，4141

他的原话：

> 「注意了 如果再次跌破 4141 继续放量 3 个 15 分钟确认跌破 那刚才 4161 的减仓位下调。早上没减的就要减」

- 4141 是**盘中触发位**，和 4161 是同一组“减仓下调”的阶梯；
- 它不一定是日线结构位，更可能是：
  - 当天/前一天的盘中低点或反抽位；
  - 4161 减仓之后的**第二道盘中确认线**。
- 我们的日线候选里根本没有 4141（只有 4130/4150 近似），因为**日线数据生成不出盘中 4141/4161**。
- agent 只能看到日线候选，于是选了 4034.08（1/6 突破箱体顶）——那是“结构起点”，不是“盘中第二道减仓线”。

H 的失败有两层：
1. **动作模式错**：把“盘中确认”当成“结构性破位”；
2. **数据粒度不够**：日线候选没有 4141/4161，只有 15min/分时才能生成。

## 3. 四种动作模式，四种选点偏好

| 动作模式 | 他的选点偏好 | 例子 | 确认方式 |
|---|---|---|---|
| **结构性破位** | 多结构合流 + 当前段起点/更高已破结构 | B/C 3922、D 3888 | 收盘、放量 |
| **盘中确认/三买失败** | 最近的前一日低点/盘中低点/上一道减仓位 | G 3876.47、H 4141/4161 | 3×15min、放量 |
| **反抽卖出** | 反抽高点 + MA20/34 簇 | A 3370/3375（6/20 高 3370.80 + MA20 3372.4） | 回拉到带内卖出 |
| **收盘阈值** | 他明确说的收盘位 | E 3856、F 3950 | 收盘不到/跌破 |

## 4. 这说明什么

1. **“位置偏好”不能全局套。**
   结构性破位偏“更高/更久的结构”，盘中确认偏“最近/最贴身的失效线”；两者方向相反。
2. **G 的 3876.47 不是“更低所以不重要”，而是“这笔三买的失效线”。**
   对三买来说，前低就是最重要的位，不需要第二个结构。
3. **H 的 4141 是盘中位，日线候选天然缺。**
   不是 agent 不想选，是它看不到；要选 4141 必须给 15min/分时数据，或者给“4161 减仓后下一道 4141”的上下文。
4. **先分动作模式，再谈选点。**
   不先问“这次是结构性破位、盘中确认、反抽卖出、还是收盘阈值”，任何统一的位置偏好都会在另一批 case 上失效。

## 5. 对 agent 的修正

prompt 第一问不应该是“哪个位最强”，而应该是：

```
这次动作是什么类型？
  A. 结构性破位 → 找多结构合流/当前段起点
  B. 盘中确认/三买失败 → 找前一日低点/盘中低点/上一道减仓位，等 3×15min
  C. 反抽卖出 → 找反抽高点+MA20/34
  D. 收盘阈值 → 找他明确说的收盘位
```

先定模式，再选点；模式没定，选点必错。
