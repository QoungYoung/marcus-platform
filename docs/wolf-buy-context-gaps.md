## 六大类遗漏

1. **工具性/仓位型买入**：E15 的“为了T空间买回”，E01 的“50%仓位才敢买”——需要三仓档位模型，不是信号问题。
2. **日历与事件节奏**：业绩披露日历（E11）、年初业绩预期差（E07）、H1设备/H2材料（E11）、老黄演讲/涨价事件（E12/E13）——news/公告源 403 + 无产业事件日历。
3. **指数/流动性环境门槛**：GJD缺口护盘（E01）、量能2.3万亿+券商退潮+银行地产白酒必须跌（E05）、微盘止跌/黄线吸血（E12）——目前只在少数 T 腿里有黄线护栏。
4. **机构行为/政策底传导**：机构带黄线切换（E04）、政策底→市场底→机构调仓一致（E14）、杀杠杆阶段（E14）——现有 systemic_risk 和季度基金持仓太粗。
5. **分步/条件化买入**：站稳趋势线再加（E05）、上午收新低再观察（E10）、“一步一步”的分批（E10/E13）——系统是触发一次买完。
6. **个股/细分龙头定位**：液冷缺龙头我来打造（E06）、国算交换机穿越（E14）、设备硬票新高→材料（E11）——position_class 是概念级聚合，个股龙头/景气度排序缺失。
