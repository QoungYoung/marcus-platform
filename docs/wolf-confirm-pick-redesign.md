   R3 资金：个股主力净流(moneyflow_dc 字段级待验证) + 龙虎榜机构/游资净买近20日(top_inst/

   R4 位置量价：position(LOW/MID 加分、HIGH 减分) + 缩量止跌/企稳形态(日线)

   · position ∈ {LOW, MID} 且 回调到位（价在 20日高低区间中下沿/接近前低）

L5 布腿输出：票池 ∩ L4 按综合分取前 2 → 253/254 腿（TMonitor 执行链路不变）

### 缺口汇总
- **G1 主营构成/行业正宗度**（真缺口）：概念 map 太脏是根因。v1 代理 = 确认链成分 ∩ 核心概念 + 多子概念交叉；
  中期可试 Tushare 中继 `fina_mainbz`/申万行业接口做主营占比门（未验证，列为待测）。
- **G2 老龙头/辨识度标签**（非数据缺口，缺构建）：新脚本按主题产出每日 leader 榜
  （区间涨幅/成交额/涨停/领涨期），供 R2 与 L0 风向标使用。
- **G3 基本面风险事件库**（缺口）：立案/业绩暴雷需公告解析或第三方；v1 用 ST+黑名单，
  缺名单外的突发暴雷识别（提示：TMonitor 有 ④support 破位门兜底）。
- **G4 moneyflow 字段级**（待复验）：若仅 buy_elg_amount 可用，主力净流退化为单边大单买入额。
- **北向个股不可用**（已知）：主线资金维度用 ETF 份额/龙虎榜替代（已有）。
