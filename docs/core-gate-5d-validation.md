# core 动作闸：全 PIT 滚动 5 日验收

> 2026-10-22；87 个 PIT 周度日期，2,221 个 picks。  
> 只看 5 日，不看 10/20 日。

## 合规

```text
dead + second     = 0
warning + second  = 0
```

通过。

## 5 日结果

| 组 | n | 5日均值 | 胜率 |
|---|---:|---:|---:|
| allowed | 1201 | **+0.519%** | 49.3% |
| blocked | 1017 | **+0.354%** | 49.9% |

方向对：

```text
blocked 5日 < allowed
```

但只差 **0.165pp**，且 blocked 仍是正收益，不是“挡掉坏票”。

## 组合层

| 组 | 5日均值 | 95% CI |
|---|---:|---:|
| A rule | +0.435% | [-0.344, +1.201] |
| B gate（现金） | +0.278% | [-0.169, +0.749] |

B-A 仍为负，gate 没有提升组合收益。

## 分状态

| 状态 | allow | block |
|---|---:|---:|
| alive | 642 / +0.86% | 0 |
| warning | 261 / +0.54% | 813 / +0.21% |
| stale | 56 / +0.15% | 200 / **+0.90%** |
| rotated | 242 / -0.32% | 0 |
| dead | 0 | 4 / +2.66% |

关键问题：

- `stale` 被挡的票 5 日反而 +0.90%，**挡错**；
- `dead` 只有 4 个，且 +2.66%，**样本不可用**；
- `warning` 的 blocked 更低，方向对，但差距小；
- `alive` 最好，但 rotated 为负。

## 结论

```text
合规        ✅
warning挡   ⚠️ 方向对，幅度小
stale挡     ❌ 挡错
dead挡      ❌ 样本不足
组合收益    ❌ gate 更低
```

动作闸还不能算通过。  
当前最明确的问题不是“挡得不够”，而是 **stale/dead 的挡法不对**。

## 下一步

1. `stale` 不应该按 warning 处理，先放开或单独定义；
2. `dead` 需要更多样本，不能拿 4 个下结论；
3. 只保留 `warning + second` 这一条硬规则；
4. 重新跑 5 日滚动。

一句话：**全 PIT 5 日回放合规通过，但 blocked 仍为正、stale 明显挡错、dead 样本不足；动作闸还没通过。**
