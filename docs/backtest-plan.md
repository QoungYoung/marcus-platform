## 3. 时序与前视纪律（不可妥协）

1. **gate 时序**：gate 在 **收盘后 18:45** 产出（用当日收盘数据）→ **次日 09:20 布腿**。
   回测必须按此建模：**用 D 日收盘产出的 gate 布 D+1 日的腿**。
   （`docs/PRODUCTION_PIPELINE.md` §12.2 已记录此前回放用了"gate 当日布腿"，需重跑。）
2. **无前视**：所有选股/位置/结构判据只能用到布腿日**之前**的数据。
   本批次新引入的判据尤其要检查：
   - P0-2 的 `rs` = 个股 r20 − 主题 r20，两者均取**布腿日前一日收盘**；
   - P1-1 的 `wind_broken` = 风向标**收盘** vs 前一交易日最低 → 是 D 日收盘信号，用于 D+1 布腿；
   - P1-3 的主题浪 `track_a.stage` 取**该 gate 日期**的 trend_confirm 产物；
   - P1-6 的反弹幅度窗口不得包含未来 bar。
3. **同池同日基线**：任何"提升胜率"的结论都必须与**同池同日随机买入**对照
   （既有基线：n=23,512，胜率 49%，均值 +0.61%）。否则会把 beta 当成 alpha。
4. **成交假设显式声明**：现有回测按"一腿一次、每笔满额可成交"，**未建模**资金闸分批、涨跌停不可成交、滑点 → 结论需注明该乐观性。
