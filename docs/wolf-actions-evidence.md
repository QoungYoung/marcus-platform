## 四、从他的动作反推四个问题

| 问题 | 他的做法 | 对应选项 |
|---|---|---|
| **在 defense / 主线未激活时能不能开仓** | 能。11-04 就是在熊市 + 主线 weak 下从 5% 推到 30% | **Q1 = A（允许试探仓）** |
| **给多少** | 先 5%，条件成立再加到 30%；熊市总仓上限 1/4；单方向 25–30% | **Q1 上限：单方向 ≤30% 的熊市额度内，试探仓 5% 起** |
| **谁拍板** | 他自己，盘中即时 | 模拟盘可自主；实盘建议人工一键确认（Q2 = A） |
| **改到哪一层** | 他的判断依赖结构+筹码+子链，但执行只用现成的仓位公式 | **Q3 = A（只改决策层，不动 calc_position）** |
| **怎么算对** | 他事后认错的标准是"结构有没有坏"（数三失败→筑双脚），不是当天盈亏 | **Q4 = A（过程评分 + 踏空记账）** |

## 五、一句话

**他不是"敢赌"，他是"先算好错了亏多少，再动手"。**
所以要让 agent 像他，不是把提示词改成"勇敢一点"，而是给它三样他现在没有的东西：
**① 一个明确的试探仓额度（5% 起）；② 一张必须写 trigger/deadline/size/invalid 的决策卡；③ 一个会把"没动手"也记账的记分板。**
