# 题材选股、入场、离场手册

> 依据：狼大公开发言。  
> 原则：每个要点尽量带原话；没有出处的数值阈值不写成硬规则。  
> 适用范围：题材 sleeve，不直接套用于主线性趋势仓。

---

## 0. 使用原则

1. 先判**阶段**，再判**角色**，最后才看个股。
2. 不把单一指标当结论：涨停数、breadth、open_times、bellwether 都只是证据。
3. 没有狼大出处的阈值，只能作展示/排序，不能一票否决。
4. 龙头不等于当日涨停；风向标不等于买入标的。
5. 外溢是跨题材事件，不是“相关板块”四个字。

---

## 1. 体系分层

```text
主线 mainline
  └─ 赛道 track
       └─ 题材 theme
            ├─ 龙头 leader
            ├─ 风向标 wind
            ├─ 中流砥柱 mid
            └─ 后排 / 杂毛
```

题材仓与主线仓分开：

- 题材仓看情绪、角色、首联、外溢。
- 主线仓看趋势、赛道、权重。
- 题材仓不能被主线的 wave/P3 闸门一刀切。

## 2. 题材阶段

### 2.1 首联

狼大：

> 独立资金第一次尝试做机器人板块联动。

> 第一波不挣钱，第二波才是拿来挣钱。

特征：

- 之前没有联动过；
- 当天第一次出现板块级同步；
- 龙头先动，风向/中军跟上；
- 市场还没形成一致预期。

### 2.2 第二天/确认

首联后第二天，看：

- 大哥是否继续；
- 二哥是否掉队；
- 中流砥柱是否承接；
- 是否有新的后排补涨。

狼大：

> 机器人大哥先涨，其他哪怕不涨他也不会跌。

### 2.3 高潮

特征：

- 涨停家数多；
- 后排都拉上去；
- 炸板增加；
- 无晋级/二板少；
- 龙头加速；
- 成交额异常放大。

狼大 10/28：

> 今天都高潮成这样了。。。。。。甚至后排都拉上去了。

### 2.4 高位/低位

高位和低位不是一套规则：

- 低位：看逻辑、套牢、企稳、首次放量。
- 高位：看龙头、量价、炸板、接力。

不能用同一套 breadth/涨停阈值打所有阶段。

## 3. 角色：1 龙头 + 2 风向 + 3 中流砥柱

狼大：

> 一个龙头，两个风向，三个 10CM 中流砥柱。

### 3.1 龙头

- 题材辨识度最高；
- 最先转强/最先涨停；
- 能带动板块；
- 不一定是当日涨幅第一，但通常是资金第一选择。

### 3.2 风向标

- 20CM/高弹性核心；
- 用来判断题材温度和资金风险偏好；
- **不一定要买**。

狼大 10/23 机器人：

```text
宇树 +20%，但已在高位
→ 风向标只当温度计
→ 不追高
```

### 3.3 中流砥柱

- 10CM 中位；
- 有量、能承接；
- 龙头回落时不大幅掉队；
- 是题材持续性的骨架。

### 3.4 后排/杂毛

- 龙头、风向、中军都救不起来时，后排更不能去。

狼大：

> 后排反倒不能去，要看好龙头那些；龙头和核心都救不起来，那其他后排还要死。

---

## 4. 选股要点

### 4.1 先定角色，不先看涨幅

错误做法：

```text
今日涨幅第一 → 龙头
```

正确做法：

```text
龙头/风向/中流砥柱/后排
→ 再看谁最强
```

### 4.2 套牢要少

狼大：

> 业绩不业绩无所谓，重点是套牢要少。

看：

- `winner_rate`：获利盘是否过高；
- `price_vs_cost85`：现价相对 85% 成本；
- 上方套牢区；
- 近期是否放量派发。

套牢重 → 只做短，不做趋势；套牢轻 → 可给更高预期。

### 4.3 大哥先涨，二哥不掉

狼大：

> 机器人大哥先涨，其他哪怕不涨他也不会跌。

检查：

- 龙头涨时，风向是否跟；
- 龙头回落时，二哥是否抗跌；
- 中军是否守住；
- 不是“龙头涨、其他全跌”的假联动。

### 4.4 首联/第一天

狼大：

> 第一天 总不至于怕。

首联日：

- 可以 probe；
- 不要求当天全部确认；
- 第二天看大哥/二哥是否延续；
- 失败就撤，不把首联当趋势。

### 4.5 先涨/后涨的人气标

狼大：

> 先涨的都不是之前的人气标，后涨的一定是之前一批人气标。

含义：

- 第一波：新面孔先涨；
- 第二波：老龙头/人气标接力；
- 不要在第一波把老龙头当必然龙头；
- 也不要在第二波忽略老龙头。

### 4.6 高位/低位分开

低位看：

```text
逻辑
套牢
企稳
首次放量
```

高位看：

```text
龙头是否加速
炸板
后排是否补涨
是否无晋级
```

## 5. 入场

### 5.1 A：首联 probe

条件：

- 题材首次联动；
- 龙头先动；
- 风向/中军至少一部分跟上；
- 套牢不重；
- 目标不是高位一致。

动作：

```text
小仓 probe
第二天确认再加
不确认就撤
```

### 5.2 B：低位首次放量

条件：

- 低位/横盘；
- 首次放量；
- 不破前低；
- 套牢可接受；
- 有可验证的题材逻辑/跨题材关联。

动作：

```text
probe
确认后加
```

### 5.3 C：高位加速

狼大：

> 高潮/炸板切外溢。

高位加速不是买点，是：

```text
减仓
T
切外溢
```

不是追龙头。

### 5.4 D：确认加仓

条件：

- 龙头不死；
- 二哥不掉；
- 中军承接；
- 量价同步；
- 13:30 进量。

### 5.5 时间

- 首联日尾盘/次日开盘附近；
- 13:30 看资金是否继续进量；
- 不确认不追。

## 6. 离场

### 6.1 龙头/风向标死

狼大：

> 龙头风向标死了就不能做了，麻溜跑。

死：

- 龙头跌停/破位；
- 风向标跌停/跌破关键低点；
- 板块联动断裂；
- 不是“跌一天”就叫死。

### 6.2 高潮/炸板

狼大：

> 高潮/炸板切外溢。

高潮：

- 后排全拉；
- 炸板增加；
- 无晋级；
- 龙头加速。

动作：

```text
不追
减
T
切外溢
```

### 6.3 T

狼大：

> 我早都 T 完了。

> 没有量，如果能 T 是真的要 T 出去的。

T 是题材仓的常规动作：

- 冲高无量 → T；
- 高潮 → T；
- 不是清仓，是降低成本/锁定利润。

### 6.4 结构破位

- 龙头跌破平台；
- 题材 breadth 快速收缩；
- 中军集体掉队；
- 不再有首联/二波。

### 6.5 不要高切低

狼大：

> 千万不要想高切低，麻溜的跑就行。

龙头/风向标死时：

```text
不补后排
不切低位杂毛
先跑
```

## 7. 外溢：跨题材转移

### 7.1 定义

```text
源题材高潮
→ 资金找不到低位
→ 目标题材第一天联动
```

不是“两个板块相关”。

### 7.2 条件

- 源题材高潮/后排补涨/炸板；
- 源题材没有低位；
- 目标题材低位/首日联动/龙头先动；
- 目标与源题材之间存在可验证的产业/资金/成员关联；
- 第一天。

### 7.3 外溢观察点

首日外溢只看：

- 源题材是否高潮、后排是否补涨；
- 目标题材是否低位、首次联动；
- 目标龙头是否先动；
- 是否存在可验证的跨题材关联；
- 是否第一天；
- 指数/源题材是否拖累。

不引用任何后续结果。

### 7.4 外溢不是轮动

| 类型 | 源题材 | 目标 |
|---|---|---|
| 外溢 | 高潮但没死 | 首日联动 |
| 轮动 | 源死 | 目标接棒 |
| 补涨 | 同一题材 | 后排/低位 |

### 7.5 外溢失败条件

- 指数弱；
- 目标被源题材拖累；
- 目标没有独立资金；
- 只剩尾气。

---

## 8. 反例/不要做

1. 只按当日涨幅选龙头。
2. 只按涨停数判题材好坏。
3. 把风向标当买入标的。
4. 高潮后追龙头。
5. 龙头死了去补后排/高切低。
6. 只有相关、没有资金，就判外溢。
7. 用没有出处的固定阈值一票否决。
8. 把 bellwether `alive` 当成整个题材健康。

## 10. 系统映射

### 10.1 已用字段

```text
first_linkage
ret1/ret5/ret20
breadth
amount_ratio
b4 (u/z/d/open_times/ladder)
overhang (winner_rate/price_vs_cost85)
roles (leader/wind/mid)
internal_linkage (leader_pct/wind_up/mid_hold/sync)
bellwether (subtheme/code/state/successor)
agent_state (state/action/new_buy/size_multiplier)
```

### 10.2 判断顺序

```text
1. 题材阶段
2. 角色
3. 套牢
4. 量价/13:30
5. 外溢
6. agent 决策
7. select 执行
```

### 10.3 不做什么

- 不在 select 里写 breadth 硬门；
- 不用 B4 open_max 直接否决题材；
- 不让 bellwether 覆盖 agent leader；
- 不把 `new_buy=false` 当成永久禁止。

## 12. 出处与边界

### 直接原话

- 1 龙头 + 2 风向 + 3 中流砥柱
- 业绩不业绩无所谓，重点是套牢要少
- 大哥先涨，二哥不掉
- 龙头风向标死了就不能做了，麻溜跑
- 高潮/炸板切外溢
- 第一波不挣钱，第二波才是拿来挣钱
- 先涨的都不是之前的人气标，后涨的一定是之前一批人气标
- 我早都 T 完了
- 没有量，如果能 T 是真的要 T 出去的
- 第一天 总不至于怕
- 跨题材票在下跌行情里容易被原题材拖累（泛化表述，不指向具体板块）
- 后排反倒不能去，要看好龙头那些
- 千万不要想高切低，麻溜的跑

### 非原话/派生

- breadth、open_max、winner_rate 的具体数值门槛；
- 9:50/13:30 的精确执行时间；
- `size_multiplier` 的具体数值。

这些只能作为**系统参数/证据**，不能写成狼大原话。

---

## 13. 一句话总结

> 先看题材阶段，再分龙头/风向/中军；首联可试，高潮不追；套牢要少，二哥不掉；龙头风向标死就跑，高潮炸板切外溢；外溢只看第一天和可验证的跨题材关联；所有判断用证据，不用单因子。
