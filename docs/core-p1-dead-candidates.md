# 风向标 dead 正例搜索

> 2026-10-21；来源：狼大回复汇总 xlsx 全表 + 已整理语料。

## 结论

**没有找到“狼大明确说某日某风向标已经死了”的确认正例。**

能找的是：

| 类型 | 案例 | 能否当 dead |
|---|---|---|
| 明确说没死 | 2021-06-21「还在顶，暂时死不掉」；2022-09-27「第一风向标没那么容易死」；2026-01-12「风向标没有死」 | 否，是 alive |
| 单日跌停 | 2021-02-08 朗姿「被摁跌停」 | 否，缩量跌停，次日平盘、第三日涨停 |
| 走弱/问题 | 2021-07-16「两边的风向标都是问题了」；2022-05-18「所有风向标缩量出货」 | 否，是 warning |
| 用户说倒 | 2021-08-10「芯片风向标都倒了」 | 狼大只答「大幅度套利」，未确认 |
| 龙头倒了但洗盘 | 2025-02-27「龙头倒了……恐慌盘会出大一点」 | 否，他说是在洗盘 |
| 条件式退出 | 2026-05-08「半导体顶分型……如果破位我就撤大部分」 | **dead_candidate**，未确认 |
| 未来预测 | 2022-06-06「疫情龙头……都要死绝了」 | **dead_forecast**，不是当日事件 |
| 没有风向标 | 2021-06-18「华为新材料没有风向标，但是能做」 | unknown，不是 dead |

## 唯一可用的正例候选

**2026-05-08 半导体**：

> 「半导体已经有顶分型的迹象，如果破位我就撤大部分了……上面那些高位PCB、半导体都是只有被动止盈位了。」

这是**条件式退出**，不是“已经死了”。  
要当 dead 正例，必须补：

1. 当日/次日是否真的破位；
2. 是哪个风向标；
3. 是否有新龙头接力；
4. 他后续是否真撤。

## 负例更重要

以下都必须让状态机输出 **非 dead**：

- 2021-02-08 朗姿跌停；
- 2021-06-21「死不掉」；
- 2021-07-16「有问题」；
- 2022-05-18「缩量出货」；
- 2025-02-27「龙头倒了但洗盘」；
- 2026-01-12「风向标没有死」。

## 下一步

1. 把 2026-05-08 半导体做成 **dead_candidate 事件**，用日线确认是否破位；
2. 不再从“嘴上的死”硬找；改为“操作上的死”（撤大部分/切低/停止补涨）；
3. 如果没有确认正例，dead 不能做监督学习，只能做保守规则；
4. 继续用负例约束，避免把跌停/问题/洗盘误判为 dead。
