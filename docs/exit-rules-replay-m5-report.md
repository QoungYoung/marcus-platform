## 2 结论（可验收的四条）

1. **「破分时黄线」作为独立离场条件没有 alpha —— n=428 上确认。**
   四种破线口径（单根 / 2 根 / 只做 T 窗口 / 加确认）**全部 ≈0 或为负**（均值 −0.04 ~ 0.00），
   胜率 41–42% 低于持 T+5 的 47.4%；且 **428/428 条腿都会破线**（与生产 n=33 的 33/33 一致）。
   → 2026-09-14 之前那个"72.7% 胜率"是**日线代理假象**，现在有 n=428 的真 m5 证据推翻。
2. **A1 的"加确认"不是关键**：V2d（≥0.5% 或连续 2 根）−0.02% vs V2a（一破就走）−0.03%
   —— 差别在噪声内（块状 t 0.79 vs 0.61）。**阈值扫描（`jobs/eval_roundtrip_confirm.py`）也显示
   阈值极度敏感且方向是"破线出场越少越好"**，故不调参（A3 保持"口径已定、阈值未定"）。
3. **唯一稳定有效的仍是「+3% 止盈」**：胜率 +5.2pp（47.4%→52.6%）、中位 +0.98pp（−0.58→+0.40），
   但**均值 −0.14pp**（+0.29→+0.15）—— 这是一个**分布变换**：削掉右尾换更高的胜率与中位。
   若目标是"高胜率、少坐过山车"（他的做 T 兑现语义），V1 是对的；若目标是期望收益最大，V1 不如持有。
4. **A1 的生产现口径（V3d）在大样本上不比旧口径差**：V3d +0.34 / 块状 t 2.29
   ≥ V3c（旧"破线优先"）+0.30 / 2.05，**H1/H2 同号**（+0.50 / +0.17，n=33 时是变号的）。
   → **保留 A1，不回退**（`WOLF_RT_PRIORITY=target_first` 继续生效）。

## 3 必须写明的限制（不要过度解读）

- **参考腿 ≠ 生产腿**：replay 腿是 `bt_pit` 历史触发（254/253 形态），不是用户实际成交；
  它解决的是"样本量与跨期"问题，不解决"这批腿和今天下的单有多像"。
- 参考腿日线来自 `bt_pit/daily/*.json`（只有 date/close/low/amount）→ 日线本身是**降级**的
  （`ReplayBars` 用 close 顶 open/high）；m5 是真数据，但 V1 的 +3% 判定用**日线收盘**，
  盘中最高价触及 +3% 的情形不在 V1 内（会低估 V1 的触发率）。
- 组合变体（V3*）的"高均值"来自**破线在冲高后离场**（离场价常高于 T+5 收盘），
  **不是"破线择时准"**；把 V2*（破线单独）为负与 V3*（组合）为正放在一起看才完整。
- 农业 155 / 电力 91 / 资源 82 三个方向占 328/428 → 主题集中度高，跨方向外推要谨慎。
