- **相符**：有逐字/近逐字原话，方向与动作一致；
- **外推**：有原话依据，但阈值、映射、分层是我们加的；
- **自设**：没有原话，属平台/工程规则；
- **冲突/偏差**：与他的做法语义不同，或比他更松/更严。

### 13.3 可能冲突 / 语义偏差（最需要留意）

| 项 | 偏差 |
|---|---|
| **G0 75% 上限 vs 75%以上+满仓滚动** | 我们封顶 75；他允许主升 75% 以上、盘中满仓。主升期可能被压得过低 |
| **G3 15% vs 0 或 20-30%** | 15 是折中；他没说过 15 |
| **G2 硬拦 T 回补** | P3 允许 `t_refill≤5%`，但 `p2_entry_gate` 在 G2 硬拦所有买 → 实际 T 也做不了；他在 50% 调整期是允许做 T 的 |
| **防御残余等比减** | 他会“卖弱/卖高β/留核心”；等比减会把核心底仓一起削，和“底仓不动/卖强留弱”有偏差 |
| **G2 残余可能减底仓** | 他的“底仓不动”是常态；G2 等比减可能动到底仓，G3 才更合理 |
| **周末 50% 回退** | 他的 65% 是条件式；50% 是平台旧值，二者同时存在时以 65 为先是我们的选择 |
| **账户回撤 5% 硬禁止** | 语料无此规则；他在调整期反而说“跌多了买一点”，固定 5% 熔断可能过严 |

| **t_derisk 40%** | 与 G3 15/0 冲突；且未接线 |
| **risk_manager 0.2 地板“永不清仓”** | 与“下跌趋势就不做”冲突；已退役，仅模型重训 |
| **板上减半/小赚兑现与防御残余并行** | 同一票可能被止盈腿和防御腿各卖一次；目前靠 `_wolf_done` 部分去重，仍需观察 |

### 13.4 一句话

**方向、档位（75/50/30）、破位、两融、公募拥挤、时间门、周末65%、去弱留强、3-5点T：与狼大相符。**
