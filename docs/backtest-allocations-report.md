# 资产配置回测报告（AI 推荐 vs 当前持仓 vs 稳定腿最优）

## 方法与数据

- 数据：本地 `data/etf_1min` 分钟线聚合日线，复权收盘 = close × adj_factor（**含分红再投资**）
- 区间：**2024-01-01 ~ 2026-07-24**（618 个交易日，约 2.5 年）
- 资产近似：银行个股→银行ETF(512800)；高股息个股→红利ETF(510880)/红利低波100(515100)；科技个股→科技ETF(515000)；其余用对应 ETF
- 两种口径：固定权重（每日再平衡）为主 + 买入持有（不调仓）为辅
- 现金按年化 1.5% 计息；未计再平衡成本/税费
- 用户当前持仓：科技 10万 / 中证红利 5.7万 / 十年国债 8万 / 纳指 4万（总 27.7 万）

## 结论

1. **纯收益最高是 AI 推荐配置**（年化 29.4%），但代价是波动 20.7%、回撤 -12.6%——它的超额主要来自 50% 成长腿（2024-2026 科技/半导体大年），不是「稳定」的功劳。
2. **稳定收益最高（用户诉求）= 固定成长 + 稳定腿改为「银行 + 黄金 + 国债 + 红利」**：
   - 夏普最优（含纳指 1.69）、回撤最小（无纳指 -7.7%）、卡玛最高（3.43）
   - 当前持仓的问题：**国债 29% 太重**（低息低弹性拖累收益）、缺黄金/银行、稳定腿内部没有做风险分散
3. **等权稳定腿（无纳指）年化 24.4%/回撤 -8.8% 是不过拟合的稳健替代**，比当前持仓夏普高（1.44 vs 1.36）、回撤小 2.3pp。
4. **过拟合警示**：优化器把权重集中到银行/黄金，是因为 2024-2026 银行高股息 + 黄金大牛市；这是**样本内最优**，直接照抄极端权重有风险。建议采用「银行+黄金各 15-20%、红利低波 10-15%、国债 10-15%、现金 5%」的稳健折中，而不是 24%/20% 的极端值。
5. 未计调仓成本与税费；2.5 年单一行情段，结论不宜外推。

期望管理：26.5% 是 2024-2026 银行/黄金/科技共振的样本内数字；按各类资产长期假设（科技 10-15%、银行红利含息 8-10%、黄金 5-8%、红利低波 8-10%、国债 3%、纳指 8-12%、现金 1.5%）加权，理性中性预期约 10-15%/年，保守 9-11%。回测数字不能线性外推。

### 关键发现（样本外验证）

1. **2024 年前这套配置不赚钱**：2020-2023 年化仅 1.7-6.2%，2022 熊市回撤 -13% ~ -27%。2024-2026 的 26.5% 是银行/黄金/科技共振的行情贝塔，**不是配置的长期能力**。
2. **「银行+黄金」最优是 2024-2026 的产物**：在 2020-2023 样本外重新优化稳定腿，银行权重只剩 0.6-3.7%，最优变成 纳指 ~24% + 黄金 ~20% + 红利低波/中证红利 ~20%（2022 纳指虽大跌但 2020-2021 涨幅大）。**稳定腿最优配置随时间漂移，照抄样本内最优有风险。**
3. **穿越牛熊的真实水平**：2020-2026 全周期，折中版年化 12.1%、最大回撤 -18.7%——这才是这类「成长+红利+国债+黄金」配置的长期中枢。
4. 三配置全周期排序：折中版 ≈ 当前持仓（12.1% vs 12.2%）> AI推荐（11.5%），且 AI 推荐回撤 -29.9% 显著更深。
