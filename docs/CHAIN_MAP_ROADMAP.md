# chain_map 15 主题环节词典扩展清单（roadmap）

> 状态: 立项 2026-09-08 | 方法: 环节词典 AI+人工共建 → mv+主营核实龙头 → 每日 chain_map 产物 → fusion 门
> 触发证据: 农业主题 7 概念并集成分 294 只按市值 top6 = 牧原/伊利/泸州老窖/温氏/徐工/中联
>           ——白酒(泸州老窖 -9%)与工程机械(徐工/中联)混入, 主题指数被杂质稀释,
>           按概念市值买龙头会买错票; 主题级结构/龙头判定前必须先主营核实剔异业。

## 1. 目标（完成定义）

- [ ] SEED 环节词典覆盖 THEME_CONCEPTS 全部 15 主题（现 3/15：AI/算力·科技、传媒/游戏、消费/内需）
- [ ] 每主题环节拆分可解释（role/label/concepts/kw 与 Wolf 产业链叙事一致）
- [ ] 每主题跑通 chain_map 流程：双轨池 → fina 主营核实 → mv top3 leading → AI 裁决边界股 → kw 自举
- [ ] 杂质剔除验证：每主题市值 top10 抽查无 >1 只异业票（农业案例: 泸州老窖/徐工/中联必须被剔除）
- [ ] 每日产物 chain_map_{date}.json 覆盖 15 主题，主题完整度分可被 fusion 门消费

## 2. 每主题扩展四步（复用 apps/main_line/chain_map.py 已有机制）

1. **起草环节词典**：主题 → 3 环节左右（上游/中游/下游或按产业事实）; concepts 从 THEME_CONCEPTS 主题概念集拆分; kw 从概念名+主营常识起草（初稿粗糙可接受）
2. **AI/人工审**：跑 chain_map 后看 leading/rejected/needs_verify/ai_verdicts，边界票交 AI 裁决（conf>=0.85 回补），kw 建议累积 chain_kw_suggestions.json
3. **杂质审计**：主题成分按市值 top10 列名，人工核对异业票是否被 fina 剔除（未剔除→补 kw / 概念归属争议记录）
4. **每周校准**：chain_kw_suggestions 固化回 SEED; 稳定后转"盘后自动跑"
