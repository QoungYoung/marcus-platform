# G/H 全新留出验证：位置偏好没有泛化

> G/H 没有参与“位置偏好”的规则修改；输入仍是完整 point_engine 候选、无狼大原话/点位。
> G = 2025-12-11，他的第一档 3876.47（前一日低点 + 3×15min）。
> H = 2026-01-14，他的第一档 4141（再破 4141 + 放量 + 3×15min）。

## 1. 结果：0/2

| case | 他的第一档 | agent risk_trigger | 偏差 | 判定 |
|---|---:|---:|---:|---|
| G | 3876.47 | 3936.31（12/08 反抽高/10/09 前高） | +1.54% | ❌ |
| H | 4141 | 4034.08（1/6 突破箱体顶） | -2.58% | ❌ |

## 2. 它错在哪

### G：把“更高的已破结构”当成第一档

- 候选里明明有 `prior_day_low 3876.47`（他的第一档），agent 把它放进了 3850-3873 的 `support_holding` 带；
- 但 `risk_trigger` 选了 **3936.31**，理由是“12/08 反抽高 3936.31 撞 10/09 前高 3936.58 失败，是这波下跌起点的结构线”；
- 它按“同一波里优先更高的已破结构线”选，结果选到了 **上方 1.54% 的修复位**，不是他说的 3876.47。

### H：把“突破起点”当成第一档

- 候选里有 4130（-0.27%）、4150（+0.22%），离他的 4141 都不到 0.3%；
- 但 agent 的 `risk_trigger` 选了 **4034.08**，理由是“1/6 突破的箱体顶/颈线，是这波上涨的起点结构”；
- 它优先“远端结构起点”，完全跳过了 4141 附近的近端位。

## 3. 说明什么

1. **A-F 的 5/6 是拟合，不是泛化。**
   加了“位置偏好”后，A-F 变好；但 G/H 两条全新案例直接 0/2。
2. **“当前段起点/更高的已破结构”不是稳定规则。**
   G 里它把“更高的已破结构”选成 3936；H 里它把“上涨起点”选成 4034；两次都跳过了他真正说的近端位。
3. **他的第一档不是由价格数据唯一决定的。**
   3876.47 是“前一日低点 + 3×15min”的即时防守位；3936 是更高、更久的结构，但 3876 才是他当天要看的。
   4141 是“再破 4141”的近端触发；4034 是更早的突破起点，但 4141 才是当天的话。
4. **继续加规则只会过拟合。**
   每加一条“优先更高/优先起点/优先结构”，都会在另一批 case 上失效。

## 4. 结论

**agent 适合输出：候选带、合流、角色、区间、理由、不确定性；不适合单独决定“第一档是谁”。**

- 第一档应该来自 **账本 case 库**（他的原话/顺序）或人确认；
- agent 可以做“第二意见”：指出 3936/4034 也是结构位，但不能替代 3876/4141；
- 生产里如果 agent 选出的第一档和 case 库差 >0.5%，应该报“分歧”，而不是直接采用。

一句话：**位置偏好能解释 A-F，但 G/H 直接 0/2；这条规则不能进生产，第一档必须由 case 库/人定。**
