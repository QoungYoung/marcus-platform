## 2. 三条关键规律（对 gate 设计最重要）

### 规律①：build 主升 ≠ 永远禁切出——看"主线是否明牌吸金"
- **A2/A3/B1/B2（1-3 月 build）**：主线健康主升 → 只做主线内细分/补涨，符合"禁切出"。
- **B4/B5（2026-05-08，wave 仍是 build）**：半导体/PCB 出现 **HIGH+箱顶+资金连续流出≥2日** → 狼大撤高位、切低位——**板块级顶分型预警可推翻"build 禁切出"**。
- **A4/D4（05-25，wave 缺，语料=抽血无法轮动）**：主线高位仍净流入 160 亿 → 资金被吸在一个方向，此时高低切不可行（无承接）。
- → **判别变量不是 wave_op，而是"主线吸金强度/轮动健康度"**：主线仍领涨吸金=禁切出；主线内板块出资金流出/结构破位=允许撤高。

### 规律②："低位" = 相对主线落后（G2），不是自身价格低位
- C1（2026-04-15，t_only）：创新药/减肥药**自身 HIGH(箱顶98-100%) 但 rel_mainline=low(B反)** → 狼大称"低位、拿来切换"。
- position_class 若只用自身价格会判 HIGH 误减——**必须保留"rel=low + 资金确认"的豁免/可切分支**。
- B1/B2 卫星互联网/商业航天同为 HIGH(箱顶100) 但 rel=high → 语义是"高位龙头"，不是可切低对象。

### 规律③：t_only/side（调整/4浪）才是"切到主线外低位"的窗口，但要叠轮动健康度
- C1(t_only)、D2/D3(3-4 t_only)、C5/D6(side) → 非 build 期狼大/机构做防御性切换（或降个股转 ETF）。
- 但 D4(05-25 抽血)与 D6(08-03 无主线快速轮动)显示：**同样非 build，若市场无承接/快速轮动收割散户，切低不成立**——切低窗口 = 非build **且** 轮动健康（有承接、方向有持续性）。
- B3(03-19, MISMATCH) 提醒边界：wave_agent 判 d4/4-1/defense，狼大语料却说"国算未出货、趁切换"——这是 **千人千浪 + 机构资金逻辑（业绩/出货周期）与波数标签不同频** 的典型；gate 建议对"语料明示主线未出货/业绩月未过"的日期人工复核或加提示词维度。
