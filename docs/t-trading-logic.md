## 9. 规则草案（待 code 化）

资格：有底仓才有资格做T；T仓与底仓分离（不混仓）
正T信号：
  T1 缩转放：量能由缩转放（vol_z 由负转正/放量）→ 买 T 仓
  T2 黄线纪律：日内价格在分时黄线(日均线)上可做；跌破黄线直接走
  T3 时间窗：15 分钟线为依据；半小时冲高无量不过前高 → T出
T出信号（狼大 7-29 原话）：
  放量反弹 → 第一次分时高点后停止放量 → 第二次拉升无量不过前高 → T出
反T禁忌：无底仓不反T；反T 不得丢底仓
差价目标：3-5 个点；舍得卖（敢买敢卖）
指数级：指数波动差价优先于个股（安全性）
