# 狼大止盈体系（被动止盈线）：语料汇编 + 策略拆解

> 语料：`狼大回复汇总 20260814-1457&往期.xlsx` 全量 25,807 条（2016-01 ~ 2026-08-14），其中含“止盈”251 条、“被动止盈”100 条；增量 NGA [tid=47288722](https://ngabbs.com/read.php?tid=47288722) 楼主 1,263 条（至 2026-10-16）。
> 目标：只做一件事——把他关于“止盈”的话全部翻出来，去重、归类、提炼成可执行的被动止盈规则。
> 约定：本文把“止盈”分成 **主动止盈** 与 **被动止盈** 两套，不混在一起谈。

---

## 0. 先给结论

1. **主动止盈看“目标/逻辑”，被动止盈看“结构/趋势”。** 主动止盈是到了心理预期或逻辑目标先减 1/3，剩下的全部转被动；被动止盈没有目标价，只有“破哪条线就走”。
2. **被动止盈本质是跟踪止损（trailing exit），不是目标价。** 所以它既能保护利润，也能在没利润时当止损用——他自己就混用“被动止盈止损”这个词。
3. **只上移，不下移。** “我的被动止盈不断往上，不接受损失”（2025-05-13）；每创新高/每上一个平台，止盈线跟着抬。
4. **触发分五族**：趋势结构（通道/均线/平台）、高点回撤（-3%/-5% 记忆点）、形态量价（顶分型/放量大黑 K）、指数/组合（防御仓看指数、一半盈利仓触发=4 浪）、事件时间（催化兑现/13 天时间成本）。
5. **执行上三句话**：提前挂条件单；多数看收盘确认；破了先减 1/3，放量破/跳空破才清。破了不急着回原票，变现金找新逻辑。

## 2. 定义与分工：他自己怎么说

### 2.1 最完整的一次定义（2021-01-22）

> “主动止盈一般看你的心理预期，你做逻辑策略的那个点，到了就减仓 1/3，其他的转被动止盈就行了。超预期就继续吃超预期的利润，但是不要想着改你自己的预期，除非有消息导致整体逻辑有变。”

这句话把两套止盈的关系说透了：

- **主动止盈 = 目标位/逻辑兑现**，动作是“减 1/3”；
- **被动止盈 = 剩余仓位的跟踪退出**，不预测顶；
- 超预期不修改目标，只让被动止盈跟着抬。

### 2.2 趋势票没有“止盈位置”，只有被动止盈（2021-11-17）

> “做趋势是没有止盈位置的，只有被动止盈，就是回撤到破趋势位后直接出场。通过每一次趋势内的小波段不断地降低成本获取收益……通道上沿减仓对应的是下沿我是加倍仓的。”

### 2.3 主动与被动必须分开执行（2026-07-06）

> “主动止盈已经提前做了，被动止盈是个股的被动操作，不受盘面影响。”

这句非常关键：**被动止盈一旦设好，不因为盘中情绪、消息、别人喊单而临时改**。

### 2.4 目的：少赚不亏（2021-01-03 / 2025-09-10）

> “只要做好被动止盈，哪怕少赚也不会产生亏损，放低自己的预期，不要想着卖到山尖就行。”（2021-01-03）

> “所以设置被动止盈很重要，可以不赚，但是不能亏。”（2025-09-10）

> “浮盈没用的，拿到手里才是盈利。”（2025-08-29）

## 3. 被动止盈的五族触发

### 3.1 趋势结构族（最核心）

**触发线候选**：趋势通道下沿、最近平台低点、13/34/60 日线、日线 BOLL 中轨、上一日最高价/缺口下沿。

| 触发 | 动作 | 原话 |
|---|---|---|
| 通道下沿带量破 | 策略单直接丢 | “100 就是通道下沿，带量破通道下沿策略单就丢了”（2021-02-22） |
| 13 线破 | 减 1/3 | “13 线的位置被动止盈 1/3，其他继续”（2021-01-19） |
| 34 线破 | 减 1/3，不回补 | “34 线我是 1/3 仓位没回补”（2025-09-10） |
| 放量跌破 60 日线 | 清仓 | “放量跌破 60 那天清仓”（2025-09-10） |
| 日线 BOLL 中轨放量跌破 | 收盘完全止盈 | “全止盈的位置就放在日线 BOLL 中轨附近，放量跌破收盘完全止盈”（2025-05-13） |
| 收盘跌破平台 | 减仓 | “收盘跌破平台减仓，是为了被动止盈、保收益”（2026-01-29） |
| 顶分型 + 破位 | 撤大部分 | “半导体已经有顶分型的迹象，如果破位我就撤大部分了”（2026-05-08） |

**2016 年的原始版本**（同源，只是更朴素）：

> “股票突破后回落再突破，那就以第一次的突破回落高点做止盈；如果继续突破，就继续把止盈设在第 2 次突破回落的点……有效跌破或者跳空到下面，直接出场。”（2016-06-24）

> “白酒跌破 6 月 16 那根红 K 开盘价，直接止盈。”（2016-06-20）

### 3.2 高点回撤族（记忆点）

**最具体的一组参数**（2025-08-13，科创 ETF）：

> “按今天收盘价，单天 -3% 止损，或者一周 -5% 止损，只要每往上 3% 就重新做记忆点。这样保证利润不会回撤太多。”

翻成规则：

- 记忆点 = 最近一个“新高”（每 +3% 抬一次）；
- 从记忆点回撤 -3%（单日）或 -5%（一周）→ 触发；
- 触发后不是清仓，而是减仓/卖利润，底仓保留（见 §4.3）。

**更早的版本**（2021-01-04，金龙鱼）：

> “金龙鱼 115 了，被动止盈上调成 108，一旦有针头破了这个位置出 1/3。”

- 止盈线从 87 → 108，随价格上移；
- “针头破”也算，先出 1/3。

### 3.3 形态/量价族

| 触发 | 动作 | 原话 |
|---|---|---|
| 顶分型 | 减/撤 | 2026-05-08 |
| 放量大黑 K / 高开长阴 | 清/撤大部分 | 2026-09-02（大光破位大黑 K = 科技彻底止盈）、2026-09-04（高开放量长阴） |
| 放量跌破 | 完全止盈 | 2025-05-13（BOLL 中轨） |
| 缩量不过前高 | 做 T 离场（非被动止盈） | 2026-08-04，属于 T 腿规则，不要混用 |

### 3.4 指数/组合族

**防御仓用指数点位做被动止盈**（2025-05 ~ 06）：

> “被动止盈调整到大盘 3320 位置。”（2025-05-19）

> “目前 30% 仓位的防御板块，被动止盈提高到 3334 点。”（2025-05-22）

> “持仓，下方被动止盈位提高到 3373，不破不卖。”（2025-06-09）

> “3373 是被动止盈区域，这些位置看收盘。”（2025-06-25）

**组合宽度信号**（2026-06-30）：

> “当我手上一半盈利仓触发被动止盈的时候。”（回答“什么情况你会开始减仓甚至清仓，认为进入四浪了”）

这条不是单票规则，而是**组合级 regime 开关**：一半以上的盈利仓同时触发，说明不是个股问题，是趋势/风格切换。

### 3.5 事件/时间族

- **催化兑现**：“九天的被动止盈就是出新闻的时候。”（2025-05-30）
- **时间成本**：“13 天内超不过抄底那根 K 线的高点，就不用呆了，时间成本也是成本。”（2026-03-06）
- **尾段/结账**：“最后一段撤掉”“结账的方式我之前也给你们分析过了”（2026-09-04、2026-06-23）。

## 4. 执行细则：他实际怎么下单

### 4.1 条件单，提前一天做好

> “我自己是根据线做的价格条件单，提前一天做好。开盘竞价和大盘预判要是正常就不用管了；要是条件不满足就撤了打 PLAN B。”（2021-02-04）

要点：**不是盘中盯出来的，是盘前就把线画好、单挂好**。盘中只判断“条件是否满足”，不临时改线。

### 4.2 收盘确认，例外是“针头/突发/跳空”

- 平台、指数、BOLL 中轨：**看收盘**（“这些位置看收盘”2025-06-25；“收盘跌破平台”2026-01-29）。
- 趋势票的“针头破位”：**盘中破就算**，先出 1/3（2021-01-04）。
- 跳空低开：**开盘直接丢**，不等收盘（“今天直接跳空低开，所以只能是开盘丢的”2021-07-01）。
- 弱势日：**低于开盘价直接被动止盈/止损**（2021-02-08）。

### 4.3 分批，不是一次清

| 场景 | 首减比例 | 剩余 |
|---|---|---|
| 主动止盈到目标 | 1/3 | 转被动 |
| 针头破位 | 1/3 | 继续按线 |
| 13/34 线破 | 1/3 | 继续按线 |
| 放量破 60 日线 | 清仓 | — |
| BOLL 中轨放量破 | 完全止盈 | — |
| ETF 到被动止盈位 | 利润全卖 | **只留最初底仓**（2025-08-27） |

> “到了被动止盈位置后把利润全部卖出，只剩一开始买的底仓。”（2025-08-27）

### 4.4 只上移，不下移

> “其实核心就是他只能涨，我的被动止盈不断往上，不接受损失。”（2025-05-13）

> “我只要不断按平台提高我的被动止盈就行。”（2021-01-04）

**这条是硬约束**：止盈线一旦上移，不因反弹预期、消息、成本而调低。

### 4.5 破了不急着回原票

> “一个票做技术被动止盈后不一定要急着回去，可以去另一个分类板块的票进行滚动操作，这也就是为什么我开杂货铺的原因。”（2021-02-13）

> “手上的没破就一直拿，破了就变成现金继续找新逻辑。”（2026-06-30）

### 4.6 触发即“核按钮”，不和执行讨价还价

> “机械设好被动止盈点……只要触及我的点位立马核按钮。”（2021-01-07）

## 9. 可落地规则草案（给“被动止盈线”）

### R-PT1 账户分层

底仓/趋势仓、T 仓、防御仓、长线仓分开；**被动止盈只作用于底仓/趋势仓、防御仓、长线仓**，T 仓走 +3% 目标兑现（已有）。

### R-PT2 趋势仓：结构跟踪线

```
line = max(通道下沿, 最近平台低点, MA60, BOLL中轨)
line = max(line, pos.trailing_line)      # 只上移
if close < line:
    exit 1/3
    if volume_break or gap_down:
        exit all
```

### R-PT3 ETF/题材仓：记忆点回撤

```
hwm = max(hwm, close)
if close <= hwm * 0.97 or week_dd <= -5%:
    sell_all_profit_keep_base()
if close >= hwm * 1.03:
    hwm = close                            # 每 +3% 重置
```

### R-PT4 防御仓：指数收盘线

```
if index_close < index_trailing_line:
    exit_all_defensive()
```

### R-PT5 组合宽度

```
if triggered_profit_positions / profit_positions >= 0.5:
    reduce_gross_exposure()
    regime = 'wave4_defense'
```

### R-PT6 执行约束

- 盘前挂条件单，盘中不改线；
- 结构看收盘，针头/跳空例外；
- 首次 1/3，放量/跳空清；
- 触发后不原价回补；
- 止盈线只上移。

### R-PT7 禁止事项

- 下移止盈线；
- 破位补仓摊平；
- 把 T 腿的 +3% 规则套到趋势仓；
- 把期货“不设止损”套到股票；
- 用“长期逻辑”推翻已触发的止盈。

## 10. 与现有 exit-rules 线的衔接

现有 `docs/plan-exit-alignment.md` 的 R1–R5 主要解决 **做 T 腿的兑现**（+3% 目标、破黄线、做 T 前置、高低位分工），`exit-rules-*` 的实测也集中在 T 腿（+3% 抬胜率、破黄线无 alpha）。

**本文的被动止盈线是另一条腿**：波段/趋势仓的退出。两者不要共用一套评估：

| 维度 | T 腿兑现 | 被动止盈线 |
|---|---|---|
| 对象 | 有底仓的日内/隔日 T | 底仓/趋势仓/防御仓 |
| 目标 | +3%~+5% | 不设目标，跟踪结构 |
| 触发 | 目标价、破黄线 | 通道/平台/均线/回撤/指数 |
| 评估指标 | 胜率、均值、盈亏比 | **回吐率、趋势捕获率、最大回撤** |
| 现有设施 | `profit_take`、`roundtrip_priority` | `WOLF_BOLL_MID_EXIT`、`WOLF_CUSHION_CAP`（部分） |

**建议的度量口径**（不要只用胜率）：

- **捕获率** = 实际退出价 / 该腿最大有利变动（MFE）；
- **回吐率** = 1 - 捕获率；
- **趋势捕获** = 是否吃到主升段（按 MA60/通道持有天数）；
- **尾部** = 触发后 N 日反事实收益（判断是否卖在洗盘）；
- 分类型（趋势/ETF/防御）、分市场状态（趋势/震荡/下跌）、H1/H2 分段；
- n<100 只做探索，关键结论用块状 t。

**先做的事**：从 `paper_trades` 和 `bt_pit` 里把**非 T 的波段腿**分离出来，否则会重复用 T 腿样本得出“止盈无用”的结论。

## 12. 一句话总结

**主动止盈决定“赚多少”，被动止盈决定“能不能带走”。** 他的被动止盈不是一条固定线，而是三套并行的跟踪退出：趋势票看结构、ETF 看回撤记忆点、防御仓看指数；共同约束是——只上移、看收盘（针头/跳空例外）、先减 1/3、放量破才清、破了不回头。
