# B反 框架 v2（人类判断版）

> 2026-10-23 重写。v1（闸门打分卡）已被自己的回测否掉，见 `docs/b-rebound-reread-202610.md` §5.5c/§5.5d。
> 本版只保留**能被原话支撑、且能和人一起用**的部分。
> 生产口径：只观察，不接交易、不接 gate。

---

## 0. 一句话定义

> **B反 = 在一个预判的级别里，一段有时限、一次性的反弹。**
> 它的任务不是"抓住底部"，而是**在大家都知道还要跌的前提下，赚那段"必须有人接盘"的钱**。

配套的三条原话：

- 「**B反 是一次性的**……要信早信，在这波顶部才进场就等死了」（2026-08-05）
- 「**连我都没有 **[精确数浪]** 这个实力**，或者说没有意义」（2026-05-24）
- 「冲过了就是确认这波是 B反……**就是那种后视镜马后炮的技术流确认**」（2026-04-16）

⇒ 所以本框架**不做「B反 起点识别」**。它做的是：**判级别 → 等结构终结 → 等承接 → 定目标与失效 → 吃一段就走**。

## 0.5 运行方式：给 **agent** 用，按人脑方式分析（硬约束）

> 本框架的最终使用者是 agent，目标是**模拟人的判断**，不是执行公式。

### 禁止

- ❌ 用分数 / 阈值 / 公式作为买卖触发（"总分 ≥5 就买"、"量比 ≥1.3 就加"）
- ❌ 把判据写成 `if X > Y then buy`
- ❌ 用单一指标下结论（尤其实时量比、均线、超跌幅度）
- ❌ 用"胜率 60%""概率较高"当理由——那是回测的语言，不是判断的语言

### 必须

**① 四行预判先写，每行都带可核对的数字与日期**

```
级别：哪一级的反弹？依据是哪一段结构（谁是谁的 B）
长度：几天到几周？先给一个数，错了再改（3 小时 / 2 天 / 11 天 / 2 个月都合法）
目标：哪个浪型结构点？（1浪顶 / 4-3低点 / 前一轮顶，人工标）→ 再拿前低/前高/缺口交叉验证
失效：B 起点低点 ×(1−3~6%)，写明具体价位
```

**② 读相位并自证**：起点 / 中段 / 顶 / 结束 / 根本没有 B反——五选一，**"支持"与"反对"各一条证据**。

**③ 读谁在买**：放量的形状 = **放量 × 收盘位置 × 昨日承接今日有没有做上去**。
（收盘前推送，所以只能用「昨日 → 今日」，不能用次日，否则等于偷看未来。）
割肉＝放量收下半区；承接＝放量收上半区**且次日（即次日的那个"今日"）不破昨低、收在上半区**；
自救＝承接出现后"今日"破昨低或收下半区（10/9、10/13、10/15 三次都是这种）。
**单日只算候选，两日才算确认**：8/4 收位 71% 但破了 8/3 低点 ⇒ 未确认；8/5 不破昨低 + 收位 83% ⇒ ✅ 承接延续（他 8/5 开盘加仓）。

**④ 读够不够得着**：目标到现价的距离、失效位在哪，用一句话回答"这笔记不值得做"，不算 R:R 阈值。

**⑤ 给预案 1/2/3**，其中必须有一条是"都不出现就不做"。

**⑥ 给反证条件**：什么情况出现就说明这次读错了。

**⑦ 允许"看不清"**：不做是合法输出，不是失败。

### 防自欺的护栏

每个判断必须带 **可核对的数字（日期 + 价位 / 量比 / 收位）**，并写一句 **反证条件**。
**做不到这两点，就退回"看不清"，不许硬凑一个理由。**

理由：本轮研究里三次"好看→拆穿"（打分卡无超额、全连乘越连越差、五步链条样本截断），根因都是在 ~400 个独立事件、年份高度集中的样本里调参数。他本人的原话也指向同一处——「连我都没有（数浪）这个实力」「技术是保命用的」「B反 是一次性的」。

### 输出契约

一段人话 + 一张四行表 + 预案 1/2/3 + 一句反证条件。**不输出分数。**

## 1. 为什么"识别起点"是错的问题

| 证据 | 含义 |
|---|---|
| 他自己说确认是「后视镜马后炮」、数浪「连我都没这个实力」 | 起点不可精确识别，他本人也不做 |
| B反 时长跨 **3 小时 / 2 天 / 2 个月 / 11 个交易日** | 它不是形态，是**级别区间**；固定持有期没有意义 |
| 8 只 ETF 回测：闸门 ≥5 的超额 +0.94pp，CI −1.9~+4.1 | 打分卡没有统计支持 |
| 五条全连乘后超额 +1.94 → +0.37pp | **条件越多越差**：它们在同一阶段一起亮，加条件只减样本 |

**结论：v1 的「打分 → 过阈值 → 买入」全部作废。**

## 2. 五步链条（他 2026-05-24 亲口给的操作骨架）

> 「预判浪型 → 观察节点 → 节点出现迹象 → 根据预先定制操作 → 马上对应操作，这是一个完整的链条」
> 「重点是判断短波的小级别趋势方向是不是会被逆转，观察那些**逆转节点时候资金的表现是延续、诱多或是结束**」

### 第 1 步 · 预判（事前写下来，盘中不许改）

要写的只有四行：

```
级别：这是哪一级的反弹？（指数 4-4 / 板块 ABC 的 B / 下跌浪里的 4 浪反抽）
长度：预期几天到几周？（3 小时 / 2 天 / 11 天 / 2 个月 —— 先给一个数，错了再改）
目标：哪个浪型结构点？（1浪顶/4-3低点/前一轮顶，人工标）→ 再用前低/前高/缺口交叉验证
失效：跌到哪里算我错？（B 起点低点 ×(1−3~6%)，不是裸低点）
```

### 第 2 步 · 观察节点（等，不猜）

节点不是日期，是**状态**：结构终结、承接出现、题材破位、GJD 出手。四个都等不到就不做。

### 第 3 步 · 看迹象（延续 / 诱多 / 结束）

**同一个信号在不同位置含义相反**——这是他最反复强调的一点：

| 现象 | 在底部 | 在反弹末段 |
|---|---|---|
| 缩转放 | 有人进来了 → 可以加 | 「**缩转放太早了**」→ 反弹弱（5/15） |
| 放量转缩量 | 抛压衰竭 | 「机构要在这里震荡做反抽吸引人接盘」→ 准备走（5/21） |
| 尾盘拉升 | 承接 | 「一天的波动，还是尾盘缩量拉升」→ 不许改计划（8/18） |

### 第 4 步 · 预案（提前写 1/2/3）

他原话：「为什么我总叫大家提前做好方案123，然后出现对应的节点迹象做对应的事」。
预案要写清：出现 A 迹象 → 做什么；出现 B 迹象 → 做什么；两个都不出现 → 不做。

### 第 5 步 · 执行（马上、一次性）

- **一次性**：不补仓、不摊平、不把反弹当趋势；
- **卖出价在买入时定好**：「这个卖点我是现在才说的么？这不是之前就定下来的么」（8/18）；
- **到不了目标也要走**：目标 1.15，实际 1.10 卖。

## 3. 「为什么迟迟没有 B反」——四条门槛（2026-10 原话，v1 完全没有）

这一节是本次新增的核心。2026-10 他反复解释"为什么还没有 B反"，答案不是"跌得不够"，而是**下面四条没同时成立**。

### 门槛 1｜结构还在延伸，没有"终结"

> 2026-10-21：「**不，还是延伸浪。延伸浪的终结一定是一个明确的结构。**」（有人问"现在是 b 反了吗"）
> 2026-10-21：「所以结构还没完成，现在还是属于反抽……**这里就是自救，纯粹的**」
> 2026-10-22：「破了是好事啊，15 分钟之后只要开始放量就证明钱进来了」

⇒ **判据：延伸浪未终结 ⇒ 没有 B反，只有反抽。** 终结要一个"明确的结构"，不是跌够了。

### 门槛 2｜有人接，而不是"自救资金"

> 2026-10-22：「目前是**资金没有足够的理由去抗公募的止损卖盘**。就是自救资金，就是纯自救，**没有反身向上的意思**」
> 2026-10-22：「场内资金已经没有割肉盘口了，现在都是场外资金的割肉……**量能不会骗人，有量就是有人接**」
> 2026-10-22：「能不能抄底取决于量能……**没有人承接的恐慌盘不值得抄**」
> 2026-10-22：「他放量我就敢做，他缩量我就不做」

⇒ **判据：自救资金 ≠ B反。** 自救只求"比你高一点卖掉"，不会把价格推上去；B反 需要**新的、愿意在更高位置买的资金**。

### 门槛 3｜场外资金因为"辨识度 + 相对低位"进场

> 2026-10-21：「先利用我之前说的细分展开自救，但是这个时候**因为指数没上，散户和后知的大资金是不敢进场的**。因为看起来没有持续的赚钱效益，现在的利润是自救资金的」
> 2026-10-21：「利用指数大标做轴，在不触发卖盘的时候先拉同板块的细分……**到时候开始全面反弹的时候，后进资金会因为辨识度和相对低位进场这些指数大标**，从而可以更好的把里面的钱救出来」

⇒ **判据：指数不动 ⇒ 场外不进 ⇒ 没有 B反。** 这是一个自我锁死的僵局：细分越热闹、指数越不动，B反 越不来。

### 门槛 4｜别的方向都死了（资金被迫回主线）

> 2026-10-19：「目前盘面出现了几个要素：**下跌浪型完成**（上证下跌 5 浪 / 科创 ABC）；**GJD 保三天 3700**；**机构打好了自救资金**；**大光低位降速并且出了个十字顶分型**；**前期的几个题材全都跌破反弹趋势**（药、房地产那些）」

⇒ **判据："前期题材破位"不是坏事，是 B反 的前提**——只有别的方向都死了，钱才被迫回主线。

### 四条门槛的用法

```
门槛1 未过 → 只做反抽，不做 B反（仓位 ≤1/3，当日了结）
门槛1 过、2 未过 → 仍是自救行情：做 T，不持仓过夜
门槛1+2 过、3 未过 → 板块内部轮动，指数级别 B反 不成立
四条全过 → 才是能上仓位的 B反
```

## 5. 结束与减仓（B反 的另一半）

> 「B反 尾声的时候，我能看到『我减了』这三个字吗？我前面哪一次大减的时候没说？」（10-22）
> 「我吃的是共性上冲那一段，一定要舍得走。**不是抄底，而是追涨**，进去多少钱就要出来多少钱」（10-22）

判据（按他用过的顺序）：
1. **目标区到了**（够得着的位置），分批走；不到也走；
2. **放量转缩量**（机构做反抽吸引接盘）→ 准备走；
3. **缩量又转放量 + 主线跳水**（量化主卖）→ 立刻走（5/21 原话）；
4. **C杀 的必然性**：不是形态算出来的，是「多次尝试后市场达成『这里没有性价比』的统一意见，当大家都卖的时候，就是 C」（2025-09-20）。

## 6. 四种必须认得出的"变形"

| 变形 | 例子 | 处理 |
|---|---|---|
| **弱 B反** | 2025-08-01「弱 B反 就持续了 3 小时」 | 只做 T，不建仓 |

## 7. 执行细则（人用的版本，不是阈值）

```
仓位：预判仓 ≤1/3 → 反转日开盘加到 ≤2/3 → 到目标区分批走 → 破了就撤
工具：ETF（因为要「卖得掉」，且个股会晚涨导致错过出货窗口）
目标：**先看浪型结构点**（1浪顶/4-3低点/前一轮顶，人工标）→ 再拿前低/前高/缺口/平台交叉验证；冲突时以结构点为准
失效：B 起点低点 ×(1 − clamp(1.5×ATR20%, 3%, 6%))
禁止：补仓摊平 / 盘中改预案 / 把反弹当趋势 / 追高进场
```

三条数据支撑，**并标注各自的证据强度**：

| 结论 | 状态 |
|---|---|
| 裸低点止损胜率 36%，加缓冲后 46% | ⚠️ **单次回测，未做跨年复验**，只能当"方向性提示" |
| 目标越远越是把胜率卖掉（R:R<1 更好） | ❌ **已撤回**：那条是子集 artifact。全样本上是反向的（R:R<1 均值 −1.31% vs R:R≥1 −0.16%），逐年只有 1/7 一致 |
| 同一套数浪 2020/2021/2025 胜率 95–100%，2023/2026 只有 11–23% | ✅ **最稳的一条**：所有定义下都复现，年均值跨 17.6pp 且正负翻转 |

## 9. 已知缺口（不装懂）

1. **四条门槛无法回测**：「自救资金」「场外资金是否进场」需要资金流/席位数据，现在没有；
2. **"明确的结构"他没有定义**：顶分型？降速？放量？——只给了三个例子，没有判据；
3. **样本**：门槛体系只有 2026-08（成立）与 2026-10（不成立）两个观测点，n=2；
4. **可验证的部分**只有执行侧（止损缓冲、背景过滤）；「目标够不着就换」那条已被回测撤回；
5. **浪型结构点无法自动识别**：生产 `wave_state` 的锚点会漂（同一个 `wave1_top` 在 4 月是 3174、8 月是 3674），只能人工标「他引用过的点」。

## 10. 回测状态（2026-10-23，诚实版）

| 检验 | 结果 |
|---|---|
| 五步链条（信号日 → 1~3 日确认窗口 → 执行） | 首轮 +7.70%（CI +5.5~+9.7），**但这是事故**：`index_daily` 只从 2024 起，`if sig not in IM.index` 静默丢掉了 2019–2023 约六成样本。该数字实际是「2024–2026 那三年」的表现 |
| 修正后：门槛1（结构+终结迹象）vs 仅结构 | +2.35% vs +3.83% ⇒ **终结迹象没有增益** |
| 逐年（同一形态定义） | 2020 +8.09 / 2021 +6.21 / 2022 +0.18 / 2023 −1.53 / 2024 +7.76 / 2025 +13.53 / **2026 −4.10**（胜率 11%） |
| 样本外切分 | 2019–2023 +0.85% vs 2024–2026 +4.21% |
| 方差分解 | 单笔 σ≈9.3%，年际均值差 ≈6.6pp，任何条件差 1–3pp ⇒ **单笔完全看不出，只能靠大量独立事件**；而样本高度年份集中（≈400 独立日）⇒ **结构上不可验收** |

**结论**：v2 的流程是**可执行的**（步骤明确、预案可写、失效可算），但**不可验收**（无法从历史里稳定证明它优于基准）。这是本题目下能给出的最强表述。

**三次「好看→拆穿」的共同根因**：在 ~400 个独立事件、且年份高度集中的样本里找配置，必然过拟合。打分卡、连乘、五步链条，三次都栽在同一处。
