- 确认链（买入）：**缩量止跌**（地量/揉搓线/站稳 BOLL 中轨）→ **W底/双底结构** → **放量突破颈线**（吃挂单）→ **站稳 N 天**（如 3 天）→ **量能持续放大** → 右侧二买入场。
