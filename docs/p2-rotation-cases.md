## 验证状态与缺口

- **可直接回放**：A1/A2/A3 大级别可对 2025 wave 回测 TRUTH（d3/3-1、3-3 build）；D2~D5 属 2026 高位段，position_class 相关概念 2026-04/05 已在 position_systematic 的 11 时点附近（可补 2026-04-15/05-08/05-25 时点）。
- **待 wave_agent 历史重放**：2026-01~08 各 case 的大级别判定（尤其 A6/C1/C2/C4/C5/D6 的 4-4/t_only 语境）——需跑 wave_agent index_features(date) 逐日判定写入 wave_state_<date>.json，再对照"禁切/可切"预期。
- **position_class 时点回放**：对 C1(药/航天 LOW vs 存储 HIGH)、B4(半导体 HIGH→破位)、A6(药 LOW→反弹反转) 按日期算对应概念 position+structure，验证 LOW 才可切、HIGH 破位才撤。

## 预期 gate 规则（供 trade_graph/做T之外的轮动层参考）

gate_rotation(date, 持仓板块A, 候选板块B):
  wave_op = wave_state.operation
  leader = 板块A龙头状态(破位/异动)
  posB = position_class(B)
  if wave_op == build and B属于主线A:
      允许 主线内细分轮动/补涨（龙头未死）
      禁止 切出主线到非主线低位 (A4)
  if wave_op in (t_only, side) and 板块A已破位/压力线:
      允许 防御性高切低（候选 LOW+逻辑+无2孕线+未放量破前日低）
  if wave_op in (defense, exit):
      不做轮动/切低，离场为主
  leader 破位 -> 立即处理持仓A，禁止同板块低切补涨 (B1)
