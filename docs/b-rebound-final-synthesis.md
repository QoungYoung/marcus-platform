## 核心修正

```text
B反 不是选股信号
B反 不是单一指标
B反 不是下跌行情里的龙头交易
```

狼大原话：

> 「B反 我做什么个股？把指数做完就收手。」

> 「下跌行情没有主线，只有踩踏。」

所以 B反 的正确结构是：

```text
浪型/级别
+ 市场流动性/GJD
+ 总仓位
+ 工具（默认 ETF）
+ 目标位
+ 失效位/C杀
+ T 的执行
```
