# 狼大五层对齐总方案 v1

> 2026-10-22  
> 目标：从“风向标因子化”退回到“五层漏斗 + 动作纪律”，先审计、再重建、再验证、最后接管。  
> 本文是执行方案，不是投资建议，也不直接改生产交易。

---

## 0. 结论先行

我们此前最大的错误：

> **把狼大的“方向生死开关”做成了选股因子/仓位乘数，忽略了五层漏斗。**

正确结构：

```text
① 级别/浪型  → 能不能做
② 仓位档位    → 做多大
③ 方向/主线   → 做哪里
④ 票          → 做哪只：龙头/核心/老龙头/龙2，绝不后排
⑤ 买点/节奏/止损 → 怎么做
```

五层是 **AND**，不是 OR。  
风向标只属于 ③/④ 的一层开关，不能替代其余四层。

## 1. 当前基线（必须承认）

| 项 | 现状 |
|---|---|
| 生产 `select_core` | stage×role，warning/dead 不过滤，advisory |
| 当前 picks | 19 条，去重 10 只；影视/游戏、白酒/食品饮料大量重叠 |
| 当前 AI 状态 | 45 子主题：warning36 / alive8 / dead1（白酒），已写 context/PG，但不 gate |
| PIT 数据 | 2025-01~2026-10；2024 无 membership；18 主题，42+ segment |
| dead 事件 | 222 段，confirmed 156；confirmed dead 后 HCL -0.66%，CI 跨 0 |
| AI 验证 | 36 case，v4 与机械一致 69%，但 dead recall=0；对真实 5 日：AI alive +3.52%，AI warning +1.04% |
| 执行层 | 基本没有：无盘中时间窗、无挂单、无止损、无仓位档位 |
| 组合层 | 无去重/主题风险预算/同因子暴露控制 |

### 1.1 当前最可疑的结构性问题

1. **票层可能系统性买后排**：`strong → bucket=second` 与“绝不后排”冲突；
2. **角色混淆**：风向标、龙头、核心、老龙头、龙2 被压成一个 `state`；
3. **方向层缺失**：没有容量/拥挤/链条联动/龙头带动；
4. **仓位层缺失**：没有 75/50/30/0 的市况档位；
5. **买点/止损层缺失**：没有 9:45–10:00 / 14:00–14:30、挂前低、13/34/60；
6. **风向标过度中心化**：overlay/gate/AI 都在这一层反复优化；
7. **验证目标错**：用 5/20 日均值验证一个 3 日内动作。

## 2. 目标系统

```text
┌────────────────────────────────────────────┐
│ 数据层：PIT 成员 / 日线 / 概念 / 龙头角色     │
├────────────────────────────────────────────┤
│ ① 级别层：operation（build/t_only/side/defense/exit）│
│ ② 仓位层：按市况 + 利润垫给总仓位             │
│ ③ 方向层：主线池 + 容量/拥挤 + 风向标生死     │
│ ④ 票层：龙头/核心/老龙头/龙2；排除后排/杂毛   │
│ ⑤ 执行层：买点、时间窗、止损、兑现            │
├────────────────────────────────────────────┤
│ 组合层：去重 / 主题暴露 / 风险预算             │
│ 审计层：AI 角色裁判 / 证据 / 版本 / 影子       │
└────────────────────────────────────────────┘
```

### 2.1 三个角色，必须分开

| 角色 | 定义 | 用途 | 可否更换 |
|---|---|---|---|
| **风向标** | 短时期板块内最强走势个股 | 方向健康度/生死开关 | 会换 |
| **龙头** | 从风向标里产生的最强可交易票 | 主攻/持有 | 相对稳定 |
| **核心** | 绑定板块、市值/产业地位核心 | 板块定价权，板块活它活 | 不能换 |
| **老龙头** | 上一轮有辨识度的龙头 | 低位埋伏/修复反弹 | 可换周期 |
| **龙2/分类龙头** | 龙一之外的最强辨识度 | 补涨/替代 | 可换 |
| **后排/杂毛** | 核心/风向标之外的低辨识度票 | **禁止** | — |

语料依据：

- 2025-12-06：风向标/龙头/核心三角色定义；
- 2026-01-16：「后排反倒不能去」；
- 2025-09-10：「不买龙头可以买分类龙头或者龙2，不买后排」；
- 2026-01-12：「龙头风向标死了就不能做了」。

## 3. 分阶段执行

### Phase 0：冻结与审计（1 周）

**目标**：先确认“我们到底在买什么”，不急着改。

任务：

1. 冻结生产：
   - `select_core` 不改规则；
   - 风向标不接 gate、不做乘数；
   - AI 状态继续只读写入 context/PG；
2. 跑 `select_core` 角色审计：
   - 每只 pick 是龙头/核心/老龙头/龙2/后排？
   - 同主类排名、市值排名、成交额排名、辨识度；
   - 与“绝不后排”对照，统计违规率；
3. 五层评分卡：
   - 级别、仓位、方向、票、买点/止损各 0–5 分；
4. 组合审计：
   - 去重后股票数、主题簇、同因子暴露、单票权重；
5. 产出：
   - `docs/wolf-layer-audit.md`
   - `data/audit/role_violations.csv`
   - `data/audit/portfolio_concentration.csv`

验收：

```text
能回答：
  当前 picks 有多少是后排？
  有多少重复暴露？
  五层各缺什么？
```

Go/No-Go：审计报告完成才进入 Phase 1。

---

### Phase 1：PIT 数据与角色事件（1–2 周）

**目标**：把“角色/事件”变成可复算数据，不再用 `bucket=second` 代替。

任务：

1. 角色表：
   - `wind`（风向标）
   - `leader`（龙头）
   - `core`（核心）
   - `old_leader`（老龙头）
   - `second`（龙2/分类龙头）
   - `back_row`（后排，排除）
2. PIT 规则：
   - 龙头：个股强于板块、板块强于大盘；市值/成交/辨识度；
   - 核心：总市值前 5 + 产业绑定 + 营收/业绩；
   - 老龙头：历史领涨/历史成交额/概念记忆；
   - 后排：非核心、非龙头、非龙2；
3. 事件：
   - impulse；
   - 连续 lower high + 放量；
   - 换人；
   - 高切低（防御性/追涨性分开）；
   - 补涨（老龙头/龙2，不是所有 second）；
4. 数据边界：
   - 2024 无 membership，不伪造；
   - 只做 2025-01~2026-10；
   - 18 主题内先做，再补 segment；
5. 产出：
   - `data/pit/roles_weekly.csv`
   - `data/pit/events.csv`
   - `docs/wolf-role-schema.md`

验收：

```text
每个事件有 as-of 证据
每个角色有可复算规则
后排有明确排除条件
无 2024 伪造
```

---

### Phase 2：方向层（1–2 周）

**目标**：先决定“做哪里”，再谈买哪只。

任务：

1. 主线池：
   - 主题近 5 日成交额占比 topK；
   - 近 5 日相对强度 > 0；
   - 近 20 日跑赢天数；
2. 容量/拥挤：
   - 主题成交额占全市场比例；
   - 是否过度集中/拥挤；
   - 是否有链条联动；
3. 龙头带动：
   - 链内 ≥2 个子方向同时动；
   - 龙头/核心必须强于板块；
4. 风向标开关：
   - 只做 **方向级 kill switch**；
   - dead → 方向不做；
   - alive/warning → 方向可做，但买什么由票层决定；
5. 产出：
   - `jobs/direction_pool.py`
   - `data/direction/pool_daily.csv`
   - `docs/direction-pool-spec.md`

验收：

```text
池构成随 2025/2026 主线变化
2025/2026 分年方向一致
不用语料也能复现
```

---

### Phase 3：票层（2 周）

**目标**：只买龙头/核心/老龙头/龙2，绝不后排。

任务：

1. 角色识别：
   - 龙头：强于板块、板块强于大盘、市值/成交/辨识度；
   - 核心：市值前 5 + 产业绑定 + 业绩；
   - 老龙头：历史领涨/历史成交/概念记忆；
   - 龙2：龙一之外最强辨识度；
2. 选票：
   - 先角色，后强度；
   - 禁止 `bucket=second` 直接当补涨；
   - 低位补涨 = 低位老龙头，不是低位杂毛；
3. 对照实验：
   - A：现行 `stage×role`
   - B：角色过滤（无后排）
   - C：角色 + 方向池
4. 产出：
   - `jobs/select_by_role.py`
   - `data/select/role_picks.csv`
   - `docs/role-selection-spec.md`

验收：

```text
后排违规率 = 0（或可解释）
角色识别可复算
A/B/C 差异可解释
```

---

### Phase 4：仓位与组合层（1 周）

**目标**：仓位由市况/风险决定，不由风向标乘数决定。

任务：

1. 市况档位：
   - 主升：75%+
   - 调整：50%
   - 有风险：30%
   - 下跌：0
2. 利润垫：
   - 有利润垫才允许更高仓位；
3. 组合：
   - 按股票去重；
   - 按主题簇限暴露；
   - 单票/单主题风险预算；
4. 删除：
   - `position_multiplier`
   - 用 warning=0.5/dead=0.25 调仓
5. 产出：
   - `jobs/position_regime.py`
   - `docs/position-regime-spec.md`

验收：

```text
同一批 picks 不因 warning/dead 被乘数化
仓位只由市况+风险预算决定
组合重复暴露有上限
```

---

### Phase 5：买点/节奏/止损层（1–2 周）

**目标**：把“什么时候买、什么时候卖”补上。

任务：

1. 时间窗：
   - 9:45–10:00、14:00–14:30；
   - 14:45 后禁新开；
2. 买点：
   - 挂前一天低点；
   - 0.618；
   - 急杀可买、缓跌不买；
   - 不追高；
   - 缩量止跌→放量突破；
3. 止损：
   - 13 日内跌破波段低点 -3% 未收回；
   - 13/34/60；
   - 收盘确认；
4. 兑现：
   - 3–5 个点；
   - 吃一口减一半；
   - 二次冲高缩量不过前高；
5. 数据限制：
   - 无分钟数据 → 时间窗只能 shadow，不能回测；
   - 日线只能验证结构/止损，不验证分时。
6. 产出：
   - `jobs/entry_exit_rules.py`
   - `docs/entry-exit-spec.md`

验收：

```text
买点/止损/兑现规则可执行
时间窗标明“仅 shadow”
不把日线当分时
```

---

### Phase 6：分层验证与影子（2–4 周）

**目标**：不是验证“风向标 alpha”，是验证五层合起来是否比现行好。

任务：

1. 层级消融：
   - L0：现行
   - L1：+方向池
   - L2：+角色（无后排）
   - L3：+仓位档位
   - L4：+买点/止损
2. 指标：
   - 3/5 日收益；
   - 最大回撤/尾部；
   - 换手/交易成本；
   - 合规（后排=0、dead 不做、高切低仅允许场景）；
3. 统计：
   - 块状 bootstrap；
   - 分年/分市场状态；
   - 防止多重检验；
4. 影子：
   - 不接实盘；
   - 记录每日 picks/角色/仓位/理由；
5. 产出：
   - `docs/layer-ablation-report.md`
   - `data/validation/`
6. 验收：
   - 至少 L2/L3 有稳定改善；
   - 不是靠单一层/单一年份；
   - 回撤不恶化。

## 4. AI 的位置

AI 只做 **角色/状态裁判**：

```text
风向标是否还活着
龙头是否换人
核心是否绑定
后排是否排除
```

不做：

```text
选股排序
仓位
收益预测
自动下单
```

约束：

- as-of 输入；
- 证据引用；
- prompt/model 版本化；
- 与机械状态分歧记录；
- 失败回退机械；
- 不接 gate 直到分层验证通过。

## 5. 明确不做

```text
❌ 继续调 dead 阈值
❌ 继续比 AI/机械一致率
❌ 用 5/20 日均值证明风向标 alpha
❌ 给每只 pick 挂 state/multiplier
❌ 用 2024 当前成员伪造 PIT
❌ 在 36 个 case 上过拟合
❌ 把 warning 当 dead
❌ 把 all second 当补涨
```

## 6. 关键风险

| 风险 | 应对 |
|---|---|
| 角色识别仍不准 | 先审计，再换规则；不直接上线 |
| PIT 样本不足 | 只做 2025-2026；不伪造 2024 |
| 无分钟数据 | 时间窗只 shadow，不假装可回测 |
| 过拟合 | 预注册假设、分年、块状 bootstrap |
| 组合集中 | 去重/主题上限 |
| AI 不稳定 | 只裁判、证据、回退 |
| 生产事故 | 开关默认关、模拟盘、回滚 |

## 7. 成功定义（DoD）

```text
1. 后排违规率可解释/接近 0
2. 方向池跨 2025/2026 成立
3. 仓位由市况档位决定，不由风向标
4. 买点/止损/兑现可执行
5. 分层消融显示 L2/L3 稳定改善
6. 影子期无重大偏差
7. 任一开关可回退
```

## 8. 最先做的三件事

```text
1. Phase 0 审计：当前 picks 到底有多少后排/重复
2. Phase 1 角色表：把风向标/龙头/核心/老龙头/龙2 分开
3. Phase 2 方向池：先决定做哪里，再决定买哪只
```

一句话：

> **先审计“票层”是否买错，再重建“方向→角色→仓位→买点”的五层漏斗；风向标只做方向开关，AI 只做角色裁判。**
