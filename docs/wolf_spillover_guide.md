# 外溢题材发现指引（不指向具体板块）

> 只给方法，不给答案。  
> 目标：从源题材高潮出发，自己找出“外溢目标”，而不是找“最相似的板块”。


## 0. 目标函数：找源题材高潮后的延伸方向

不是找：

```text
今天最强的新题材
今天涨停最多的新题材
今天封板最早的新题材
```

而是找：

```text
源题材高潮后
资金沿什么能力/产业/叙事向外延伸
```

### 延伸方向的三类

1. 能力延伸：源题材的核心能力，能用到另一个终端市场。
2. 产业延伸：上下游相邻，但不是同一批票的补涨。
3. 叙事延伸：政策/新闻/资金偏好，把源题材的逻辑映射到新方向。

### 不是延伸

- 同一终端、同一批票：补涨。
- 只是概念标签重叠：伪延伸。
- 主线下跌板块反弹：补跌，不是延伸。

### 评分

```text
extension_fit =
  capability_transfer
  + different_end_market
  + low_position
  + first_day
  + new_funds
  + catalyst
  - same_chain
  - mainline_down
```

`extension_fit` 优先于“当日强度”。

## 1. 先确认源题材高潮

必须同时有：

- 涨停家数多；
- 后排补涨；
- 炸板增加；
- 无晋级/二板少；
- 龙头加速；
- 成交额放大；
- 源题材内已没有低位。

不是“涨得多”，是“容纳不下资金”。

## 2. 候选池不能只看 facts 里的题材

必须从全市场概念表扫描：

- 每个概念的 10/28 等权收益、breadth、涨停数、龙头；
- 概念成员；
- 与源题材成员的重叠。

候选池 = 全市场概念，不是现有 8 个题材。

## 3. 重叠不是否决，关键看重叠票的位置

重叠可以是坏事，也可以是桥梁。

### 坏的重叠：源内高位补涨

- 重叠票是源题材高位龙头；
- 已经 3–5 板/加速；
- 只是换概念标签；
- 没有新资金；
- 这种是补涨，不是外溢。

### 好的重叠：低位双属性桥梁

- 重叠票是低位/首日；
- 主属性属于目标题材；
- 不是源题材高位龙头；
- 有新资金；
- 这种重叠恰恰是外溢桥梁。

所以：

```text
有重叠 ≠ 不能做
重叠票是源内高位 → 补涨
重叠票是低位双属性 → 可以外溢
```

不要因为 overlap>0 就直接否掉目标。

判断重叠质量：

```text
overlap_quality = low_position + new_face + main_attribute
```

不是只看 overlap 数量。

## 4. 目标必须满足“第一天”

“第一天”不是“昨天没有涨停”，也不是“只看昨天一天”。

错误定义：

```text
昨天有 1-2 家孤立涨停 → 不是首日
昨天 breadth 低 → 今天是首日
```

正确“第一天”：

```text
过去 5–10 个交易日
没有出现过板块级联动
今天第一次出现板块级同步
```

必须看回看窗口：

- `prior_breadth_5d`：过去 5 日平均 breadth；
- `prior_limit_5d`：过去 5 日平均涨停数；
- `breadth_jump`：今天 breadth - 过去 5 日；
- `limit_today`：今天涨停数；
- 不是只看今天 breadth 高不高。

区分：

```text
edge / 首日：
  prior_limit_5d <= 1
  limit_today >= 3
  breadth_jump > 0.2
  → 从冷到热

late / 扩散：
  prior_limit_5d >= 3
  breadth 已经高
  → 已经启动过，不算边缘
```

高 breadth 但 prior_limit 也高 = 扩散/补涨，不是边缘。
- 如果 5–10 天内已经启动过一次，
  今天再启动 = 二次启动/回踩再起，不是第一天。

判错例子：

```text
10/23 已经 breadth 0.94、6 家涨停
10/26–27 回踩
10/28 再 breadth 0.92、9 家涨停
→ 10/28 不是第一天，是二波
```

只有过去 5–10 天都没有板块级联动，
今天才叫第一天。

如果之前启动过、回踩后再起：

```text
标记为 second_wave
不是 first_day
```

硬规则：

```text
prior_launch_days 非空
→ first_day_absolute = false
→ 直接 reject
→ picks 不能包含
→ 不是降仓，不是二波观察
```

必须运行：

```bash
python scripts/validate_first_day.py --target <目标概念>
```

退出码 2 = 二波，禁止选。

高 overlap + 之前已启动 = 相邻二波，不是首日外溢。

举例（仅作定义说明）：

```text
某题材 10/27：ret1 -4%，breadth 0，avoid
→ 没有板块级启动
10/28：5 家涨停，breadth 0.867
→ 这才是第一天
```

孤立涨停不算启动；板块级同步才算。

### 晚封不是否决

13:00–14:00 才封，是弱证据，不是硬否决。

看：

- 是不是第一天；
- 封板后有没有量；
- 次日能不能确认；
- 龙头/中军是否同步。

第一天可以晚封；不能因为“封得晚”直接否掉整个目标。

## 5. 目标必须在低位

看：

- ret5/ret20 不在高位；
- 距 20 日高点有空间；
- winner_rate 不过高；
- price_vs_cost85 不深；
- 不是已经连续加速。

源题材高潮 + 目标也高位 = 不是外溢，是双高潮。

## 6. 目标龙头必须先动

目标概念里必须有：

- 最早封板/最先转强的龙头；
- 或至少一只 10CM 中军先动；
- 不是全板块无涨停、只有跟涨。

如果龙头没动：

```text
只有相关性，没有资金
不是外溢
```

## 7. 目标要有独立资金

看：

- 目标概念成交额放大；
- 目标涨停家数从 0→有；
- 目标龙头不是源题材的同一批高位票；
- 目标概念里出现新面孔/首板；
- 不是源题材后排的重复计票。

注意：

```text
独立资金 ≠ 0 重叠
```

可以是：

```text
双属性票 + 新资金
```

不要求和源题材完全无关。

不能因为 overlap>0 就判“没有独立资金”。

## 8. 候选打分

不要只算 overlap。

每个候选概念打：

```text
source_climax        源题材是否高潮
cross_chain          非同链/非同产业链
overlap_quality      重叠票是低位双属性，还是源内高位
first_day            是否首次联动
low_position         是否低位
leader_turn          目标龙头是否先动
independent_flow     是否有独立资金
overhang_light       套牢是否轻
```

规则：

- 同链且重叠最高 → 降级为补涨；
- 跨链、首日、低位、龙头先动 → 外溢候选；
- 只有 overlap、没有 first_day/leader_turn → 不做。

## 9. 最终选择

优先级：

```text
first_day + leader_turn + low_position
> overlap 最大
```

如果两个候选：

```text
A：重叠 0.54，但同链、已跟涨、无首日
B：重叠 0.20，但跨链、首日、龙头先动、低位
```

选 B，不是 A。

## 10. 输出

必须写清楚：

- 源题材是谁；
- 为什么是高潮；
- 目标是谁；
- 为什么不是同链补涨；
- 目标是不是第一天；
- 目标龙头是谁；
- 资金/涨停/量能证据；
- 失败条件。

## 10.5 硬校验：overlap 必须由程序算

外溢目标不能由 agent 自己写 overlap。

必须运行：

```bash
python scripts/validate_spillover.py --source 人形机器人,减速器,机器人执行器 --target <目标概念>
```

规则：

```text
overlap_n >= 1 才允许叫外溢
overlap_n == 0 → label = independent_first_day
```

即：

```text
0 重叠 = 独立首日/轮动
不是外溢
```

agent 输出中如果写了 overlap，但程序算出来是 0：

```text
直接判 invalid
不能选
```

## 10.6 没有合规外溢就空仓

如果所有候选出现以下任一情况：

```text
overlap_n = 0
is_spillover = false
label = independent_first_day
只有同链补涨
只有主线下跌反弹
没有龙头先动
```

则本次外溢任务输出：

```text
picks = []
```

禁止用“独立首日”“轮动”“补涨”硬补一个仓位。

独立首日只能进另一个 sleeve，不能冒充外溢。

## 11. 禁止

- 不许按 overlap 最大直接选；
- 不许把同链补涨当外溢；
- 不许把 0 重叠的独立首日当外溢；
- 没有合规外溢时不许硬选，必须空仓；
- 不许选已经高位/连续加速的目标；
- 不许选没有龙头、没有涨停、没有放量的“相关板块”；
- 不许引用后续结果或判例。
