# 风向标 PIT 验收：合规 + 风险口径

> 2026-10-22；65 个 PIT 日期，1,645 个 picks。  
> 收益不再作为主验收。

## 1. 合规

| 项 | 实际 | 目标 |
|---|---:|---:|
| dead + second | **2** | 0 |
| warning + second | **595** | 0（“warning 不新做二线”） |
| dead/warning 后上涨 | 383 / 747 | 误杀率需可接受 |

结论：**合规不通过。**  
当前只是软 overlay（改仓位），没有真正阻止 warning/dead 下的二线选股。

## 2. 风险

| 组 | 均值 | 波动 | 下行波动 | 最大回撤 |
|---|---:|---:|---:|---:|
| A rule | +2.40% | 5.98% | 3.06% | -27.24% |
| B overlay | +2.52% | 6.17% | 3.31% | **-29.08%** |
| C theme_eq | +1.74% | 7.30% | 4.74% | -43.14% |

B 的收益略高，但：

- 波动更大；
- 下行波动更大；
- 最大回撤更深。

结论：**按风险口径，overlay 不通过。**

## 3. 收益（仅参考）

## 4. 结论

```text
合规     ❌ warning/dead 下仍有大量 second
风险     ❌ B 回撤/波动均劣于 A
收益     ⚠️ 不显著，仅参考
```

当前 overlay 只能算“权重标注”，不能算风控闸。

## 5. 下一步

1. 若目标是“warning/dead 不新做二线”，必须做**硬过滤**，不是乘数；
2. 若目标是“降风险”，要重新设计 overlay（例如直接降暴露/对冲），不是给每只票乘 0.5；
3. 修正 PIT 固定龙头/前视后重跑；
4. 通过合规和风险后，才谈收益。
