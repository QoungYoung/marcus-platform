## 一、策略概述

黄金坑策略是基于 ArkVol 贪婪指数的宽基 ETF 抄底策略。当指数贪婪值跌破阈值（P10 百分位附近）触发入场信号，等待连续回升确认拐点后进入买入窗口，按分层仓位金字塔式加仓，在贪婪值回升到退出百分位时止盈离场。

### 核心参数

| 参数 | 说明 |
|------|------|
| 入场阈值 | 各指数独立的固定贪婪值阈值（0.328 ~ 0.512） |
| 拐点确认 | 贪婪值连续 0 日回升（同日入场最优） |
| DCA 策略 | 大多数采用 lump_entry（一次性建仓） |
| 退出方式 | staged（分批）/ full_only（全量）/ trailing_stop / fixed_hold |
| 回撤兜底 | 20 日未达退出条件则强制平仓 |

### 指标说明

| 指标 | 计算方式 |
|------|---------|
| **原始年化 (raw CAGR)** | 每笔交易独立复利：`Π(1+return_i)^(252/calendar_span) - 1` |
| **调整年化 (adjCAGR)** | 资金池模型：总收益 ÷ 最大并发仓位，再年化。更贴近实盘（共用资金池，不复利加仓） |
| **Sharpe** | 按笔计算：`(mean/std) × sqrt(年交易数)` |
| **最大回撤** | 单笔最差收益 |
| **盈亏比** | 盈利总和 ÷ |亏损总和| |

## 七、关键结论

1. **组合收益**：等权组合调整年化 **16.61%**，按实盘权重加权约 **19.89%**，在 A 股/跨境 ETF 策略中属于优秀水平。

2. **风险收益比**：中证500 和科创50 是 Sharpe 比率和胜率综合最优的选择（Sharpe 1.6-2.0，胜率 72-73%）。中证1000 年化最高但胜率不足 50%，波动大。

3. **年度特征**：2023 年是策略小年，多数 A 股指数的年度收益为负或微利（震荡市频繁触发入场但反弹不及预期）。2024 年是大年，科创板/创业板年度收益超过 200%。

4. **海外 vs A 股**：纳斯达克、道琼斯胜率最高（79-89%），Sharpe 达 2.0-3.5，但回测数据较短（2025 年起）。A 股指数中 2022 和 2024 年收益集中爆发。

5. **最优退出方式**：A 股指数偏好 `full_only`（一次清仓）或 `staged`（分两批），固定百分位退出（40-80 百分位），配合 20 日兜底。海外指数偏好 `fixed_hold`（固定持有天数）。

6. **上证50 不可用**：调整年化仅 5.15%，已被策略剔除（tier=drop, weight=0%），与其大盘价值风格不适用贪婪恐慌抄底逻辑一致。
