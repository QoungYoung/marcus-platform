## 质询一回复：推理时间点与特征滞后

### 承认

专家指出了一个文档描述上的严重歧义。当前方案中，特征推导使用了"当日"数据（`change_pct`、`turnover_rate`、`vol_ratio_1d`），但没有明确说明推理执行时间。

### 澄清

模型的**正确推理时间点是每个交易日 15:01（收盘后）**。此时 T 日的所有量价数据（收盘价、成交量、换手率）已完整可得。模型输入 T 日完整特征，输出 T+1 日（明天）的预期收益率。训练目标 `(T+1收盘 - T收盘) / T收盘` 与推理完全对齐，**不存在未来函数问题**。

### 但是——专家的核心关切仍然有效

即使用 15:01 推理，存在两个实盘问题：

**问题 A：T 日收盘价 → T+1 开盘价的隔夜跳空**

模型预测的是 T 收盘 → T+1 收盘的收益。但实盘买入价是 T+1 的**开盘价**（甚至盘中价），不是 T 日收盘价。如果出现隔夜利空跳空低开，模型预测 +2% 但开盘已低开 -3%，全天反弹 +2% 收在 T 日收盘价附近——模型判断"涨了"（正确），但你实际亏损（开盘买入）。

**问题 B：部分特征在盘前不可验证**

即使模型在 15:01 跑，`big_order_net`（当日主力净流入）的数据源 East Money 在收盘后可能尚未更新完毕，存在数据到达延迟。

### 修正方案

**采纳专家建议，将所有个股权重特征统一滞后 1 天：**

| 特征 | 当前 (有歧义) | 修正后 |
|------|-------------|--------|
| `change_pct` | T日涨跌幅 | **T-1日涨跌幅** |
| `turnover_rate` | T日换手率 | **T-1日换手率** |
| `vol_ratio_1d` | T日量/20日均量 | **T-1日量/20日均量** |
| `vol_ratio_5d` | 近5日均量/20日均量 | **(T-5~T-1)均量/20日均量** |
| `gap_up_pct` | T日开盘-T-1日收盘 | **T-1日开盘-T-2日收盘** |
| `consecutive_up/down` | 截至T日的连涨连跌 | **截至T-1日的连涨连跌** |
| `big_order_net` | T日主力净流入 | **T-1日主力净流入** |
| `ret_5d` | T-5→T收益率 | **T-6→T-1收益率** |
| `rsi6/rsi14` | 截至T日 | **截至T-1日** |
| `ma20_deviation` | T日收盘偏离MA20 | **T-1日收盘偏离MA20** |

滞后后，训练目标相应调整为 `(T收盘 - T-1收盘) / T-1收盘` ——逻辑完全自洽：**已知 T-1 日特征，预测 T 日收益**。

实盘运行：每天 15:01 跑模型，用当天刚收盘的数据作为特征，预测明天，盘前 9:00 出信号，用户在 9:25 集合竞价或 9:30 开盘买入。**消除了所有未来函数嫌疑和盘中数据不完整问题。**

## 质询二回复：市场级常数列特征的处理

### 承认

专家的分析从单日截面角度看完全正确——同一天内这 9 个特征对所有股票取值相同，XGBoost 在单个树节点中无法用它们区分样本。

但在 120 天的训练批次中，跨日方差存在。树模型可以在根节点附近用 `up_ratio > 0.6` 将 120 天中"普涨日"和"普跌日"的样本分到不同子树，从而实现择时效果。这不是"理论幻觉"——实际上 v1 模型的特征重要性中，INDEX_COLS 占了 40-50%。

### 但专家关于列采样的批评是正确的

`colsample_bytree=0.8` 意味着每棵树随机选择 80% 的特征列。9/35 = 26% 的无效截面特征确实会稀释有效个股特征的采样概率。每棵树有 26% 的概率"浪费"采样配额在无截面区分能力的特征上。

### 修正方案

**采纳专家建议，将市场级特征从模型中剥离：**

1. **从 XGBoost 特征集中移除全部 `MARKET_COLS` (6维) 和 `INDEX_COLS` (3维)**
2. 模型专注于纯截面排序（28 维：19 个股 + 7 行业 + 2 保留）
3. **另建独立的轻量择时模块**：用上证指数 ADX/MA（已在 leaderboard 中实现）判断市场状态，对模型输出的预期收益率做后处理乘法缩放：

```
final_score = expected_return × regime_multiplier
  trending:   multiplier = 1.0    (趋势市，充分参与)
  ranging:    multiplier = 0.7    (震荡市，降低敞口)
  transitional: multiplier = 0.5  (过渡市，保守)
```

这个 multiplier 的数值仍需回测确定，但架构上解决了特征污染问题。

### 消融实验计划

| 实验 | 特征集 | 预期结果 |
|------|--------|---------|
| A (当前) | 35维全量 | 基线 |
| B | 移除9维市场级 (26维) | Spearman R 持平或略升 |
| C | 仅19维个股 (19维) | 行业轮动信号丢失，R下降 |

如果 B 的 Spearman R ≥ A，则证明专家判断正确——9 维常数特征纯属噪声。

## 质询三回复：回归目标在涨跌停截断下的合理性

### 部分承认

专家的批评在以下场景成立：如果训练数据中有大量连续涨跌停样本（如 ST 股炒作期），MSE 确实会被极端值主导。

### 但存在重要反论

**反论 1：龙头股涨跌停频率远低于全市场**

行业市值 Top 3 的股票（如茅台、宁德、比亚迪），连续一字板涨停/跌停是罕见事件。在 500 天 × 330 只龙头 ≈ 16.5 万样本中，涨跌停样本占比预估 < 2%。MSE 对 2% 极端值的敏感度有限。

**反论 2：LambdaMART/RankNet 在实践中并非银弹**

- LambdaMART 需要 pairwise 标签，将 N 只股票扩展为 O(N²) 个股票对，训练成本呈平方增长。330 只股票 → 5.4 万个 pair/天 → 500 天 = 2700 万 pair，训练时间从分钟级变为小时级。
- A 股中，相邻排名的两只股票收益率差异可能仅 0.01%，将这种"噪声相邻"强制建模为 A > B 的偏好关系，反而引入大量伪标签。
- 回归模型在实践中有良好的排序性质（Spearman R 本身就是排序指标），因为单调的预测函数天然产生排序。

### 修正方案

**双管齐下，而非推翻重来：**

1. **对目标 y 做 Winsorize（1%/99% 分位数缩尾）**：将涨跌停极端值截断到 ±10%（主板）或 ±20%（双创），消除 MSE 的长尾放大效应。

```python
from scipy.stats.mstats import winsorize
y_winsor = winsorize(y, limits=(0.01, 0.01))
```

2. **增加 Rank-Gaussian 标准化作为对比实验**：

```python
from scipy.stats import rankdata, norm
ranked = rankdata(y) / (len(y) + 1)
y_normal = norm.ppf(ranked.clip(0.001, 0.999))
```

在两个版本上分别训练，比较 Spearman R 和 Top-10 方向准确率，择优选用。

3. **坚持回归而非排序模型**——理由：回归输出 `expected_return` 有直接的物理含义（预期涨几个点），对交易员可解释、可校准、可用作仓位权重。LambdaMART 输出的 score 没有量纲，难以与其他信号融合。

## 质询四回复：资金流向降级逻辑的数学荒谬性

### 完全承认

专家对"成交额 × 涨跌幅"的批评**完全正确**。这个公式在逻辑上有根本缺陷：

- 高开低走（+2% + 巨量）→ 公式输出正，实际主力出货 → **反向**
- 低开高走（-1% + 巨量）→ 公式输出负，实际主力吸筹 → **反向**

用这个代理信号训练出的模型，学习的是"涨的股票有大单流入"的同义反复（tautology），而不是真实的资金流逻辑。实盘中如果 East Money 和 Tushare 同时挂了，fallback 到这里，预测会彻底随机。

### 修正方案

**完全剔除资金流维度的 fallback，改为缺失值策略：**

```
资金流数据获取策略（修正后）:

实时模式:
  1. East Money 成功 → 使用真实主力净额
  2. East Money 失败 → big_order_net = 0, main_force_ratio = 0, 
     flow_5d_cum = 0, 并设置 moneyflow.available = False
     (模型学习到资金流数据缺失也是一个信号)

历史模式:
  1. Tushare moneyflow_dc 成功 → 使用大单净额
  2. Tushare 失败 → 同上，全部填 0 + available = False
```

**移除 `_moneyflow_fallback` 函数**。0 填充比错误填充好——至少不会引入虚假相关性。

### Level2 数据的考虑

专家提到 Level2 逐笔成交的大单统计。当前数据源（East Money `f137` 主力净额）本质上就是 Level2 的聚合结果，只是粒度更粗。暂时保持 East Money → Tushare → 0 的降级链，0 填充时 `available=False` 让模型能区分"资金流看空"和"资金流缺失"。

## 质询五回复：固定 120 天窗口的策略鲁棒性

### 承认

120 天没有经过严格的超参敏感性分析。选择依据是：A 股一个完整的"情绪周期"（恐惧→怀疑→乐观→狂热→恐惧）大约 4-6 个月，120 个交易日 ≈ 6 个日历月，刚好覆盖一个完整周期。

专家指出的风格切换拐点问题确实存在——如果模型恰好训练在"旧趋势的尾端 + 新趋势的开端"，120 天的样本混合了两个统计分布不同的阶段。

### 修正方案

**1. 窗口长度敏感性分析**

在 Walk-Forward 验证中，分别测试 60/120/180/250 天的窗口，比较 Spearman R 的均值和稳定性：

```python
for train_days in [60, 120, 180, 250]:
    svc.train_walk_forward(data_path, train_days=train_days, step=10)
```

如果 60 天窗口的 Spearman R 波动率显著高于 120 天，说明短窗口过拟合噪声；如果 250 天窗口的 Spearman R 均值低于 120 天，说明长窗口包含殭尸信息。

**2. Spearman R 转负时的熔断机制**

在 Walk-Forward 验证报告中，追踪每个窗口的 Spearman R。如果连续 2 个窗口（20 天）的 Spearman R < 0：

```
触发熔断 → 模型暂停预测 → 回退到等权持有或空仓 → 
触发重新训练（用最近 60 天数据） → Spearman R 恢复正值 → 恢复预测
```

这个熔断逻辑编码为 `DirectionPredictionService` 的 `health_check()` 方法。

**3. 在线自适应窗口**

不固定窗口长度，而是根据最近的市场波动率（VIX 代理 = 上证 20 日振幅）动态调整：

```
高波动期 (振幅 > 3%): train_days = 60  (快速遗忘旧模式)
正常期:              train_days = 120
低波动期 (振幅 < 1%): train_days = 180 (需要更多数据提取微弱信号)
```

## 质询六回复：交易成本与净收益验证

### 完全承认

当前 Walk-Forward 评估**没有扣除交易成本**，所有指标（RMSE、Spearman R、方向准确率）都是"毛收益"口径。这在实盘中是致命的——一个毛收益 +0.5% 的策略在扣除 0.18% 双边成本后只剩 +0.32%，月换手 2 次就只剩 +0.14%。

### 成本建模

A 股实际交易摩擦：

| 成本项 | 费率 | 说明 |
|--------|------|------|
| 印花税 | 0.05% 单边（卖出） | 国家收取，不可避免 |
| 佣金 | 0.015%~0.03% 双边 | 按万1.5计算 |
| 滑点 | 0.05%~0.1% 单边 | 龙头股流动性好，取0.05% |
| **单次完整换手** | **≈0.18%** | (买入佣金+滑点) + (卖出佣金+滑点+印花税) |

### 修正方案

在 Walk-Forward 评估中增加扣除成本后的净收益指标：

```python
def net_return(predicted_return, turnover_rate_annual=24):
    """
    predicted_return: 模型预测的毛收益率 (%)
    turnover_rate_annual: 年化换手次数 (5日换手 ≈ 48次/年)
    """
    cost_per_trade = 0.18  # %
    return predicted_return - cost_per_trade

# Walk-Forward 每个窗口报告：
# - 毛收益 Top-10 组合均值
# - 净收益 Top-10 组合均值（扣除成本后）
# - Sharpe ratio (基于净收益)
# - 盈亏比
```

**净收益为正才是模型上实盘的门槛条件**。如果 38 个窗口中净收益均值 < 0 的窗口超过 30%，模型不能上线。

### 关于 Spearman R = 0.05 的实盘可行性

专家的算术是对的。但有一个重要的对冲视角：

**模型输出的 Top 10 vs Bottom 10 的收益差**才是真正的 alpha，而非 Top 10 vs 基准的差异。如果 Spearman R = 0.05，Top 10 均值 vs Bottom 10 均值的差异约为 0.3-0.5%/5日（取决于截面的收益离散度），扣除 0.18% 成本后仍有正期望。做多 Top 10 + 做空 Bottom 10（或等额做多指数对冲 → 纯 Alpha）的净收益才是有意义的评估口径。

### 修正后的评估报告格式

```
Window 2026-06-01 ~ 2026-06-10 (5d horizon):
  Spearman R: 0.047
  Top-10 mean return: +1.85% (gross) / +1.67% (net)
  Bottom-10 mean return: -1.12%
  Long-Short spread: +2.97% (gross) / +2.61% (net)
  Direction accuracy (Top-10): 58.3%
  Max drawdown (Top-10): -3.2%
```
