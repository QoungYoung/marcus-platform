## 结论

1. **同日对齐率很低：24 只代理中只有 1 只(E12 002371)与狼大低吸日同日触发 254**。狼大“低吸”不是只等“触前日低点+缩量”这一种盘口事件，多数日期是逻辑/分步加仓。
2. **当 254 真在同日触发时，收益完全一致**（E12 002371 T+5 = +10.58%），说明通道本身与狼大打法同构。
3. 狼大买后 5 日不一定赢：E06 三只 AI硬 T+5 全负（-4.65 均值），系统若提前 2-5 天触发也亏（-4.48），说明 E06 是左侧接刀，不是稳定正收益。
4. 系统 254 触发经常比狼大早/晚 3-10 天；若只拿“附近最低吸”来比，两者进的是同一波低位区间，收益差异主要来自入场日期错位，不是策略好坏。
5. **局限**：v0 用日线粗代理 254（非 5min 实时量比）；ETF(E08) 未直接回测；代理股票不等于狼大实际持仓；n 极小，结论仅方向性。
