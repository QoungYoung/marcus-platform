# T1缩转放 护栏复测报告（5min指数, 184天, 2026-09-02）

> 背景：用户问"缩转放/分时T出与价格无关只与形态相关吗" → 确认 T1 是纯量能形态、T出是量能+相对价格结构后，建议给 T1 叠加企稳/价位护栏复测。本报告为复测结果。

## 1. 复测设计

- 数据：data/index_5min_dh.json（datahubco 5min，指数 000001.SH，184 天，2025-12-01~2026-09-01，每天 49 根）+ index_daily_000001.json（日线）
- 口径：**盘中逐 bar 扫描**（对齐生产实时判定——收盘后全天数据会把最后一根固定为 15:00 缩量 bar 导致 0 触发，必须先反转时间序再逐 bar 判）
- 信号：生产同款 T1（近8根缩量[末端≤起点] + 当前 bar 放量 > 前8均量×1.2），首次命中即当日触发
- 护栏变体：V1 企稳(触发价距日低+0.5%) / V2 回调(触发价距日高-1%) / V3 跌势(触发<前收) / V4 组合
- 前向收益：从当日收盘算 1/3/5 日

## 2. 关键发现①：生产 T1 在指数上 91% 命中午休伪信号

触发时点分布（184 天，mult=1.2）：

| 时点 | 次数 |
|---|---|
| **13:05（午休后第一根）** | **167（91%）** |
| 14:35（尾盘放量段） | 31 |
| 其余时段 | ~30 零星 |

原因：13:05 bar 成交量是 11:25 的 **1.5~2.3 倍**（午休后资金进场天然放量）+ 午前尾盘（11:20-11:30）自然缩量 → 完美构成"缩转放"假信号。**A股午休效应**，个股同样存在（午休后开盘放量是普遍规律）。

## 3. 关键发现②：护栏变体分半验证不稳健

| 变体 | 全部(184天) | 前92天 | 后92天 |
|---|---|---|---|
| V0 基线 1.2×全时点（173次） | 5日 +0.08% hit0.56 | — | — |
| V5 排除效应 1.2×（107次） | 3日 +0.19% hit0.60 | 3日 +0.41% hit0.76 | 3日 +0.03% hit0.50 |
| 1.4× 排除（34次） | 3日 +0.26% hit0.74 | 3日 **+0.73% hit0.90** | 3日 **-0.49% hit0.46** |
| 1.5× 排除（15次） | 3日 +0.71% hit0.80 | 3日 +1.01% hit0.91 | 4次样本不足 |
| V7 排除+回调（19次） | 3日 +0.37% hit0.58 | — | — |
| V8 排除+跌势（47次） | 3日 +0.13% hit0.60 | — | — |
| 无信号（6次） | 5日 -0.52% hit0.33 | — | — |

**结论：前段（2025-12~2026-04）信号有效（1.4× 3日+0.73% hit0.90），后段（2026-05~2026-09）失效甚至负收益（-0.49%）→ 指数级缩转放是市场状态依赖的，不能据此调生产参数。**

## 4. 明确结论

1. **生产 T1（1.2× 全时点）在指数上基本是午休/尾盘效应伪信号**，5日 +0.08% ≈ 无预测力。排除 13:05/09:30/09:35 结构效应是**确定性修复**（与个股指数无关，A股普遍规律）。
2. **护栏参数（阈值/企稳/回调/跌势）样本内有效、样本外不稳**——184 天指数样本不足以定参，且有明显的市场状态依赖。
3. **个股验证受限**：datahubco stk_mins 限频 1次/小时，184 天个股 5min 无法快速补齐（需换通道或等限频窗口）。
4. **建议**：生产先落地"排除 09:30/09:35/13:05 结构效应"（不动阈值 1.2×），消除确定性伪信号；阈值收紧与个股验证待数据通道解锁后再做（避免过拟合）。
