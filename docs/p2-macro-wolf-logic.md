> 结论：Wolf 不是“看宏观点位做交易”，而是把宏观/机构行为当 **4 类开关/环境过滤器**：崩盘清单、流动性开关、主线资金归属、政策日历。

## 1. Wolf 怎么使用这个模块（按语料组）

### 1.1 美联储/海外流动性（174 条）
**用法：定“钱从哪来 + 会不会反转”**
- 「这波全球 AI 牛市的最核心基础逻辑就是放水；通胀>9% → 公司被迫花钱/烧钱 → 钱最终流向金融市场」(2026-01-04)
- 「赌今晚美联储议息，如果降息，海外大反弹就能打断公墓滚雪球卖出」(2026-07-29)
- 「如果老美加息，多低都要清；唯一例外=我们逆周期降息」(2026-07-29)

→ 模块输出：海外利率政策状态(降息/观望/加息)、风险开关（加息→清仓档；降息→公募踩踏可能被外力打断）。

### 1.2 美债/30年国债（108 条）
**用法：放进“崩盘检查清单”，不作为买点**
- 「期指空单猛加了吗？30年债放量暴涨了吗？券商砸破位了吗？有什么迹象表明要崩了吗」(2026-01-12)
- 「三桶油跌→白线不准；看金融有没有对冲、30年有没有大变化，没有就看黄线操作」(2026-03-04)

→ 模块输出：30Y 放量暴涨/利率异动 = 风险确认信号；金融对冲状态辅助日内黄白线。

### 1.3 两融/杠杆（125 条）
**用法：看“热钱属性 + 顶部/爆仓风险”**
- 「两融只看有没有消息降温，没降温你怕什么；融资进场成本不比你的高」(2026-01-12)
- 「高位融资进来的钱出不去了，已经是基石；这些热钱容易追热点」(2026-01-14)
- 「融资盘爆仓状态 → 谨慎接盘，等国家队看用什么兜底、在哪里兜底」(2026-01-20)
- 「4-4 阶段=杀杠杆阶段；一个月 3WE 两融爆到 2WE 就不是市场行为能解释的了」(2026-07-23/28)

→ 模块输出：两融余额/变化/净买；热钱活跃度；爆仓风险档（爆仓→不接盘等 GJD 兜底）。

### 1.4 汇率/美元/黄金（归入美债/美元组 108 条）
**用法：管海外资产与黄金交易节奏，不是 A 股买点主输入**
- 「等美元指数回升再卖第二次黄金」(2026-01-28)
- 「美元上涨=川普打仗让新兴市场钱回流美元美债；原油逻辑等川普卖委内瑞拉油」(2026-03-03)
- 处理国外资产时汇率升值会吃掉利润（2026-02-11/26）

→ 模块输出：美元指数/人民币汇率状态；影响黄金/石油等对冲仓（非 A 股主信号）。

### 1.5 北向/外资（94 条）
**用法：用“外资”解释资金增量归属（更多靠龙虎榜，不信日频北向）**
- 「国内模组爆发本质是海外资金买的，从龙虎榜能看出来；他们先跑时直接出场」(2026-05-09)
- 「外资一次按 10E 打进去，谁钱多谁说的算；他们跑，内资接不住」(2026-05-09)
- 「看明天外资上班后如何，内资做光存没那个格局」(2026-07-01)

→ 模块输出：外资增量方向(存储/光/海外链映射)；但 Wolf 用法是龙虎榜级验证，不是北向日频数值。

### 1.6 GJD/国家队（405 条，最高频）
**用法：护盘点位 + 政策底→市场底 + 决定是否抄底/做T**
- 「GJD只想把指数稳在3800，不涨也不跌，板块轮动收割」(2026-08-03)
- 「整个7月净流入各类宽基 4500E 以上，护盘的沪深300 与没护盘的光纤/存储差异明显」(2026-07-31)
- 「机构在测 GJD 保的位置：不是3950就试3900」(2026-08-11)
- 「GJD 政策底 → 市场底=机构重新调仓一致后才出」(2026-07-23)

→ 模块输出：GJD 宽基份额/净申赎、护盘点位地图(3800/3900/3950/4000)、政策底已出/市场底未确认。

### 1.7 政策/会议（119 条）
**用法：主题日历（埋伏提前量），会议确认前不乱动**
- 「埋伏十五五题材等开会后兑现的卫星/核聚变」(2026-03-03)
- 「等月底经济会议确认，现在只是猜想」(2026-07-28)
- 「十五五的都有，但别肉没吃到进去陪他们抗；过年期间会出穿越龙，航天可以」(2026-01-16)

→ 模块输出：政策事件日历(十五五/经济会议/业绩月/IPO潮)，事件前埋伏/事件后兑现。

### 1.8 机构行为（1579 条，最广）
**用法：判断谁在买/谁在卖（公募滚雪球、柚子、外资）**
- 「海外链最大问题是基金抱团拥挤；公墓破位只能靠政策/海外映射打断」(2026-07-29)
- 「机构吃了割肉的筹码，缩量拉起来→看你们追不追」(2026-08-04)
- 4-3/4-4 = 机构按业绩和指引调仓换股、公募体量主导 (2026-07-23)

→ 模块输出：公募/机构行为(拥挤+滚雪球风险)、调仓阶段(业绩后)、龙虎榜/席位验证。

## 2. Wolf 的用法总结（模块定位）

1. **不做“宏观择时大师”**：不靠 30Y 点位、美元指数做 A 股买卖点；用它们做**风险开关和背景**。
2. **真正影响买卖的宏观是两条链**：
   - 流动性链：美联储/放水 → 公募能否继续抱团/外资是否来；
   - 政策/护盘链：GJD 宽基份额/护盘点 → 政策底是否成立 → 才轮到机构调仓一致=市场底。
3. **崩盘检查清单**：期指空单猛加 + 30年债放量暴涨 + 高标板块爆 + 券商破位（任意多条件）→ 防守/清仓。
4. **两融 = 热钱属性**：融资冲高≠马上顶，只防“消息降温/爆仓”。
5. **外资/机构 = 用龙虎榜验证资金归属**，日频北向仅弱参考。
