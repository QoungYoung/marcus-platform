# 浪型链 golden set：用他自己的语料逐日打分（2026-10-15 首版）

> 为什么要这个：之前只有 **6 个手挑锚点**（03-23 / 04-09 / 07-31 / 08-05 / 08-19 / 10-09~14），样本太薄，
> 无法判断浪型链是「真对他的口径」还是「挑出来的巧合」。
> 公开的 A 股历史数浪**没有机器可读数据集**（见下「公开资料」），唯一带日期的标注就是他自己的发言。

## 1. 方法（可复核）

语料：`狼大回复汇总 20260814-1457&往期.xlsx`（8 个 sheet，25131 行有日期+正文）。脚本：
`jobs/eval_wave_ladder_vs_corpus.py`（抽取+漏斗）、`jobs/eval_wave_ladder_golden.py`（人工标注+评分）。

漏斗（每步都写死在脚本里）：

| 步骤 | 数量 | 说明 |
|---|---|---|
| 语料行（有日期+正文） | 25131 | 8 个 sheet |
| 剥掉 `[quote]…[/quote]` 后含浪型词 | 722 | 引用块是**提问者**的话，必须剥 |
| 带**指数语境**的显式级别词候选 | 60 | 命中词 ±40 字内要有 大盘/指数/上证/科创/双创/市场 |
| 人工标注（可比） | **6** | 只收**指数级且与我们的级别相同**的发言，并按「日 × 档位」去重 |
| 不可比/无断言 | 16 | 上一级（3-2/3-3/3-5）、板块级、或没有档位断言 |

## 2. 结果（按「日 × 他的档位」去重后）

- **结构档**：严格一致 **4/6 = 67%**、相邻一致 **5/6 = 83%**（相邻 = 差一档，同一段行情的不同读法）。
  ⚠️ **n 只有 6，只能当方向性结论**：他的同级、指数级、非条件句的发言本来就稀（60 条候选里 15 条是上一级、
- **操作档**：我们给出的 `operation` = `t_only` ×5 / `side` ×1，与他实际做法（「只做半导体 ETF 反抽」
  「按 4 接 5 做」）**同向 8/8** ✓；
- 唯一硬分歧：**2026-07-24** 他说「大盘走了完整 ABC…现在判断是转成**下跌5浪**级别」（= 结构转下），
  我们当时是 rung0「4 浪调整」✗ —— 但他随后 07-31~08-05 的做法是「只做半导体 ETF 反抽」= 我们
  rung0 的 `t_only` ✓ ⇒ **分歧在“标签”，不在“操作”**。

## 3. 已知局限（别过度解读）

1. **语料截止 2026-08-14**：他 2026-10 的词汇（「下跌1浪」「成功4-5」「大B浪反弹」）在语料里 **0 次**
   （普查：下跌1浪 0 / 主跌1浪 0 / 成功5 0 / 大B浪 0）⇒ 10 月那几个锚点只能取自帖子本身。
2. **他 2025 年用的是上一级**（2 浪/3 浪、3-2、3-3、3-5）：与本链建模的「主升 4 浪」不是同一级 ⇒ 标
   `not_comparable`（16 条里绝大多数属此类）。要用本链给 2025 打分，得先把**等级维度**扩到 3 浪族。
3. **误命中要防**：如「4-5 天最多」里的 `4-5` 是天数不是浪 ✗（脚本按指数语境过滤掉了一部分）。
4. **条件句不算状态**：「一旦资金测试成功 4-4 就能走出来了」是**场景**，已 skip ✓。

## 4. 公开资料（为什么不用）

- 静态全景划分（只可做年代级粗校验）：[上证指数 1990-2015 全景波浪划分](https://bbs.shudaoyoufang.com/thread-2635774-1-112.html)、
  [波浪理论在上证周线图的总体划分](https://www.renrendoc.com/free-down/8113115055000036.pdf)；
- 自动计数指标（可作第三方口径）：[EWCore](https://br.tradingview.com/script/dqzD2E1E-EWCore-Automated-Elliott-Wave-Counting-Labeling/)、[Waves Ultimate PRO](https://ar.tradingview.com/script/UEfVNKbB-Waves-Ultimate-PRO-v6/)；
- 通用 EW 数据集（非 A 股）：[EW_Dataset](https://github.com/A-J-Financial-Solutions/EW_Dataset)。
⇒ **没有**权威的、机器可读的「上证历史数浪」数据集；他的语料是唯一带日期的标注源 ✓。
