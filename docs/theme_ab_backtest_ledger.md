# 题材 A+B 回测账本规则

> 适用：10/23–11/04 新口径回测 / `data/backtest/ab_equity.json`

1. **首日空仓**：回测起始日 `20261023` 只观察，不买入；首日不参与。
2. **后续空仓 + A 不切**：有源 leader 时按下一交易日开盘买入源 leader，收盘计收益；无源 leader 则空仓。
3. **A 切 + B 有 target/leader + picks 非空**：按 B 的 leader 执行；`picks=[]` 视为不交易，必须空仓。
4. **A 切 + B 无合格 leader**：空仓，不用配套股/后排替补。
5. **收益口径**：信号日次日开盘买入、当日收盘卖出；不隔夜、不复利加仓。
6. **10/28 基线**：`target=商业航天`、`leader=600118.SH`、次日 `+10.47%`。
7. **白名单**：只做商业航天/机器人/贵金属/医药/AI应用；其他题材不进入 A/B 候选池。
