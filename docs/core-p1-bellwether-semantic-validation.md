# 风向标状态：语义案例校验

> 2026-10-21；按狼大原话校验“状态是否复现判断”，不看收益。

## 案例

| 日期 | 子主题 | 风向标 | 狼大态度 | 状态机 |
|---|---|---|---|---|
| 2026-01-12 | 卫星互联网 | 中国卫星 | 「风向标没有死」 → alive | **alive** ✅ |
| 2026-01-16 | 卫星互联网 | 中国卫星 | 周末说「先看风向」→ 不判死 | **warning** ✅（非 dead） |
| 2026-01-22 | 半导体设备 | 中科飞测 | 「先从风向标看起」→ 不判死 | **rotated** ✅（非 dead） |
| 2026-01-28 | 半导体设备 | 北方华创 | 「被压制……核心能不跌就不错，很强」→ 不判死 | **warning** ✅（非 dead） |
| 2026-07-02 | 光模块/CPO | 中际旭创 | 「等大哥表现」→ 不判死 | **rotated** ✅（非 dead） |

## 结果

- 5/5 都不违背“没有判死”的语义；
- 但只有 2026-01-12 判 `alive`，其余是 `warning/rotated`；
- 语义上“不判死”通过，不能说明“状态机认为强”。
- 没有一条真正的 `dead` 案例，所以 **dead 仍未验证**；
- `rotated` 在“不判死”上是对的，但不能说明能买。

## 关键发现

1. 状态机在“没死”的案例上基本能保持非 dead；
2. 无 impulse 时现在最多 carry 3 日，之后按上次 impulse 高点刷新：高点上方→alive，跌破 5%→warning，中间→stale；
3. 目前没有“狼大明确说死”的日期，因此 dead 分支无法做正例校验；
4. 不能再用收益反推权限；权限仍按语义定义。

## 下一步

1. 为 2026-01-28 这类“强但无 impulse”的案例增加“状态刷新”规则，不能无限 carry warning；
2. 从语料里继续找 `dead` 的正例；没有正例前，dead 只能作为保守默认；
3. 语义案例集扩到 2021/2022（需要历史数据/PIT 风向标）；
4. 语义通过后再做决策反事实，不拿状态预测收益。
