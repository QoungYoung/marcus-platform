## 2 三处结构性冲突（不是"缺参数"，是方向问题）

### C-1 「辨识度老龙头」被实现成了动量因子 → 稳定买在主题内最热的位置
他的话是"题材内**被市场认得出**"（辨识度），我们落成 `r60 + 成交额 + 涨停次数` 的分位均值 = **动量**。
实测（`docs/wolf-pick-selection-eval.md`）：IC 负向、十分位单调向下、tier1 比同池随机还差 0.98pp（5 日）。
→ 不是"调权重"能修的：**要么换代理（成交量级/换手/历史领涨次数/龙虎榜席位/是否曾做龙头），要么把榜降级为环境指标。**

### C-2 机构思路（先板块后个股）vs 他的游资思路（先有个股题材再推板块）
我们整条链是 `主题 → 主题内选股`；他 2021-07-08 明说那是机构思路，他做的是"个股先动 → 反推板块"。
→ 影响：主题级信号确认时，个股往往已经走完第一段；这与我方"买点逆向选择"（§C1）是同一现象的两面。

### C-3 选股域与可执行域不一致（F2）
选股按全市场排名（含创业板/科创板），执行层按账户权限剔除 → **排到前面的票可能根本买不到**，
实际买到的是排序靠后的主板票。v2.1 的两个展示案例（神农 300189）就落在被剔除的板块。
