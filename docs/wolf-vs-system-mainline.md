## 四、结构性差异（四项检验的结论）

1. **我们的 gate 是粗筛不是选择**：每天 14 候选 → 中位确认 **10 个**（确认率 60.5%）→ 与他方向无正区分（超额 −0.0822, t=−2.16）。
2. **heat 与他的方向强反向**：他方向平均 heat 排名 **10.42/13**（随机 7.0）→ −3.42, t=−11.89。heat 追"资金流入/放量"，他做"缩量/未被关注"。
3. **gate 抓动量不是拐点**：确认后 5 日超额——高位(过去20日>+5%) **+0.338%(t=3.78)**、低位(<−3%) **−0.204%(t=−2.93)**。
4. **他的方向本身显著有效，我们的不显著**：1–7 月他 **+0.410%(t=2.64, n=180)**、我们 −0.050%(t=−1.10, n=1300)。

## 五、对我们的直接含义

- **该复刻的是"他的方向选择"**，验收线：同口径 **> +0.41%（t>2.6）**。
- 方向层要能表达"**缩量/未被资金注意**"（他原话：趁小跳买、量能开始缩转放），而不是继续奖励资金流入。
- 同一批 gate 结论需**按位置分层**：高位确认=动量信号、低位确认=仅观察，低档不给仓位。

## 九、「排除型数据」的验收结论：**否决，不接进方向层**

依据他的话（2026-08-26「避开那几个大公募持仓个股」、2026-08-27「基金持仓多的就上不去」、2026-08-24 成交占比拥挤），
用**现成产物**（`crowding_pit/stock_crowd_*.json` 20 期 PIT 公募持仓快照 + `crowding_blacklist.json` 自带规则
`n_funds_min=4, float_pct_min=1.0` + `mkt_bars_daily.amount` 成交占比）做验收，结果**反向**：

| 检验 | 结果 | 判读 |
|---|---|---|
| ① 主题层 IC（拥挤指标 vs 主题后5日超额） | float_avg **+0.008(t=0.35)**、crowd_share +0.023(t=1.02)、mkv_avg +0.013(t=0.61) | 无预测力（符号还是正的） |
| ① 成交占比拥挤分位 IC | **+0.086(t=2.10)** | 弱**正向**（动量，非拥挤反转） |
| ② 按公募拥挤分档 | 低 −0.099 / 中 −0.126 / **高 +0.117** | 高拥挤档反而最好 |
| ④ 个股层（他的话的原始层面） | n_funds **+0.019(t=2.08)**、sum_float −0.002、mkv +0.018 | 亦不支持"持仓多的上不去" |
| ⑤ 条件式（高位才危险？） | 高位 float_avg_IC +0.061(t=1.69)、低位 −0.012 | 不支持 |
| ③ 变体（gate∩r5 top1） | V0 基线 **+0.683%(t=3.04)** → V1 公募排除 **−0.152%(t=−1.02)** → V2 成交排除 +0.152%(t=1.01) → V3 **−0.009%** | **加排除即崩塌** |
| ③ 他方向命中 | 23% → 12%(V1) / 20%(V2) / 13%(V3) | 排除把好方向排掉 |

**机制**（表2 最直观）：现成黑名单的 `subs` 就是「**芯片/半导体、材料、AI终端**」，即**他的第一主线**。
"用拥挤度排除"在实战上等于"**与他的主线对着干**"：半导体 40 天→**0 天**、AI 11 天→**0 天**，
于是 D1+排除 的选股池被迫落在农业/电力/消费/资源这些**防御方向**上。

**诚实边界（不把"正显著"当结论）**：IC 的 t 值被**重叠样本**膨胀（20 期快照 × 重叠的 5 日前瞻 ≈ 有效独立样本仅 20 块），
按快照分块后的块状 t 尚未算（列入待办）；但**操作结论不受影响**——加排除让基线从 +0.683% 掉到 −0.15%/+0.15%，
方向层**不接排除型数据**，D1 保持现状（模块里也从未接线，无需回退）。

## 十、大方向判断（用户问的"大方向上对不对"）

1. **对**：D1（gate 资格 ∩ 近 5 日相对强度）在**方向层**是他方向选择的一次有效近似 ——
   他方向落我们 top1/top3 = **23%/48%**（随机 7.7%/23%，3.0×/2.1×），所选方向后 5 日超额 **+0.683%(t=3.04, n=152)**，
   已越过为他设的验收线（> +0.41%, t>2.6）。
2. **不对的地方**：我们 gate 本身**无信息**（命中 75% ≈ 随机 77%）；D1 的残留偏差是会把**农业(28 天)/医药(20 天)**
   这类他从不碰的防御方向推到第一（他 2026 全年农业 0 天、医药 5 天、消费/金融/稳增长各 1 天）。
   → 待办：查"防御方向在 r5 上冲第一"的过滤条件，**必须由语料支撑**（他的"有没有行情/有没有主线题材带动"），
   不再自造指标。
3. **排除型数据**：现成两套口径（公募持仓拥挤、成交占比拥挤）在主题层与个股层**都没有负向预测力**，
   接进去有害 → **不上线**。他的话应理解为**个股/事件级的主观规避**（点名的那几只海外链公募重仓股），
   不是可统计复制的主题排序因子。
