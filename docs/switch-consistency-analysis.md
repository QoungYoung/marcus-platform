## 2. 结论
1. **切换链路可执行性成立**：日线层“链级切换”判定的 4 个事件，全部能在 ±6 交易日内的 5min 中找到卖旧/买新的盘中触发点（卖=冲高破黄线；买=急杀企稳/254 低吸）。
2. **对一致率的贡献集中在 E10**：E10 之前是 v2 唯一 partial；规则+分钟执行把它转成 aligned（切换通道计数），使 8 事件 8/8 aligned。
3. **低吸/T 通道与切换通道是互补口径**：单看 254/253 低吸通道 ±5 日 29/39=74.4%；加切换通道后 35/39=89.7%——不能把两者相加当“都触发”，它们代表不同行为。
4. **Agent 相对规则的增量尚无可比数**：Agent 已并入 auto_trade 提示层、不独立下单；需 buy_point_log + 事件日志积累后才能量化“Agent 决策 vs 规则 vs Wolf”逐事件差异。

## 3. 残留风险/待办
- E05/E06/E13 的覆盖来自 253/254/分步回补，不是切换通道；其中 E13 仅 3/6（50%）在切换/低吸口径下偏弱。
- 分钟级执行点回放是“存在性”验证（±6 日窗口内至少有一个触发），不是“当日必成交”；真实成交还受资金/仓位/冷却约束。
- Agent 上下文目前不带“当日计划持久化”，只有回退链信号；若需要 agent 结构化输出对比，可加“auto_trade 决策日志”字段（计划中）。
