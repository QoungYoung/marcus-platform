# 卖出前门（sell_gate）：狼大止盈止损口径 + 重复卖出拦截

> 目标：agent 的止损/止盈卖出必须经过狼大规则，不能凭感觉卖；同一标的不能重复卖。
> 实现：`backend/app/services/sell_gate.py`；接线：`backend/app/api/trades.py` 的 sell 侧。
> 现状：止损/重复已硬拦；止盈只做重复拦截（Wolf 止盈的价/位判据留到第二阶段）。

---

## 1. 意图分类

| intent/理由 | 分类 | 处理 |
|---|---|---|
| 止损/破位/破线/跌穿/斩仓/清仓 | `stop_loss` | 过狼大止损线 + 收盘确认 + 时点 + 地量 + B8 |
| 止盈/高抛/兑现/目标/前高/0.618/BOLL | `take_profit` | 只做重复卖出拦截 |
| 做T/T出/低吸/回补 | `t_sell` | 只做重复卖出拦截 |
| 减仓/减半/防御/避险 | `reduce` | 只做重复卖出拦截 |
| 未识别 | `other` | 只做重复卖出拦截 |

## 2. 止损：只认他的线

| 判据 | 原话 | 实现 |
|---|---|---|
| 指数大级别 | 2026-08-27「只看指数大级别……转下跌1浪就止损」 | `index_break` 直接放行（唯一无条件） |
| MA60 | 2021-01-28「60日是我的底线」 | 上一根收盘 < MA60 → 放行 |
| MA34 带量 | 2021-01-28「没站稳34日带量下穿的我都会砍掉」 | 上一根收盘 < MA34 且量比 ≥1.0 → 放行 |
| MA5 黑K | 2026-01-12「收黑K跌破5日线……减仓避一下」 | 上一根黑K且收盘 < MA5 → 放行（原则上是减仓，不是清仓） |
| 收盘确认 | 2026-01-29「收盘跌破我才出」；2026-01-12「等收盘确认破位出清」 | 只用**上一根已收盘 K** 判线；盘中刚跌破 → 等收盘 |
| 时点 | 2026-03-23「止损绝对不应该是下午1点到2点半；要么早上卖，要么尾盘卖」 | 13:00-14:30 拒绝 |
| 地量不割肉 | 2026-08-21「这种地量不值得我割肉，我的策略就没有这个量能割过肉」 | 量比 <0.8（代理）→ 拒绝 |
| 假跌破/回踩不破 | B8 三态（2026-02/03 语料） | `hold`/`false_break` → 拒绝，等次日 |

**没有**：固定 -5%/-8% 止损、MA5>MA20 硬闸、背离信号计数——这些不是他的话。

## 3. 止盈（第二阶段）

当前只做重复拦截；Wolf 的止盈判据已整理在 `docs/wolf-exit-playbook.md` / `docs/wolf-takeprofit-corpus-playbook.md`：

- 做 T 3-5 个点（2026-04-23、2026-08-13）；
- 二次冲高半小时缩量不过前高走（2026-08-04）；
- 破分时黄线直接走（2026-08-04）；
- 前高/0.618/整数关/BOLL 上轨减半（2026-03-05、2026-04-29、2026-01-13）；
- 放量滞涨减（2025-08-28、2025-09-11、2026-05-11）；
- 被动止盈线（2026-08-19）。

这些需要价格/位置数据，放在 `sell_gate` 的第二阶段；当前不硬拦，避免误杀他的主动兑现。

## 4. 重复卖出

| 判据 | 原话/依据 | 实现 |
|---|---|---|
| 同标的当日卖 ≤2 笔 | 2025-02-07「一个票最多买2笔 卖2笔」 | `_count_today_trades` ≥2 → 拒绝 |
| v3 当日已动作 | 防 t_monitor 已卖、agent 再卖 | `wolf_v3_production.pg_symbol_action_today` → 拒绝 |
| 同 action_key | 防同一价格/同一意图重复 | 本地 `sell_gate_actions.jsonl` → 拒绝 |
| 换手/冷却 | `t_turnover`（同价来回/跨日冷却） | 若开启则复用 |

---

## 5. 接线与开关

- 位置：`trades.py::execute_trade` 的 **sell 侧**、`executor.sell` 之前。
- `WOLF_SELL_GATE=off|shadow|enforce`，默认 **enforce**。
  - `shadow`：只记录 would-block，不拒单，用于观察误杀。
- 日志：`data/sell_gate.jsonl`。
- 不影响 `t_gateway`/`t_monitor` 的 T 止损链路（它们走独立网关，已有 G6 笔数/在途锁/换手闸）。

## 6. 已知缺口（下一步）

1. **旧闸冲突**：`marcus_trade._check_sell_trend_constraint`（MA5>MA20 + 背离<3）是平台 AI 闸，不是 Wolf；它可能在 `sell_gate` 放行后仍把卖单拦掉。
   → 下一步：`sell_gate` 返回 `wolf_validated` 时，调用 `executor.sell(..., skip_trend_constraint=True)`；MA5 黑K 用 `WOLF_SELL_HALF_ON_BREAK`/减半，不用全平。
2. **13 日早期止损**：2026-03-05「13日内跌破波段低点-3%没收回，直接止损」还没进 `sell_gate`；可复用 `wolf_early_stop`。
3. **量比口径**：当前用上一根日线量/20日均量；盘中应改用同刻累计量（PIT）。
4. **止盈判据**：第二阶段接前高/0.618/BOLL/放量滞涨。
