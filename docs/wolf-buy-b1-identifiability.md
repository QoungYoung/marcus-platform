## 0 一句话

他的「辨识度」**不是一个因子，而是一套"分层 + 阶段/位置依赖"的规则**：
**核心（绑定板块、他活板块活）> 风向标 > 龙头 > 龙2/二供 > 杂毛**，
且**选哪一层取决于板块处于什么阶段**（强/主升→最强；已涨起来→二供/二线补涨；下跌错杀→有业绩有订单没雷 + 资金接盘；低位→低位横盘多时）。
我们现行实现把它压成了**一个动量分**（r60+成交额+涨停次数），既丢了分层，也丢了阶段依赖 —— 这就是 IC 负向的来源。

## 4 结论与下一步（① 设计输入）

1. **不要**再找"更好的动量代理"——B1 的原话本身就要求**放弃单一动量排序**，改成分层 + 阶段依赖。
2. **立即可算的 6 个新维度**：D1 名字辨识度 / D2 量能活跃 / D3 资金不连续流出 / D4 跌时资金接盘（已验证） / D5 相对抗跌 / D6 低位横盘多时（+ D8 二供与主题阶段交叉、D9 核心共动、D10 跨题材已有）。
3. **下一轮动作**（按纪律：先离线、再开关、先影子）：
   - 把这些维度加进 `jobs/eval_pick_factors.py`（同一把尺子、同一窗口、H1/H2 分段），逐个量 IC 与十分位；
   - 只用**两个窗口都为正**、且**语料有原话**的维度构成新排序（组合分），与现行 leader 做同口径对照；
   - 再加开关 `WOLF_PICK_RANK_V3`（默认 0）+ 定向单测 + 独立 commit，影子跑一段再拍板上线。
4. **数据缺口登记**：D7 换手率（补拉一列即可）、D11 龙虎榜席位（薄）、D12 订单/业绩事件（无结构化源）——**不要用假代理硬凑**。

## 6 由实测得出的三条硬结论（① 的设计输入）

1. **不存在"更好的单因子"**：他所有可算维度里，只有 `flat_low_days`（低位横盘）与 `hist`（老票）在 5/20 两个窗口**同向为正**，且都只有 +0.004~+0.018 —— 微弱到不足以单独当选股排序。**动量类（r20/r60/涨停/成交额/曾领涨）一致显著为负**，必须从排序里拿掉。
2. **他的"板块级"判据不能直接搬到"个股级"**（本轮第二次踩到，第一次是 ② 的资金确认）：
   - 2025-06-16 明说「量能活跃…**这是选板块的第一要素**」→ 我们按个股排序用，实测 **−0.033（20 日, t −1.93）**，池内 −0.085（t −3.57）；
   - 2021-08-04「资金去配置」在**全成分**为正、在**我们已选池内**为负。
   → 规则落地前必须先判"他这句是判板块还是判个股"。
3. **真正没被实现的不是"因子"，而是"分层 + 阶段依赖"**（B1 §C）：
   「弱势板块找强势票，强势板块找二线补涨」(2026-04-19)、「已经涨起来的板块的龙头不做 做他的二供」(2026-04-13)、
   「抱团方向局部的龙2龙3 + 超跌板块的龙1」(2021-02-18)、「下跌浪就做龙头」(2025-07-29)、
   「低位横盘多时 > 超跌」(2026-04-07)、「错杀要有业绩有订单没有雷 + 看资金是否接盘」(2025-03-25)。
   → 这些是**条件化规则**（选哪一层随板块阶段变），**单因子 IC 测不出来**，必须用"主题阶段 × 组内位次"的**条件分组验收**
   （harness 里已有 `x_pos_*` / `x_r20pos` 这类分档机制可直接扩展）。

**因此 ① 的正确形态 = 条件化分层排序**（待做）：
```
若 主题强（r5 高/加速）        → 取主题内强度第 2–4 名（二供/二线补涨），且不追已创新高的龙头
若 主题弱（下跌/超跌）          → 取主题内最抗跌/最强（跌得少涨得多），且需"资金有接盘"
若 主题低位横盘                → 取低位横盘多时（flat_low_days 高）> 超跌
所有情形共用：去掉动量类权重；保留"距前低近 + 缩量 + 跌时资金净流入 + 老票"
```
**验收口径**：与现行 leader 同窗口、同超额、同块状 t 对照；**H1/H2 两段都不劣**才允许进开关；
