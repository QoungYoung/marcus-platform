# 行业龙头方向预测模型 — 设计方案

> 版本: v2.0 | 日期: 2026-07-27 | 状态: 待评审

---

## 1. 问题定义

### 1.1 交易场景

用户只交易 **申万一级行业市值 Top 3 龙头股**（约 110 个行业 × 3 = ~330 只候选），从中选取 5-10 只构建多头组合。

### 1.2 模型目标

给定当日全市场行情截面，预测每只龙头股未来 N 个交易日的预期收益率（回归目标），按预测收益率降序排列，供交易决策使用。

### 1.3 预测周期

三个独立模型：**1 日、3 日、5 日**。分别对应短线、波段、持仓周期。

## 3. 特征体系 (35 维)

### 3.1 个股权重特征 (19 维) — FEATURE_COLS

| 类别 | 特征名 | 含义 | 计算方式 |
|------|--------|------|---------|
| 量价结构 | `vol_ratio_5d` | 5日均量/20日均量 | 放量突破信号 |
| | `vol_ratio_1d` | 当日量/20日均量 | 单日放量程度 |
| | `amount_breakout` | 成交额突破 | 当日成交额 > 20日中位数×2 |
| 买压 | `up_vol_ratio` | 上涨日量/下跌日量 | 近5日，上涨放量vs下跌放量 |
| 趋势 | `consecutive_up` | 连涨天数 | 从最近向前计数 |
| | `consecutive_down` | 连跌天数 | 同上 |
| | `gap_up_pct` | 向上跳空缺口(%) | (今日开盘-昨日收盘)/昨日收盘 |
| 行情 | `change_pct` | 当日涨跌幅(%) | |
| | `turnover_rate` | 当日换手率(%) | |
| 资金 | `big_order_net` | 大单净流入(亿元) | 买大单+买特大单 - 卖大单-卖特大单 |
| | `main_force_ratio` | 主力净占比(%) | |
| | `flow_5d_cum` | 5日累计主力净额(亿元) | |
| 动量 | `ret_5d` | 5日收益率(%) | |
| | `ret_10d` | 10日收益率(%) | |
| 技术 | `rsi6` | RSI(6) | 从日线收盘价推导 |
| | `rsi14` | RSI(14) | 同上 |
| | `ma20_deviation` | 收盘价偏离MA20(%) | |
| 交互 | `strength_score` | 涨跌幅 × 全市场排名 | 动量确认信号 |

### 3.2 行业特征 (7 维) — SECTOR_COLS

| 特征名 | 含义 | 计算方式 | 用途 |
|--------|------|---------|------|
| `sector_pct` | 涨跌幅行业中位数偏离 | change_pct - median(sector) | 选股：龙头是否强于同行 |
| `sector_ret_5d` | 5日动量行业中位数偏离 | ret_5d - median(sector) | 同上 |
| `sector_vol` | 量比行业中位数偏离 | vol_ratio_1d - median(sector) | 同上 |
| `sector_mf` | 资金流行业中位数偏离 | big_order_net - median(sector) | 同上 |
| `sector_money_flow` | 行业资金总流向 | sum(big_order_net) within sector | 行业选择：资金在流向哪个行业 |
| `sector_breadth` | 行业宽度 | up_count / total within sector | 行业健康度 |
| `sector_rank` | 行业全市场排名 | 行业涨跌幅中位数在全市场中的百分位 | 行业轮动信号 |

**行业统计基于全市场全股票计算**（约 5000 只），而非仅 330 只龙头，确保中位数/排名有统计意义。

### 3.3 市场宽度特征 (6 维) — MARKET_COLS

| 特征名 | 含义 |
|--------|------|
| `up_ratio` | 全市场上涨占比 |
| `limit_up_count` | 涨停家数 |
| `advance_decline` | 涨跌比 (上涨家数/下跌家数) |
| `mkt_mean` | 全市场平均涨跌幅(%) |
| `mkt_vol` | 全市场涨跌幅标准差 |
| `mkt_amount_total` | 全市场总成交额 |

### 3.4 指数特征 (3 维) — INDEX_COLS

| 特征名 | 含义 |
|--------|------|
| `index_ret_5d` | 上证指数5日收益率(%) |
| `index_rsi14` | 上证指数RSI(14) |
| `index_ma20_deviation` | 上证指数偏离MA20(%) |

### 3.5 关于市场级特征的说明

MARKET_COLS(6) + INDEX_COLS(3) = 9 个特征在同一天内所有股票共享相同值，对截面排序无贡献。保留它们的原因：XGBoost 的树结构天然会按这些特征在根节点附近分裂，模型自动学习"大盘好时加仓、大盘差时减仓"的市场择时效应。如果移除它们，模型失去择时能力，只剩下纯选股信号。

## 4. 目标标签

### 4.1 回归目标

```
target_1d = (T+1日收盘价 - T日收盘价) / T日收盘价 × 100 (%)
target_3d = (T+3日收盘价 - T日收盘价) / T日收盘价 × 100 (%)
target_5d = (T+5日收盘价 - T日收盘价) / T日收盘价 × 100 (%)
```

缺失值(NaN)表示该股票在目标日期停牌或无数据，训练时跳过。

### 4.2 为什么用回归而非分类

| | 二分类 (v1) | 回归 (v2) |
|---|---|---|
| 目标 | P(return > 0) | E[return] |
| 信息量 | 丢失幅度信息 | 保留完整分布 |
| +0.01% vs -0.01% | 标签相反 | 数值接近，损失小 |
| 排序质量 | 间接（概率排序≈方向排序） | 直接（按收益排序） |
| 龙头策略匹配 | 一般 | 好——需要排前5-10只 |

## 5. 模型架构

### 5.1 核心模型

**XGBoost 回归** (XGBRegressor)，三个独立模型分别预测 1d/3d/5d。

输入: 35 维特征向量 (StandardScaler 标准化)
输出: 预期 N 日收益率 (%，连续值)

### 5.2 超参搜索

**Optuna TPE** (Tree-structured Parzen Estimator)，首个训练窗口执行一次：

| 参数 | 搜索范围 | 分布 |
|------|---------|------|
| max_depth | 4 - 10 | int uniform |
| learning_rate | 0.01 - 0.2 | log-uniform |
| n_estimators | 100 - 500 | int uniform |
| subsample | 0.6 - 1.0 | uniform |
| colsample_bytree | 0.6 - 1.0 | uniform |
| reg_alpha | 1e-6 - 1.0 | log-uniform |
| reg_lambda | 1e-6 - 1.0 | log-uniform |
| min_child_weight | 1 - 10 | int uniform |

- 目标: 最小化 RMSE
- CV: TimeSeriesSplit(3)
- 剪枝: MedianPruner (前 10 次试验不剪枝)
- 默认 trials: 100

### 5.3 训练方法: Walk-Forward 滚动窗口

```
日期轴:  [d1, d2, ..., d120 | d121..d130 | d131..d140 | ...]
          ←── train ──→ ← test → ← test →  ← test  →
                         Window 1  Window 2  Window 3
```

- 训练窗口: 固定 120 个交易日（约 6 个月）
- 步长: 10 个交易日
- 500 天数据 → 约 38 个验证窗口
- 每个窗口产出: RMSE, Spearman R, 方向准确率, R²
- 最终模型: 最后一个窗口训练的模型（代表最近的市场状态）
- 指标汇总: 所有窗口的均值

### 5.4 为什么用滚动窗口而非扩展窗口

- 扩展窗口: 训练集持续膨胀（120→130→140...→490天），早期数据权重递减但仍在训练集中，且训练时间不断增长
- 滚动窗口: 训练集固定 120 天，始终反映最近半年的市场状态，训练时间恒定

## 6. 评估体系

### 6.1 核心指标

| 指标 | 公式 | 含义 | 为什么重要 |
|------|------|------|-----------|
| **Spearman R** | corr(rank(pred), rank(actual)) | 预测排序与实际排序的相关性 | **龙头策略最关键指标**——决定了 top N 推荐的质量 |
| RMSE | sqrt(mean((pred - actual)²)) | 预测误差幅度 | 模型校准质量 |
| 方向准确率 | mean(sign(pred) == sign(actual)) | 涨跌方向判断正确率 | 辅助参考 |
| R² | 1 - SS_res / SS_tot | 解释的方差比例 | 整体拟合度 |

### 6.2 评估方法

- Walk-forward 验证，每窗口独立评估
- 最终报告 38 个窗口的均值 ± 标准差
- 无数据窥探：每个窗口的训练/测试严格按时间分割

## 7. 推理流程

### 7.1 市场状态判定

复用 `IndustryLeaderboardService._detect_market_regime()`:
- 上证综指 ADX + MA5/MA20 关系
- ADX > 25 且 MA5 > MA20 → **trending** (趋势市)
- ADX < 20 → **ranging** (震荡市)
- 其他 → **transitional** (过渡市)

API 返回 `market_regime` 字段供前端/交易策略参考，**不再乘以置信度系数**（回归模型直接输出预期收益率，不做人为缩放）。

### 7.2 资金流向数据源策略

```
实时模式 (无 date 参数):
  East Money 实时 API → Tushare moneyflow_dc 降级 → 成交额×涨跌幅代理

历史模式 (有 date 参数):
  Tushare moneyflow_dc → 成交额×涨跌幅代理
```

单位一致性: 训练(万元→/1e4→亿元) = East Money(元→/1e8→亿元) = Tushare(万元→*1e4→元→/1e8→亿元)

### 7.3 行业分散约束

最终输出强制每行业最多 2 只股票，防止推荐集中在少数热门行业。

## 8. 与 v1 的关键差异

| 维度 | v1 (旧) | v2 (新) |
|------|---------|---------|
| 候选股 | 全市场 (~5000) | 行业龙头 (~330) |
| 预测目标 | P(return > 0) 二分类 | E[return] 回归 |
| 特征数 | 32 | 35 (新增3个行业级) |
| 行业特征 | 仅个股vs行业偏离 | 新增行业资金流/宽度/排名 |
| 模型 | XGBClassifier | XGBRegressor |
| 校准 | IsotonicRegression | 不需要 |
| 大势判定 | 独立 MarketRegimeClassifier | 复用 leaderboard ADX/MA |
| 置信度缩放 | 0.49/0.7/1.0 硬编码 | 移除，直接用预测值 |
| 行业分散 | 无 | 每行业最多2只 |
| 评估 | Accuracy vs baseline | RMSE + Spearman R + DirAcc |
| 训练数据源 | 全部 API | 全部本地 parquet |

## 9. 已知局限与后续方向

1. **市场级特征占特征 9/35 (26%)**，这些特征对截面排序无贡献，但提供择时能力。如希望纯选股，可将它们移除。

2. **Spearman R 是核心但难以很高**——A 股个股收益的截面可预测性本来就很低（通常 R < 0.05），龙头股之间的差异更小。合理的预期是 Spearman R 在 0.02-0.08 区间。

3. **行业归属使用当前 stock_pool 快照**，历史上个别股票的行业分类可能变更，引入轻微的行业标签噪声。

4. **无宏观/基本面特征**——CPI、PMI、利率、PE/PB 等未纳入。这些可后续作为额外特征维度加入。

5. **单模型**——只用了 XGBoost。可考虑 ensemble（LightGBM + XGBoost + 简单NN）提升稳健性。

6. **未考虑交易成本**——预期收益率未扣除手续费/滑点，实盘需叠加成本模型。
