# 他给的点位到底是什么：R04/R10/R11/R12 溯源

> 目的不是“采用他说的数字”，而是反推：这个数字对应哪类结构位？他为什么记成这个数？
> 方法：用信号日前的日线，枚举 MA/BOLL、前高前低、平台、缺口、整数关、摆动点、趋势线；±0.6% 内的全部列出，不强行选一个。
> 结论只用于理解策略，不把 3370/3922/3888 写成常量。

## 0. 先看结论

1. **他给的是“合流区”，不是一条精确线**：3370/3375、3888、3922 都是 2-4 个结构叠在一起的区域，他把区间的中心/整数念出来。
2. **他的“点位梯子”是不同结构**：3922 是前低/缺口，3900 是下降趋势线+前高+MA60+整数；3888 是前低+缺口+MA5，3850 是整数/缺口，3816 是平台低点。
3. **他口中的“趋势线”有时是宽松叫法**：3922 用简单上升趋势线拟合对不上（11/24 约 3987-4016），更像水平前低/缺口；“趋势线 3922”不能按 rising line 直接编码。
4. **整数关不是噪声**：3900、3920、3888-3890、3850、3930 都参与合流；他念的数字常是整数化的标签。

**判断**：3370 不是单一结构，是 **6/20 当日最高 3370.80 + MA20 3372.4 + MA34 3367.4 + 摆动低点 3365.7 + 整数 3370** 的合流区；3375 靠近 MA5。
他说的“收破 3370/3375”本质是**收破这个 3365-3377 的合流带**，不是精确 3370。

**更关键的角色**：他的原话是“昨天已经收破 3370 以下……今天或周一，在探底后的**回拉出掉**手中的票”。
所以 3370/3375 不是“跌破就卖的支撑”，而是**破位后反抽卖出的目标区**——当天最高正好 3370.80，冲到这个区就出。R04 应归为 `rebound_exit`，不是 `breakdown_reduce`。

**为什么引擎会给 3388.78**：3388.78 是 **2025-02-27 的高点**，也是 6/16-6/18 的箱体中枢（收盘 3388.73/3387.40/3388.81）。它比 3370 高 18.78 点，是**更老、更高的颈线/箱体中枢**，不是同一个结构。引擎的候选里有 3388.78，却没有 3370（当日最高/MA20/整数没进候选），agent 只能选这个“更强的替代”。

## 5. 这四次说明了什么策略

1. **先找合流，再取整数**：他不报 3372.4、3922.58、3899.96 这种精确值，而是念 3370、3922、3900、3888——**整数是合流区的标签**。
2. **梯子不是均分**：3922（前低/缺口）和 3900（趋势+前高+MA60+整数）是两类结构，所以 40%→20% 不是随意加码；3888（前低+缺口+MA5）→3850（整数）→3816（平台）也是三类结构。
3. **缺口簇是他的高频依据**：3922-3931、3888-3891 都是缺口；他后来会用“缺口位置”复盘。
4. **“趋势线”要验算**：3922 的上升趋势线拟合不成立；如果直接按“趋势线”编码，会错。正确做法是**先归类结构，再决定叫法**。
5. **点位必须带“角色/日期/来源”**：同一个 3922，在 11/21 是“跌破的支撑”，在 11/23 是“没站回的趋势线”，在 12/03 是“上方压力/加回条件”。**数字相同，角色不同。**

## 6. 对引擎的含义

- 不要把 `3370/3922/3888` 写成常量；把它们写成**合流区**：
  - R04：`3365-3377`；
  - R10/R11：`3912-3929`（3922 区）；
  - R10 3900：`3898-3901`；
  - R12 3888：`3888-3891`；
  - R12 3922-3930：`3922-3935`。
- 选点位时，不按 `confidence` 单指标，而按：
  1. 结构类型是否匹配他的用词（前低/缺口/趋势线/平台/整数）；
  2. 是否 2 个以上结构合流；
  3. 是否在他讲话的“段位/角色”里（支撑/压力/失效线）。
- 如果他说的“趋势线”拟合不出来，**标为“术语不一致”**，不要硬造一条线。
- 最终目标不是复刻数字，而是复刻**“合流区 + 角色 + 梯子”**这套选点方法。
