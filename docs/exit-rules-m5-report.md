# 阶段 1 追加：真·分时均价线（m5）验收「破黄线」——结论与生产改动建议（2026-09-14）

> 取数：jobs/fetch_m5_legs.py（**复用既有 tushare/brze 接口** t_backtest_data.prefetch_m5 → stk_mins）
> 实测：**15 只标的 × 43 个交易日（2026-07-15 → 09-11），0 缺口**，缓存 data/m5_local/m5/（已 gitignore，可重跑）。
> 变体实现：jobs/eval_exit_rules.py 的 sim_variant_m5 / sim_variant_m5_window。

## 1 变体定义（都用标的自己的分时均价线）

- **V2a** 全天任一时点：某根 m5 收盘 < **当日累计均价线**（amount 累计 / vol 累计）→ 当根离场；
- **V2b** 同 V2a，但要求**连续 2 根**跌破（"突发跌破"去抖）；
- **V2c** 只在**他做 T 的两个时间窗内**判（09:45–10:00 / 14:00–14:30）——对应 2026-08-04 10:48
  「**在这个半小时内**有个绝对不能破的点 就是日均线那条黄线」＋2025-04-15 成文流程条件 2；
- **V3a/V3b/V3c** = 对应 V2 与 **+3% 止盈**先到先执行；另有日线代理版 **V2_vwap**（旧口径，已淘汰）。

## 3 结论（这一步的价值就在这三条）

1. **「破分时黄线」不是择时信号：它是持仓期间几乎必然发生的状态。**
   用真 m5 算，**无论全天（V2a/V2b）还是只在他那两个做 T 窗口内（V2c），33/33 条腿都会破线**
   —— 因为"当日累计均价线"本身就是当天价格的平均，价格围绕它上下穿越是常态。
   → 旧日线代理（当日最低 < 当日 VWAP）给出的 72.7%/+0.34% **是代理假象**，现已被真数据推翻。
2. **把"破黄线"与"+3% 止盈"并列成"先到先执行"，会把 +3% 的优势抹掉**：
   V1 +1.29% → V3c −0.06%（26/33 走破线、只有 7 条走到 +3%）。
   ⚠️ **这正是我们生产里的写法**：t_monitor._check_roundtrip_sell 里 vwap_break 是**优先离场**条件
   （cur < 分时均价 → 直接卖），所以"低吸后反弹 3% 卖回"这个目标**大多被提前触发**，
   实际执行的更接近"随时破线就走"（V2c 口径，−0.31%）。
3. **他的原话需要加限定才是信号**：他 10:48 那句的完整语境是「**这半小时内**…一旦**突发**跌破直接走；
   **如果没跌破就找这半小时的高点**」——"突发"与"没跌破就等高点"都指向：**破线是需要确认的（急跌破位），
   不是任意一根 m5 收盘低于均价**。可算化的确认条件还没有定；语料里同族还有量能条件
   （「缩量不参与」「放量跌破收盘完全止盈」）可以叠加。

## 4 给生产的建议（A1 **已按用户拍板落地**，2026-09-14）

| # | 建议 | 依据 | 状态 |
|---|---|---|---|
| A1 | **把 roundtrip_sell 的优先级反过来**：+3% 目标**优先**于破黄线；破黄线只在"跌破且回落幅度 ≥ X%"（或跌破后 2 根不收回）时才提前离场 | 本报告 §3.2（V1 +1.29% vs V3c −0.06%） | ✅ 已落地并部署（`backend/app/services/roundtrip_priority.py` + `t_monitor._check_roundtrip_sell`；X 默认 0.5%、2 轮；回退 `WOLF_RT_PRIORITY=vwap_first`） |
| A2 | 破黄线保留**保护语义**（不回补、不减仓目标），但不作为独立 alpha 来源 | §3.1（33/33 命中） | ✅ 按设计成立：破线仍在（目标之后）触发离场，只作直跌保护；不再被当作"择时信号"计入 alpha |
| A3 | 若要继续做"破线"信号，需定义**确认条件**（急跌幅度/根数/量能），否则永远 100% 触发 | §3.3 | 🚧 口径已定义（幅度 / 连续轮数两旋钮），**阈值不能靠 n=33 定** —— 见 §4.1；生产先取保守默认 |

### 4.1 确认条件的阈值敏感性（`jobs/eval_roundtrip_confirm.py`，n=33，真 m5）

同一批生产腿，扫 `pct`（跌破幅度）× `rounds`（连续在黄线下的轮数，一轮 30s），变体 V3d = **+3% 目标优先 + 确认破线**：

| pct | rounds | 破线出场 | 走 +3% | 持 T+5 | 均值% | 胜率 | 中位% |
|---|---|---|---|---|---|---|---|
| 0.0% | 2 | 26 | 7 | 0 | −0.03 | 45% | −0.72 |
| 0.5% | 2（**生产默认**） | 26 | 7 | 0 | +0.01 | 45% | −0.72 |
| 0.5% | 3 | 26 | 7 | 0 | −0.04 | 45% | −0.72 |
| 0.5% | 5 | 16 | 17 | 0 | +1.65 | 64% | +3.09 |
| 0.5% | 99（≈只按幅度） | 14 | 19 | 0 | +1.76 | 64% | +3.09 |
| 2.0% | 99 | 9 | 19 | 5 | +0.84 | 58% | +3.09 |
| 3.0% | 99（≈不等破线） | 0 | 20 | 13 | +1.48 | 61% | +3.09 |

**读法（重要）**：
1. **确认条件本身救不回 alpha**：0.5%/2 轮下仍是 **26/33 走破线**，均值 +0.01%（vs 不确认 V3c −0.06%），
   差别在噪声内（sd≈3.7 → se≈0.64）。**A1 的价值在"目标优先"这一半，不在"加确认"这一半。**
2. 阈值**极度敏感**：`rounds` 从 3 调到 5，破线出场 26→16 条，均值 −0.04 → +1.65。
   这不是"5 轮更好"的证据，而是**"破线出场越少越好"**——与 §3.1（33/33 必破）同一条结论的另一种表述。
3. n=33 且 H1/H2 会变号（§阶段 1 报告），**不允许**据此把生产阈值调成 5 轮；
   生产保持**保守默认 0.5% / 2 轮**（保护语义优先），待生产腿累积后再定。

### 4.2 A4「做 T 时间窗 + 14:00 到点决断」的实测（`jobs/eval_roundtrip_windows.py`，n=428）

A4 口径（2026-09-14 用户「改成跟狼大一致」）：
**目标兑现只在 09:45–10:00 / 14:00–14:30 两个窗口执行**（2025-04-15 成文流程条件 2）；
**14:00 仍未达标也 T 掉收工**（2026-09-02 14:03「2 点到了 力度不够 我先把早上博弈的先T了…结束今天做T操作」，
容忍"亏个手续费"0.5%）；**确认破黄线任何时候可走**（2026-08-04 10:48）。

| 口径（edge = 实际胜率 − 平衡胜率） | 1 日窗口 均值% / edge | 2 日窗口 均值% / edge | 5 日窗口 均值% / edge |
|---|---|---|---|
| hold（持到末端，纯基准） | −0.08 / −2.1pp | +0.07 / +0.3pp | +0.29 / +2.5pp |
| V1i（盘中一碰 +3% 即卖，旧限价语义） | −0.06 / −1.9pp | −0.01 / −0.8pp | +0.01 / 0.0pp |
| closeTP（**收盘** ≥+3% 才以收盘价卖） | −0.08 / −2.1pp | +0.14 / +1.2pp | +0.15 / +1.4pp |
| V3d（closeTP + 确认破线保护）= §2 的"生产旧口径" | +0.34 / +5.9pp | +0.35 / +6.1pp | +0.35 / +6.1pp |
| **A4a（窗口目标 + 到点收工 + 保护）= 本次落地** | **+0.01 / −0.9pp** | **−0.01 / −1.3pp** | **−0.01 / −1.3pp** |
| A4b（目标随时兑现 + 到点收工 + 保护） | −0.03 / −2.0pp | −0.05 / −2.4pp | −0.05 / −2.4pp |
| A4c（窗口目标，不做到点收工 + 保护） | +0.02 / −0.7pp | +0.01 / −0.9pp | +0.01 / −0.9pp |
| A4d（= A4a 去掉保护，用于归因） | −0.08 / −2.9pp | −0.05 / −2.4pp | −0.03 / −2.3pp |

**三条必须写清楚的读法**：
1. **A4 不是"更赚钱"的口径，是"更忠实"的口径**：它在 1/2/5 日窗口上都是 ≈0（edge 略负，扣 0.15% 成本约 −0.14%）。
   之所以照样落地：**在做 T 腿真正的 1–2 日窗口里，所有口径都落在 ±0.15pp 内（se≈0.18，全在噪声里）**，
   而 A4 是唯一一条有他原话逐条支撑的（窗口 + 2 点 + 破线直走）。**当回测无法区分时，按忠实度选。**
2. **更正 §2 的读法**：V3d 的 +0.34%/edge +5.9pp 属于「**收盘** ≥+3% 就以收盘价卖」这个 5 日口径 ——
   它的收益来自"让利润跑到尾盘、且只在强势日兑现"，**做 T 腿的 1–2 日窗口用不上它**，不能把这份优势记到 A4 头上。
3. **保护在短窗口里有正贡献**：1 日窗口下 A4d（去保护）−0.08% → A4a（含保护）+0.01%（+0.09pp），
   与 5 日口径下"保护是拖累（V2d −0.02 vs hold +0.29）"相反 —— 窗口越短，破线保护越像止损而不是剪尾巴。
