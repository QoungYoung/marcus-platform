## 3. 对生产做T体系的修正建议（下一轮实施）

现 249（index.intraday_dd 上证整日回撤 2-3%）**应重构为持仓个股级信号**，候选：

- **A. 个股挂前日低点**（最贴狼大 2025-03-06 方法）：持仓标的当日盘中触及/接近**前一交易日低点**（缩量）→ 正T低吸 T 仓
- **B. 个股当日盘中回撤**：持仓标的从当日高点回撤 X%（如 -2~3%，个股级日常波动，频率每天级）
- **C. 大盘分时跳水拖累**：上证 5min 单根急跌（如单bar≥0.8-1%）且持仓个股同步下探 → 低吸（比"整日回撤2%"敏感得多）

建议用 A+B 组合回测（5 股×184 天 brze 数据已有），与现 249 对比频率与收益，结论前不改生产。

## 4. 结论一句话

狼大"利用盘中大盘带下来的机会做正T"= **持仓个股被外部力量（大盘/板块/利空）拖累出现盘中低点时，低吸 T 仓做差价**——载体是个股、频率每天级、方法是挂前日低点/等跳水低点、大盘只是环境过滤；现生产用"上证整日回撤2-3%"是载体+频率+幅度三重错位，信号有效但已不是狼大正T。
