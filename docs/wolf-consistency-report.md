## 3. 高低位 9/18（50%）— 命中与失手

命中：
- 2026-01-29 稀土高位 ✓（HIGH 100%）、2026-01-12 AI 高位 ✓（HIGH 100%）。
- 低位：2026-08-07 电力/AI/航天 ✓（均非高位，MID）、2026-08-13 AI/机器人 ✓、2026-08-05 科技 ✓。
- 低吸：2026-08-12 半导体 ✓（MID + 资金流入 78%）。

失手（3 类真实缺口 + 1 类语义边界）：
- **G1 结构高位缺失**（2026-08-04/05/06 半导体「高位科技 B反」✗）：模块判 LOW/MID（vh -30~-35%、箱体 9~19%），
  因狼大的「高位」是**双头/M顶后的结构高位**（价格已跌但结构未走完），position_class 只测距1年高+30日箱体，不识别概念级 M顶/双头。
- **G2 相对主线低位缺失**（2026-08-07 医药 ✗）：狼大「医药是低位方向」，但模块判 70% HIGH
  （CRO vh=0% 1年高、箱体 100%，医药刚从低位启动第一波）——狼大的「低位」是**相对主线科技涨幅落后/刚启动**，
  模块的 HIGH 是 30 日箱顶。两个「位置」定义不同。
- **G3 t_only 全失**（2026-08-04/06 半导体「只做T/套利」✗）：同 G1，模块判非 HIGH 故不给只做T。
- **G4 低吸语义边界**（2026-01-14 半导体「低吸设备」✗）：当时半导体 vh=-2%、箱体 87% 确在主升高位，
  狼大是「主线强势中的回踩低吸」（他本来就持仓），模块判 HIGH 反而正确——「低吸」≠「低位埋伏」。

## 4. 结论与建议

1. **主线**：资金/动量代理命中 83%，但 4 个失手证明**代理不等于狼大定性**（产业周期/资金结构/持续性）。
   真正的 main_line_judge 一致性无法历史验证（研报无历史）→ 建议：①扩样本标签后把代理特征升级为
   「多日资金持续性 + 龙头扩散度 + 相对市场超额」，逼近 Wolf 的"主线=资金抱团+产业催化+持续"；
   ②或为研报模块建历史标注对照（需补研报历史数据）。
2. **高低位**：50% 命中率暴露两个结构性缺口——
   - **G1 概念级结构高位（双头/M顶）**：建议 position_class 增加概念自身结构形态识别（M顶/双头/新高后回落），
     复用 wave 模块的 sub_level 词汇（双头M顶/C杀），把「结构高位」与「价格距高」分开；
   - **G2 相对主线位置**：增加「相对主线（资金流入TOP概念组）的涨幅/位置排名」，区分「绝对高位」与「相对主线低位但刚启动」。
3. **标注集本身**：v1 仅 34 条、单标注者（我）、主题→概念映射有歧义（如医药=创新药）。扩样本 + 双人复核 +
   主题拆细（创新药/中药分列）是提高可信度的前提。当前数字是**方向性结论，不是最终准确率**。
4. **G4 语义边界**：低吸/埋伏类标注需区分「主线强势回踩低吸」与「超跌低位埋伏」——模块只覆盖后者。

## 5. G1 完成（2026-09-01）：概念级结构形态识别 → 高低位 50%→83%

**改动**（apps/main_line/position_class.py + wolf_match.py）：
- 新增 structure_of(ser)：概念级结构形态识别（波段高点检测 → 双头/M顶 / 新高回落 / 破位C杀 / B反），
  复用 build_wave_pivots 的 swing 思路（窗口 20 日适配 250 日概念序列）。
- resonance 新增「结构高位」分支：position∈{MID,LOW} 但结构∈{双头M顶, 新高回落} → 非主升 macro 下判「减仓/只做T」
  （狼大语义：价格可深跌但结构未走完，如 2026-08 科技 B反）；LOW+结构高位 → 不埋伏。
- wolf_match 匹配规则同步：high 判定 = 价格高位(HIGH≥50%) 或 结构高位(≥50%)；t_only 判定只看 action。

## 5.5 dip_buy 类别细分（2026-09-01）：低吸语义拆分 → 83%→94%

**问题**：原 dip_buy 用单一规则（LOW/MID+资金流入）评估，但狼大「低吸/埋伏」有 3 种语义。
**改动**：
- 标注集拆分：dip_buy_oversold（超跌低位埋伏，8/12 半导体）/ dip_buy_strong（主线强势回踩低吸，1/14 半导体）/
  dip_buy_pending（预告等待型，8/13 航天）。
- position_class.resonance 新增「回踩低吸」操作：主升期(build) + HIGH/MID + 非结构高位 + r20 回踩(-8%~0) + 资金未流出 →
  回踩低吸（狼大：持仓主线、回踩加仓；生产当前 macro=t_only 不触发，无回归）。
- wolf_match 规则按子类：oversold=原规则；strong=预期模块识别强势位(HIGH≥50% 或 上涨MID≥50% 或 模块给回踩低吸)；
  pending=预期模块观望(buy<50%，模块观望=狼大等待)。
**结果**：position 15/18(83%) → **17/18(94%)**，3 处 dip_buy 全部命中；唯一剩余 miss=医药（G2）。

## 5.6 G2 完成（2026-09-01）：相对主线位置特征 → 94%→100%

**问题**：2026-08-07 医药（狼大称「低位方向」）模块判 70% HIGH——CRO 箱体 100%/1 年高，但相对主线（科技）250 日涨幅大幅落后
（全体概念涨幅中位 -3.6%，CPO +128%/光模块 +100%，医药/电力/航天 -18%~+21%）。狼大「低位方向」= 相对主线涨幅落后的板块。
**改动**：
- position_class 新增 `build_rel_map(hist, upto)`：概念 vs 全体概念的 250 日（或可用窗口）涨幅百分位 → rel_mainline ∈ {low<0.4, mid, high>0.6}。
- resonance HIGH 分支加「相对主线低位豁免」：自身箱顶但 rel=low + 资金流入 + 非防御期 → 「观望(相对低位启动)」（狼大：低位方向持仓等，不按高位减仓）。
- wolf_match：low 匹配规则加 rel 维度（HIGH<50% 或 rel_low≥50%）。
**结果**：position 17/18(94%) → **18/18(100%)**（同一 34 条标注集）；医药 case ✓。
**生产验证**：521 概念 rel_mainline 三分（high 178/low 177/mid 98）；16 个 HIGH+rel_low 概念转「观望(相对低位启动)」
（冰雪经济/飞行汽车/工程机械等小题材，合理）；减仓/只做T 164→148，无过度放宽。
