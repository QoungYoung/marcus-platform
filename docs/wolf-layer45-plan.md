## 1. ④层目标

### 1.1 角色定义

| 角色 | 定义 | 是否可买 |
|---|---|---|
| 风向标 | 短周期板块内最强走势票 | 只看，不买它本身 |
| 龙头 | 从风向标里产生的最强可交易票 | ✅ |
| 核心 | 绑定板块、市值/产业地位核心 | ✅ |
| 老龙头 | 上一轮有辨识度的龙头 | ✅（低位埋伏） |
| 龙2/分类龙头 | 龙一之外最强辨识度 | ✅（不买后排） |
| 后排/杂毛 | 核心/风向标之外低辨识度 | ❌ 禁止 |

语料：

- 2025-12-06：风向标/龙头/核心三角色；
- 2026-01-16：后排不能去；
- 2025-09-10：不买龙头可以买分类龙头/龙2，不买后排；
- 2026-09-04：低位方向找辨识度最高老龙头埋伏。

### 1.2 角色识别输入

不新建数据源，先用已有：

- `chain_map` / PIT labels：rank、segment、leader/second；
- `stock_select.compute_features`：r20/r60、amt20、volr、dist、MA20/high20；
- `stock_pool`：市值、行业、概念；
- 历史领涨/成交额：辨识度/老龙头；
- 方向层输出：主题池、主线、容量。

### 1.3 角色规则（v1 草案）

```text
leader:
  个股强于板块 ∧ 板块强于大盘
  + 主题内市值/成交额前列
  + 趋势领跑

core:
  板块内总市值前5
  + 产业绑定/稀缺
  + 营收/业绩不拖累

old_leader:
  历史领涨次数/历史成交额峰值前列
  + 当前处于低位/回调
  + 仍有概念绑定

second (龙2/分类龙头):
  龙一之外的最强辨识度
  + 非后排

back_row:
  非核心、非龙头、非龙2
  或主题内排名后半
  → 排除
```

### 1.4 选票流程

```text
方向池
→ 角色分类
→ 排除 back_row
→ 龙头/核心优先
→ 低位老龙头/龙2 只在允许的市况
→ 主题内去重
→ 输出 picks + role + reason
```

### 1.5 验收

```text
后排违规率 = 0
每只 pick 有 role/reason
同主题不重复选同一票
leader/core 占比可解释
```

## 2. ⑤层目标

### 2.1 买点

按狼大语料：

```text
9:45–10:00 / 14:00–14:30
不追高
挂前一天低点
急杀可买、缓跌不买
缩量止跌 → 放量突破
0.618
```

### 2.2 止损

```text
13日内跌破波段低点 -3% 未收回 → 止损
13/34/60 均线
收盘确认
13:00–14:30 不执行止损
```

### 2.3 兑现

```text
3–5 个点
吃一口减一半
二次冲高缩量不过前高 → 走
跌破 5 日线 → 短期见顶，减仓
```

### 2.4 数据边界

- 无分钟数据：时间窗只能 shadow，不能假装回测；
- 日线：可验证结构、挂前低、止损、持有天数；
- 不把日线当分时。

### 2.5 验收

```text
每只 pick 有 entry/stop/target
买点/止损可执行
不再只输出 code/name/stage
```
