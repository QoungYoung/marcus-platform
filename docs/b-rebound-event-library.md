## 关键发现

### 1. B反至少四阶段

```text
low：恐慌低点，远离 MA20，收最低
mid：已反弹，站上 MA5/10，但仍低于/接近 MA20
high：远离 MA20，r20 高，二卖位
end：放量下跌，C杀开始
```

### 2. 只有 8/3 是 low 阶段

```text
2026-08-03
-9.89%
距20日低 +0.1%
距MA20 -22.5%
收盘位置 0.01
量比 1.35
```

其他“B反”大多是 mid/high/end，不是起点。

### 3. wave 标签基本是 mid/high

```text
2025-12-30 距MA20 +3.0%
2026-02-25 距MA20 +4.2%
2026-06-15 距MA20 +9.7%
2026-08-27 距MA20 +3.4%
```

所以用 wave 标签找“开始”必然晚。

## 结论

```text
我们不是没有其他 B反
而是其他 B反 大多不是“低点”
```

B反开始识别，必须分开：

```text
低点模型：恐慌、放量、收最低、远离MA20
中段模型：反弹已发生
高点模型：二卖/缩量
结束模型：放量下跌/C杀
```
