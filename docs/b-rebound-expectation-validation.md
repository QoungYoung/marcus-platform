# B反 预期日规则验证

> 2026-10-22；2 个预期日 + 30 个低区负样本。

## 正样本

```text
2025-08-01 弱 B反
2026-08-03 科创半导体 B反
```

## 规则

```text
下午低点：low_time >= 13:00
低点放量：low_vol_ratio >= 1.5
收盘低位：close_pos <= 0.5
```

## 结果

```text
TP 2：2025-08-01、2026-08-03
FP 10：
  2025-09-04
  2025-05-23
  2026-03-04
  2026-03-11
  2026-03-13
  2026-03-17
  2026-03-19
  2026-07-17
  2026-09-04
  2026-10-14
FN 0
precision 0.17
recall 1.00
```

## 结论

```text
规则能覆盖两个预期日
但假阳性 10 个
precision 只有 0.17
不能使用
```

## 原因

1. 下午放量下跌在下跌趋势里很常见；
2. 两个正样本量级差 10 倍；
3. 没有市场/板块/浪型过滤；
4. 8/1 是弱 B反，8/3 是恐慌 B反，本质不同。

## 下一步

1. 加浪型/板块/指数过滤；
2. 加低点后 30 分钟是否反弹；
3. 分弱 B反/恐慌 B反；
4. 仍只观察。
