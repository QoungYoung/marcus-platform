## 0. 摘要（先给结论，标注置信度）

1. **1.15 不是单一来源，是「半分位 + 前低」的合流区**。折算后 A 段 `1.465 → 0.828` 的 50% 是 **1.1465**；7/6 折算后首日低点是 **1.149**；而 8/3 11:20 说 1.15 时，当天已知低点是 10:25 的 **0.837**，`(1.465+0.837)/2 = 1.1510`。——**三者都指向 1.15，误差 ≤0.3%**。〔已核验：数据 + 分钟线〕
2. **「实时可算」这一条把证据权重压向半分位**：0.828 的低点发生在 14:56，而 1.15 说在 11:20；用 10:25 的 0.837 算半分位正好 1.151。7/6 前低 1.149 也同样成立，且不需要任何折算换算。——**两说无法用事后数据区分，属「推断」而非「证明」**。〔推断〕
3. 0.382/0.618 斐波那契、平台/缺口/VWAP/POC、整数关口这四类假设**被数据否定或明显偏离**（0.382=1.071、0.618=1.222；平台/缺口 1.12–1.14；POC≈1.00）。〔已核验〕
4. **8/3 的「预期」不是确认信号，是一个六要素情景**：浪型（指数 4-3 底→4-4，科技 ABC 的 B 反）、市场/GJD/量能（缩量 5500E、半导体尾盘放量割肉、银行缩量诱多、3800 真金白银）、赔率（0.828→1.15 约 +38.7%，失效 3800/0.82；按破位后 ETF 估 −6%~−8% 计，赔率仍约 5–6:1）、工具（ETF）、T（一次性、涨上去舍得卖）、失效/C 杀（后面还有 C 杀）。〔已核验：原话〕
5. **预期日 ≠ 恐慌低点 ≠ 实际反转日**：8/3 11:20 是预期日；恐慌低点是 8/3 14:56 的 0.828 与 8/4 09:33 的 0.824（后者更低）；实际反转日是 8/5（首根收盘站上 MA5，+9.70%，指数 +1.47% 且量能 +20%）；「3 天站上 5 日线」的确认要到 8/7 收盘。〔已核验〕
6. **目标没到，但 B 反确实成立**：8/18 高 1.107（=1.15 的 96.3%，差 −3.74%），当天他 14:39 说「170 到 1.1 以上了 接近我的第一目标位」并减底仓；8/19 C 杀 −7.43%，到 10/19 收 0.790（−28.4%）。〔已核验：NGA 19269 楼 + 数据〕
7. **`b_rebound` 标签不可用的原因已定位到代码**：`apps/main_line/wave_ladder.py:750` 的定义是「收盘较 20 日低点 ≥3% 且低于 20 日高、低于前 60 日高」——这是**区间位置标签**，不是结构标签。所以 8/3（+1.2%）为 False、8/5（+3.0%）为 True、2025-09-04 A 杀日反而为 True。〔已核验：代码 + 状态文件〕
8. **历史对照的判别器是「半分位 + 前高 + 量能」**：2025-08-01、2026-03-30、2026-04-20 的 B 反都越过了半分位并升级为新高趋势段；2026-08 的 B 反止步于半分位、随后 C 杀；2026-05 是升级后的 3-5 末段（已不是 B 反），5/21 由小级别 B 反接 C 杀。**「过半分位放量」是升级条件，「到半分位缩量转向」是 C 杀条件**（5/22 原话的直接推论）。〔案例验证，n 小〕
9. **可统计验收的只有「描述性 case series」**：目前能自洽标注的 B 反事件只有 6 个（2025-08-01、2026-03-30、2026-04-20、2026-05-11、2025-09-04、2026-08-03），不足以估计胜率或阈值。任何「B 反识别模型」目前都只能是案例验证 + 情景决策，不是统计模型。〔结论〕

### 2.6 `b_rebound` 标签的机械定义——为什么不可用

`apps/main_line/wave_ladder.py:750`：

```python
"b_rebound": bool(lo20 and (close / lo20 - 1) >= B_REBOUND_MIN and close < hi20 and close < hi60_prev)
# B_REBOUND_MIN = 3%（WOLF_WAVE_LADDER_BREB，可调）
```

即「**收盘较 20 日低点反弹 ≥3%，且还没创 20 日新高、仍低于前 60 日高**」。这是**区间位置**，不是浪型结构：

| 日期 | close | lo20 | close/lo20−1 | close<hi20 | b_rebound | 实际含义 |
|---|---|---|---|---|---|---|
| 2026-08-03 | 3809.66 | 3764.15 | +1.21% | True | **False** | B 反预期日，但反弹幅度还没到 3% |
| 2026-08-04 | 3822.28 | 3764.15 | +1.54% | True | **False** | 真正的低点日 |
| 2026-08-05 | 3878.43 | 3764.15 | +3.03% | True | **True** | 刚过 3% 门槛，晚 2 天 |
| 2026-08-17 | 3982.65 | 3804.69 | +4.7% | **False**（收盘=20 日高） | **False** | B 反顶部，标签反而消失 |
| 2025-09-04 | 3765.88 | 3635.13 | +3.6% | True | **True** | **A 杀日反而为 True** |

→ 结论：`b_rebound` 是「反弹超过 3% 但还没新高」的滞后区间标签。它**在预期日必然为假、在 C 杀日可能为真**，不能当 B 反起点/终点标签。代码注释（`apps/main_line/wave_ladder.py:877`）也承认口径不一致：「他 2026-08 在做的那段，我们叫 4-5、他叫 B反」。

### 3.2 H1（半分位）的证据链

1. **数值**：用 11:20 当时已知的最低点 0.837，`(1.465+0.837)/2 = 1.1510`，与 1.15 只差 0.09%。
2. **实时性**：0.828 的低点在 14:56，晚于 11:20；所以若用 0.828，则属于「事后巧合」。但 0.837 在 10:25 已出现，11:20 完全可算。
3. **教义**（他的原话，直接支持「半分位」是反弹/反转的分界）：
   - 2026-05-22 14:33：「放量下跌 一定需要过下跌浪的**半分位** 然后缩量转放量再冲 才能高看一眼 如果到**半分位**缩量 然后向下，那就是C继续。」
   - 2026-08-17（`docs/wolf-daily-log-nga.md`）：「反弹只要没有放量冲破**半分位**那都是反弹 不是反转。」
   - 2026-08-17 同日的「放量过了3970」= 4175.35↔3764.15 的半分位 3969.75（数值吻合）。
4. **跨品种一致**：指数 4-4 顶 3994.18 停在 4000/4011 半分位下方 0.15%/0.43%；ETF 1.107 停在 1.1465 半分位下方 3.4%。**同一个规则在两个品种上都表现为「到半分位附近止步」**。
5. **折算口径**：要得到 1.465 必须做「4.395/3」的折算换算；这不算强假设，因为他是这只 ETF 的活跃交易者，且折算就发生在 7/3。

### 3.3 H2（前低 1.149）的证据链

1. **数值**：7/6 低点 1.149，取整即 1.15，误差 0.09%。
2. **零换算**：在折算后图表上直接可见，不需要 ÷3，也不需要预判低点。
3. **教义**：他确实用「前低」当反弹目标——2025-10-19 23:17 对读者「目标价放在320前低附近」的做法未否定，反而接着讲画线；2025-12-11 21:23「放量跌破就是C杀……直接看前低」。
4. **弱点**：1.149 是**折算日**的低点，是 7/1 暴跌的延续低点，不是「平台/颈线」意义上的结构低点；把它当 B 反目标，等于把「下跌中继的低点」当「反弹阻力」，技术上不如半分位硬。

### 3.4 H3–H6 为什么被排除/降级

- **H3 斐波那契**：他确实只用 0.382/0.618（2026-03-05 21:29「黄金分割只用0.382和0.618」；2026-02-26 12:55 给出 Excel 公式 `=E3-(E3-D3)*0.382`）。但 1.465↔0.828 区间的 0.382=1.071、0.618=1.222，都不是 1.15。→ **「他用了斐波那契」这个说法对，但「1.15 是斐波那契位」这个说法错**。
- **H4 平台/缺口/VWAP/POC**：7/14–7/17 的平台/缺口在 1.12–1.14；VWAP 1.11；POC 1.00。都不是 1.15。→ 否定。

### 3.5 一个反证：目标位偏高了

- 若用「指数半分位 × beta」估，ETF 合理目标 ≈1.12；实际顶 1.107，正好在 1.12 下方 1%。
- 1.15 是 ETF **自身** A 段（1.465→0.837）的半分位，而 1.465 是 7/1 的**个股性逼空高点**（指数 7/1 并未创新高，指数前高在 5/14）。**用一个不同步的、idiosyncratic 的高点算半分位，会把目标算高**。
- 这解释了为什么「1.15 没到、只到 1.107」：市场最终按指数同步的半分位（≈4000）定价，而不是按 ETF 自身那个被逼空拉出来的 1.465。

### 3.6 A 的结论

- **有证据的**：1.15 是「半分位（1.1465–1.1510）」与「前低（1.149）」的**合流区**；半分位有实时计算 + 教义 + 跨品种一致三重支持，前低有零换算 + 教义支持。两者数值不可区分。
- **是猜测的**：1.15 的**唯一**推导路径；「他当时按 0.837 算的」；「他用了指数×beta」。
- **被否定的**：0.382/0.618、平台/缺口/VWAP/POC、纯整数。
- **实操含义**：把 1.15 当**减仓区上沿**，不要当必达点；合理减仓区 **1.10–1.15**（1.10 = 已实现高位/8/18 实顶，1.15 = 半分位/前低上沿）。

### 5.2 分类学（不是二值标签）

把「B 反」拆成五个可操作状态，而不是一个布尔标签：

1. **B 反观察（预期日）**：结构上 A 段可能结束，但价格/量能未确认；赔率够、失效位明确。例：2025-08-01、2026-08-03。
2. **B 反中段**：已反弹、未到半分位/前高，量能温和。例：2026-03-30、2026-04-20（上半段）。
3. **B 反升级（→ 趋势段）**：放量过半分区/颈线，且随后破前高。例：2025-08-05 之后、2026-04-22 之后。**此时「B 反」标签应作废，改按上升段管理。**
4. **B 反结束（→ C 杀）**：到半分位/前高附近，缩量滞涨、上影线，随后放量破位。例：2026-05-14→5/21、2026-08-18→8/19。
5. **A 杀（不是 B 反）**：仍在 A 段主跌，放量破位/跳空未收回；此时任何反弹都是 A 段中继，不是 B 反。例：2025-09-04 当天。**2025-09-04 不能算 B 反。**

### 5.4 2025-09-04 的原文再核验（对任务前提的一个修正）

任务说「2025-09-04 狼大原话定性『主线 A 杀』」。原文（`xlsx` 2025，2025-09-04 22:23）是：

> 「还是那句话 9.1-9.4别的大部分都是-20%了 我这里最多从+17%回撤到+12%。…… 指数上低点就是今天低点3732，可能明天有顺势再探一次这种位置…… 上面压力3808，中间强弱分水岭就是3761…… **还是那句话 主线A杀的话就不可能有指数新高。这不合理**。」

### 5.5 对照得到的三条规律

1. **B 反的默认结局是「反弹」，不是「反转」**：6 个案例里，2025-08、2026-03/04 升级为新高趋势段；2026-05、2026-08 止步于半分位后 C 杀；2025-09-04 是 A 浪洗盘（一个月后仍新高）。**升级需要放量过半分区+破前高，缺一不可。**
2. **「弱 B 反」不等于「小反弹」**：2025-08-01 他判「3 小时、弱」，结果两周后指数 +9.5%、170 +20%。**幅度判断可以错，方向/结构判断不能错**；错在幅度时，靠「B 反没完，不要怕」+ 8/5 的放量站线规则修正。
3. **B 反的 C 杀通常是「先缩量拉、后放量杀」**：8/18 量比 0.83 → 8/19 量比 1.08；5/14 冲高回落 → 5/21 放量 −2.04%。**顶部不是放量出来的，是缩量拉出来的**（这也解释了他 8/18 13:24「缩量才对，要是继续放量今天就芭比Q了」）。

### 6.4 目标区

按优先级：

1. **第一目标（减仓区）**：A 段 **50% 半分位** ∪ **A 段中继前低**。
   - 2026-08：目标上沿 = 1.1465–1.1510 ∪ 前低 1.149；**实操减仓区从 1.10 起**（8/18 实顶 1.107 正落在区间下沿）。
   - 指数：4000–4011（实顶 3994）。
2. **第二目标（仅在 C3 确认后）**：0.618 半分位（2026-08 为 1.2217）或前高（1.439/1.465）。
3. **交叉验证**：若个股/ETF 的 A 段高点与指数不同步（如 170 的 7/1 逼空高 1.465），**优先用指数半分位 × beta 估**（2026-08 给 1.12），把自身半分位当上限。
4. **减仓纪律**：到目标区**不等精确点位**；8/18 他在 1.104 就减了（1.15 的 96%）。「到了目标点位走弱了、不及预期了、冲不上去了，才要做减法」（8/17 15:45）。

### 7.2 验证协议（可执行，但先承认 n 小）

1. **标签来源**：只用狼大原话里的「B 反/弱 B 反/B 反高点/C 杀/A 杀」定性，**不用** `b_rebound`（第 2.6 节已证伪）。
2. **事件研究**：每个事件算 T+1/3/5/10/20 的 MFE、MAE、是否先到目标、是否先破失效、峰后 20 日回撤。
3. **基准率对照**：同样本区间所有交易日的 T+5/T+10 收益分布，与事件日对比（避免「牛市里随便买都赚」的假阳性）。
4. **规则评估**：对候选规则（3 日 MA5、放量过半分区、缩量滞涨）算 precision/recall；**必须报告 FP 的具体日期**（例如 2025-09-04 这种 A 杀日）。
5. **样本外**：2025 事件做校准、2026 事件做检验；或 leave-one-out。**在 n<20 前不报告显著性。**
6. **执行可行性**：ETF T+0、涨跌幅、成交量是否支持目标仓位；滑点按 0.2% 计。

### 7.4 哪些能统计验收、哪些不能

**能（描述性/机制性）**：
- `b_rebound` 的机械定义与误报机制（8/3 False、8/5 True、9/4 True）——**已用代码 + 数据证实**。
- 1.15 与「半分位/前低」的数值关系——**已用数据证实**（1.1465/1.1510/1.149）。
- 8/18 顶部的「缩量拉、放量杀」——**单案例已证实**（量比 0.83 → 1.08）。
- 指数 4-4 顶停在半分位下方（3994 vs 4000）——**单案例已证实**。

**暂不能（需要更多样本/数据）**：
- B 反策略的胜率、盈亏比、最优阈值（3% vs 5%、MA5 vs MA10）。
- 「半分位」是不是普遍规律：本文的 zigzag 探索（index 2025–2026，阈值 2.5%）显示**未升级的反弹 ratio 中位数约 0.66、分布 0.55–0.97**，0.5 只是其中一种；**样本小、口径粗，不能当统计结论**。
- 1.15 到底是 H1 还是 H2——**无法用事后数据区分**。
- ETF beta 稳定性、跨板块可迁移性。
- 「预期日」的可自动识别性——目前只有 2 个明确预期日（2025-08-01、2026-08-03），不足以训练/验证。
