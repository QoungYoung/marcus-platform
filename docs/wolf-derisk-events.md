# 狼大减仓/清仓事件总表（按日期）

> 目的：把“他哪天、因为什么、减到多少”一条条列出来，供逐条落地。
> 来源：`docs/wolf-stop-loss-ledger.md` 的 A/B/C/D/E/H 组；只收**减仓/清仓/降仓**，不收纯原则和“不该卖”。
> 类型：`实`=他说已经做了；`条`=条件计划（如果 X 就 Y）；`规`=可复用规则；`述`=描述别人/量化，不是他本人动作；`持`=保持/不减。
> 落地：`日线`=收盘/点位可判；`盘中`=要 15min/分时/量能；`宏观`=要 30 年债/外资；`人工`=需要人判断。
