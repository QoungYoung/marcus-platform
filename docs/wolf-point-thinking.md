# 狼大怎么选点位：可给 agent 的思考框架

> 目标：不给具体点位，只给他的**选点方法**，看 agent 能不能自己选出同类结构。
> 本轮给了 A-F 六个 case（A-D 之前用过，E/F 是留出），输入无狼大原话/点位，只有 as-of 数据 + point_engine 全量候选。

## 1. 他的选点过程（从账本/溯源反推）

1. **先定位置/级别**：主升、调整、下跌 1 浪；大级别（指数）优先于个股。位置没定，不选点。
2. **找合流**：一个关键位至少 2 个结构叠在一起：
   - 前低/前高/平台、缺口上下沿、颈线/趋势线、MA20/34/60/144/200、BOLL 中轨、整数关、成本密集区；
   - 单一缺口边缘/当日高低权重最低，不能单独当关键位。
3. **点位是区间**：3922 是 3912-3929，3888 是 3888-3891，3370 是 3365-3377；输出 zone，不是单点。
4. **分角色**：
   - 下方未破 = `support_holding`；
   - 上方刚破 = `support_broken` / `reclaim_threshold`（站回才算修复）；
   - 上方未破 = `resistance`；
   - 失效线 = `invalidation`。
   已跌破的位不是普通压力，它的作用是“站不回就确认”。
5. **梯子/优先级**：第一档、第二档、第三档。第一档是“破了/站不回就确认”的结构线；不要跳到远端最强位。
6. **确认**：收盘确认、放量直接算、缩量等反抽、跌破前低要 3 个 15min 不收回；盘中不算。
7. **不确定就不选**：没有 2 个以上合流、角色不清，输出 `no_confident_level=true`。

## 2. 给 agent 的 prompt 骨架（不含具体点位）

```
你是点位分析器。先定位置/级别，再找合流；点位是区间；按 holding/broken/reclaim/resistance 分角色；
按“第一档/第二档/第三档”排序；第一档是站不回就确认的结构线，不是最近缺口边缘、也不是远端最强位；
收盘确认、放量直接算、缩量等反抽、3×15min；不确定就 no_confident_level。
只能用候选表 id/price，不得发明价格。
```

## 3. A-F 测试结果（无他的点位）

| case | 他的第一档 | agent 框架输出 | 偏差 | 判定 |
|---|---:|---:|---:|---|
| A 2025-06-20 | 3370 | 3372.40 (MA20) | +0.07% | ✅ |
| B 2025-11-21 | 3922 | 3898.66 (MA60/3900) | -0.60% | ❌ 选了第二档 |
| C 2025-11-24 | 3922 | 3898.85 (MA60/3900) | -0.59% | ❌ 选了第二档 |
| D 2025-12-03 | 3888 | 3902.18 (MA60/3900) | +0.36% | ✅ 但选的是 3900，不是 3888 |
| E 2025-08-28 | 3856 | 3844.33 (MA5) | -0.30% | ✅ |
| F 2025-11-18 | 3950 | 3966.89 (前高/缺口) | +0.43% | ✅ |

**4/6 在 ±0.5% 内**，但 B/C 仍然把 **3922 换成 3900**。

## 4. 为什么 B/C 还是错

- 3898.66/3898.85 是 **MA60 + 3900 整数 + 前高**，结构数多、离现价更近；
- 3922 是 **前低 + 缺口 + 颈线 + 量度位**，位置更高、离现价 2.2%；
- agent 按“更强的合流/更近”选了 3900，而狼大的梯子是 **先 3922、后 3900**。

这不是“结构识别”错，是**优先级**错：
**3922 是第一档、3900 是第二档，这个顺序来自他的叙事，不是价格数据能推出来的。**

## 5. 结论

1. 他的框架可以给 agent，而且 **A/D/E/F 四例能选到 ±0.5% 内**；
2. 但 **B/C 的 3922→3900 顺序，agent 靠数据推不出来**；
3. 所以 agent 适合做 **候选/合流/角色/区间**，不适合单独决定“第一档是谁”；
4. 最终 `risk_trigger` 应该由 **case 库里的第一档/第二档** 或人确认，而不是让 agent 从“更强/更近”里猜。

一句话：**框架能教会它“什么算关键位”，教不会它“他心里的第一档是哪一档”。**
