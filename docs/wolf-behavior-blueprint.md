## §1 他的一天（按时间轴）

### 1.1 盘前（约 08:00–09:30）
- **看外围**（美股/A50/金龙/关税/隔夜消息）→ 判"今天开盘是高开还是低开、是黄线还是白线在上"。
  2025-08-13「结合我今晚和机构的聊天 然后结合今晚美股那边的开盘 **明天走势平开和小高开的几率很大**」
- **定档位**（能不能做、做多大）：由**浪型/级别**决定，不是由情绪决定。
- **定预案**：2026-08-19「急啥啊。。**我不是在等吗 预案都有了**」——他不是没计划，是**有计划地等**。
- 明确写"今天买不买"：2026-08-19「我昨天有没有说过，**我说我不买**，我觉得买什么都是加大亏损？」
  （当天是减仓/等待日）

### 1.2 盘中（只在他认可的时机动手）
**做 T 的口诀（2026-08-12 10:30 原话）**：
> 「指数就是这里缩量波动，**不具备指导性**，板块轮动，**有拉起来你就丢，如果无利空跳一下就买**，这不是基础知识么。」

**买卖的判定标准（2026-08-12 11:24 原话，极重要）**：
> 「**我买卖的理由不是他涨得多还是跌得多，是我买了 他就要能涨，我卖了 他就不会涨**，仅此而已。」

**卖出的理由（2026-08-12 11:30 原话）**：
> 「**卖不是因为他会回调，而是在他不会涨的时候防止他可能会大回调**；如果大回调了，那就两吃；
> 如果不回调，就去别的地方吃一波，那还是两吃。我卖了如果他大涨，就是卖飞。」

**买点（2026-08-12 13:32 原话 + 动作）**：
> 「**趁小跳买了一部分半导体。幅度不够大，买不了太多。逻辑很简单：量能开始缩转放了。**」

**T 仓当天处理（2026-08-12 13:18）**：
> 「（药还有持仓吗）**T+0 的没必要留里面，有机会的时候摁进去就行了，我这个平时不留仓位的。**」

**兑现口径**：

**三条修正结论**（比上表更重要）：
1. **他每天真正在做的事是"判断"，不是"交易"**：判据类动作 30.4%，而**所有成交类动作合计只占 27%**
   （建仓 8 + 加仓 3 + 减仓 10 + 换股 7 + 逃顶 5 + 止损 2 + 做 T 35 = 70 次）。
   → **我们系统的重心应当是"每日决策对象"（判据→档位→仓位），而不是继续加买点/卖点腿**。
2. **"等待 + 纪律 + 仓位"合计 33%**（埋伏 21 + 纪律 33 + 仓位 33 = 87 次）——这三类在我们系统里几乎**只是注释**。
3. **"止损"30 天里只出现 2 次**，与生产端"止损六层几乎不触发"**是同一件事**：
   他的保护不是靠止损，而是靠 **①不追高 ②不在地量割肉 ③周末/事件前减半避险 ④看不懂就不做**。
   → G8（止损口径复核）的正确答案可能不是"让止损更容易触发"，而是**把这四条做成前置约束**。

## §3 他的决策循环（闭环）

```
① 判环境（浪型/级别 + 外围 + 量能）        → operation ∈ {build, t_only, side, defense, exit}
② 定仓位（由 operation 决定目标与底线）    → 75% / 50% / 30% / 不做
③ 选方向（复盘找"唯一对的那个"）★核心      → 主线/主题 + 梯队健康 + 资金流入
④ 选票（方向内选强、绝不后排）
⑤ 买点（等：确定性 > 位置；缩量转放量 / 挂前低 / 不破支撑）
⑥ 持有/做T（有拉起来就丢，无利空跳一下就买；T+0 不留隔夜）
⑦ 兑现/换方向（吃一口减一半；不涨就换地方吃；卖弱留强）
⑧ 保护（收盘确认破位才走；指数大级别转跌就止损；顶部阶段全止盈）
⑨ 回到 ①（复盘记录 + 次日计划）
```

**四条贯穿全流程的铁律**
- **预期驱动，不是价格驱动**：2026-08-12「**我买了 他就要能涨；我卖了 他就不会涨**」
- **确定性优先于位置**：「不是位置的高低，是买进去之后的确定性」
- **不确定就等**：「更多的时间就是等」「老老实实发呆有那么难吗」
- **只做自己的体系**：「不是我的体系」→ 不做（超短龙头/民爆/家居）

## §4 分层优先级（**这是当前系统最缺的东西**）

| 层 | 内容 | 谁决定谁 | 他的一天 |
|---|---|---|---|
| **L1 方向** | 主线/主题 + 梯队 + 资金 | 决定"做不做、做哪个" | 复盘产出 |
| **L2 档位** | operation（build/t_only/side/defense/exit） | 决定"能做什么腿型" | 盘前波浪 |
| **L3 仓位** | 目标仓位 + 现金底线 + 利润垫 | 决定"做多大" | 盘前 |
| **L4 选票** | 方向内选强、去弱留强 | 决定"买哪只" | 盘前+盘中 |
| **L5 买点** | 时段/形态/量能/挂单 | 决定"几点买、什么价" | 盘中 |
| **L6 兑现** | 吃一口减一半/破线走/顶部止盈 | 决定"什么时候退" | 盘中+盘后 |

**当前系统的问题**：六层是**平铺**的——L5/L6 的机制（A5 时间窗、A9 谨慎闸）会**直接拦掉 L1–L4 已经选出的买入**。
他的顺序恰恰相反：**先方向、再档位、再仓位，细节服从上层**。
（狼大 2026-01-27「**做超额是第四，首先要做好 123 才有 4**」正是这个优先级。）
