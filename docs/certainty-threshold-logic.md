## 3. 证伪/不买条件

| 证伪信号 | 原话 | 含义 |
|---|---|---|
| 主线不动 | 看是不是真反弹还是诱多 很简单 看看主线题材动没动(1-13) | 反弹/确认必须有主线题材响应 |
| 缩量拉避险 | 量能没有继续放大的情况下 拉了银行 石油 贵金属避险方向...追早上涨方向直接耻笑(8-05) | 缩量+拉避险=诱多/无承接 |
| 不过压力 | 不过压力 减出去 等M头形成(2-03) | 突破压力失败=证伪 减仓等M头 |
| 量能回退 | 量能没有回退1000E以上今天就不是高点(4-08) | 顶部判定(反向) |
| 诱多识别 | 今天缩大量拉的银行是纯骗(8-03)；缩量我根本不怕 等转放量(8-04) | 缩量拉涨=诱多；等转放量 |
| 不追高 | 诱多期不要追高 除非突发大级别利好(3-20) | 确认未完成不追 |

## 4. 操作纪律（狼大原则）

1. 只做确定性行情：我只做确定性的行情(2-04)；等新资金确认技术结构 然后等他们进来(3-25)
2. 不在最低点割肉：可以不买在最低点 也可以不卖在最高点 但是绝对不能在最低点割肉(3-18)
3. 确认突破才加仓：真正尾盘确认突破就不用T出去了 相当于加仓(1-28)
4. 分批等止跌：借业绩MISS止跌后去抄底 很有性价比(2-02)
5. 套利视角：从缩量转放量的时候就是有人在套利了 肯定不是散户(3-24) —— 缩转放是主力行为信号

## 5. 与现有模块的关系

- position_class LOW 埋伏候选：LOW+资金流入+逻辑 → 只是候选，真正入场等确认链（缩量止跌→W底/双底→放量突破颈线→站稳）——正是 2026-06 提前抄底失败案例缺的环节
- 回踩低吸(dip_buy_strong)：主升期回踩二买位 = 确认链的回踩环节（趋势未破+缩量回踩）
- 浪型 gate：防御期(下跌浪/C杀)不抄底 = 确认链的下跌环节不能接飞刀

## 6. 规则草案（待 code 化）

确认链(买入)：
  S1 缩量止跌：vol 连续收缩(vol_z20<0 或 vol_pct120 分位低) + 价格止跌(r20 跌幅收窄/十字星/揉搓线)
  S2 结构到位：W底/双底(两个相近低点) 或 低位横盘≥N日(筹码沉淀)
  S3 放量突破：突破颈线/平台/MA20 且 vol 放大(vol_z20>1.5 或 量比>1.5)
  S4 站稳确认：突破后 N 日站稳(收盘不破颈线/站稳3天) + 量能持续(不缩回)
  → 全部满足 = 右侧确认买入；部分满足 = 埋伏候选(低吸)不重仓
证伪(不买/离场)：
  F1 缩量不转放量(突破无量) → 假突破
  F2 突破后回落颈线 → 证伪离场
  F3 主线题材不动(无响应) → 反弹非反转
  F4 缩量拉避险(银行/贵金属) → 诱多不追
时间窗：15分钟/日K 站稳中轨 3 根；站稳 3 天
