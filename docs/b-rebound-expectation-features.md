## 初步共同点

```text
预期日：
  单日下跌
  低点在下午（13:39 / 14:56）
  低点放量
  收盘位置低（0.28 / 0.01）
  低点后当天反弹弱（+0.67% / +0.12%）

中段：
  单日上涨
  低点在开盘
  收盘位置高（0.94）
```

## 但不能说这就是规则

只有 2 个预期日样本，且 2025-08-01 是“弱 B反”，2026-08-03 是“恐慌 B反”，量级差很大。
