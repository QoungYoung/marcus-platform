# 狼大的决策窗口：他什么时候看，什么时候走

> 先定窗口，再问 agent。下面按 A-J 判例拆：**观察窗口 / 确认方式 / 执行时点 / 动作**。
> 时间均为交易日盘中；`14:30`=2:30，`14:45-15:00`=尾盘。

## 1. 总表

| case | 日期 | 他的点位 | 什么时候看 | 确认方式 | 什么时候走 | 动作类型 |
|---|---|---|---:|---|---|---|
| A | 2025-06-20 | 3370/3375 | 盘中，探底后 | 回拉到 3370/3375 带 | **反抽到带内就出** | rebound_exit |
| B | 2025-11-21 | 3922/3900 | **收盘** | 收盘跌破；盘中不算 | 收盘确认后 | close_break |
| C | 2025-11-23 | 3922 | **日线收盘** | 没有站回 3922 | 确认未站回后 | reclaim_failure |
| D | 2025-12-03 | 3888/3850/3816/3922-3930 | **收盘** | 收盘没站上/跌破/企稳 | 收盘确认后 | close_break / reclaim |
| E | 2025-08-28 | 3856 | **收盘前** | 收盘不到 3856；缩量不急 | 收盘确认 | close_threshold |
| F | 2025-11-18 | 3950 | **尾盘 14:45-15:00** | 尾盘不站回 3980-3986 | 尾盘/收盘 | tail_confirm |
| G | 2025-12-11 | 3876.47 | **盘中** | 跌破前低 + **3 个 15min 不收回** | **等反抽再减** | intraday_3x15_rebound |
| H | 2026-01-14 | 4141 | **盘中** | 再破 4141 + 放量 + **3 个 15min 确认** | 确认后当日下调 | intraday_3x15_volume |
| I | 2025-09-04 | 3761 | **14:30 定点** | 2:30 时点确认跌破 | **14:30** | time_specific |
| J | 2025-08-01 | 3560 | **盘中实时** | **快速放量**跌破 3560 | **放量破位即时** | intraday_volume_fast |

## 2. 分四组看

### 组 1：收盘/尾盘确认（B/C/D/E/F）

- 看：14:45-15:00 或收盘；
- 走：收盘确认后，或尾盘；
- 特点：**盘中跌破不算**，缩量/急跌也不急。

### 组 2：盘中 3×15min 确认（G/H）

- 看：跌破后 45 分钟（3 根 15min）；
- 走：
  - G：3×15min 不收回 → **等反抽**再减；
  - H：3×15min + 放量 → 当日下调；早上没减的这时减。
- 特点：不是一破就走，确认要 45 分钟。

### 组 3：定点（I）

- 看：**14:30**；
- 走：14:30；
- 特点：不是收盘，也不是一破就走，是**到了 2:30 这个时点**才执行。

### 组 4：实时量能（J）

- 看：盘中实时；
- 走：**快速放量跌破**即减半；
- 特点：唯一“当下破、当下走”的类型。

### 特殊：反抽卖出（A）

- 看：盘中探底后；
- 走：反抽到 3370/3375 带；
- 特点：不是破位止损，是**破位后找反抽出**。

## 3. 窗口 schema（给 agent 用）

```json
{
  "phase": "intraday|tail|close|post_close",
  "decision_time": "14:30",
  "observation_start": "09:30",
  "confirmation": "close|tail|3x15|volume|time_specific|rebound",
  "confirm_bars": 3,
  "execution": "immediate|at_close|at_tail|after_3x15|on_rebound|at_14_30",
  "data_warning": "今天未收盘；today_low/high 只到 decision_time"
}
```

## 4. 一句话

**他不是统一“破位就走”：**
- B/C/D/E/F 等收盘/尾盘；
- G/H 等 3×15min（G 还要等反抽）；
- I 等 14:30；
- J 放量即时；
- A 是反抽卖出，不是破位止损。
