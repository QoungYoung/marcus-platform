## 3. 结论

1. **旧整概念黑名单确实大面积误拦**：E06-E12 中 E10(国算)、E11(材料)、E12(半导体低吸非重仓) 放行后前向 20 日大幅为正（+10~+44%），属于最确定的误拦；E07/E08 部分轻仓设备/封测股也被误拦。
2. **E06(旭创/新易盛)不应被当作误拦**：n=15 / float 7-10%，新规则继续拦，是“风控分歧”而非 bug。
3. **E09 需谨慎**：低位封测代理篮子放行后前向全负（均值 -17%）。该事件狼大是“减高换低”的避险切换，代理篮子可能没对准实际买入（他还切了地面光伏等）；不能只凭“放行=好”，需对 E09 单独校准篮子或标记为“不推荐放松”。
4. **E13 与旧口径不同**：国算当时“拥挤但有空间”，旧口径本来不拦；新规则额外拦了海光 688041（6基金/3.49%，fwd-20.5%）——说明新规则在“拥挤但有空间”里仍能拦下核心公募重仓，行为正确。
