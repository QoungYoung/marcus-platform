## 3. 差距与局限（诚实清单）

1. **概念级量能用 net_amount 抛压代理**——狼大看真实成交量；只有指数级(index_daily)是真实 vol/amount
2. **15 分钟级站稳未实现**——狼大'3个15分钟站稳中轨'是日内级别，我们只有日K 3日
3. **F3 主线题材响应未接**——'真反弹看主线题材动没动'需要 main_line 信号联动
4. **F4 诱多识别未接**——'缩量拉避险=诱多'可在指数级加(银行/贵金属量能对照)
5. **个股级确认链未做**——狼大是'指数+板块+个股'三层，我们两层
6. **回测限制**：确认样本 14 个、60 日窗口不足——方向可信精度有限

## 4. 总体结论

1. **核心语义一致**：缩量止跌是前提、放量突破是关键、站稳是确认、指数先确认——四条狼大确认链主骨全部对齐，决策规则(候选 vs 可执行)贴'买在确定'
2. **行为模式一致**：回测显示确认链拦截了狼大 6 月同样没做的提前抄底、放行了 7 月筑底后的参与——不是'看起来像'而是'行为轨迹一致'
3. **定位一致**：扩样本后确认链是风控工具(避免极端接飞刀)非 alpha 增强——与狼大保守风格('只做确定性行情')一致
4. **剩余差距**：15 分钟级、主线响应(F3)、诱多(F4)、个股级——都是量/时间粒度问题，语义方向已锁定
