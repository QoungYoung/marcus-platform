# 给 agent 加“位置偏好”后的盲测

> 在狼大的选点方法上，再加一条**位置偏好**（仍不给具体点位/日期/原话）：
> - 优先结构拐点（前低/前高/平台/缺口/颈线），均线/整数/当日高低只作合流；
> - 破位后先看“这波下跌/上涨起点的那条结构线”（第一档），不选更近的均线、也不选远端最强位；
> - 同一波里优先更高的已破结构线；新的一段优先最近一段的起点结构；
> - 冲突时，优先“当前这一段刚失守、还没修复”的那条。

## 1. 结果：5/6 命中，1 条主动不选

| case | 他的第一档 | agent risk_trigger | 偏差 | 判定 |
|---|---:|---:|---:|---|
| A | 3370 | 3365.67（swing_low，当前段起点） | -0.13% | ✅ |
| B | 3922 | **3922.58**（前低/颈线/缺口） | +0.01% | ✅ |
| C | 3922 | **3922.58** | +0.01% | ✅ |
| D | 3888 | **3885.31**（12/1 缺口+颈线） | -0.07% | ✅ |
| E | 3856 | **null（no_confident_level=true）** | — | ⚪ 主动不选 |
| F | 3950 | 3963.10（缺口上沿） | +0.33% | ✅（同一缺口区上沿） |

## 2. 它这次为什么对了

- **B/C**：它没有选更近的 MA60 3898.66，而是选 **3922.58**，理由写的是“11/5 前低/10/30-11/14 颈线，是 11/14 冲 4034 那一段的起点结构；同波已破结构线中最高且未修复”。
- **D**：它没有选更高的 3922，而是选 **3885.31**，理由是“12/1 向上跳空 + 8/28-9/4 颈线，是当前这一段刚失守、还没修复的那条；3922 是更早一段的起点，按位置偏好排后面”。
- **A**：它选 3365.67（6/10 前低，当前段起点），不选 3386.92（前日高，无结构拐点）。
- **F**：它选 3950.0-3963.1 缺口区，不选更高的 4025.70/3992.40。

这说明“位置偏好”确实能改变它的选择：从“更强/更近的均线”转向“当前段起点的结构线”。

## 3. 但还有两个问题

### 3.1 E 主动不选

E（2025-08-28，他 3856）agent 输出 `no_confident_level=true`，理由是：

> 近端只有 8/25 缺口（3825.76-3839.97）一条结构，3844.33/3850 只是 MA5/当日高/整数，不满足“两个结构叠合”，所以不选。

这符合“不确定就不选”，但代价是**漏掉 3856**。说明“至少两个结构”这条门槛在 E 上过严，或者候选里缺少 3856 的结构来源。

### 3.2 这轮仍然不是干净盲测

- B/C/D/A 的“位置偏好”是看着前几轮失败案例总结的；
- E/F 是留出，但只有 2 条；
- F 命中是同一缺口区的上沿（3963.1）而不是他说的 3950，偏差 0.33%，算“同区”不算精确。

## 4. 结论

1. **位置偏好是他策略的一部分，而且能明显改善选点**：B/C 从 3898 回到 3922，D 从 3912 回到 3885。
2. 但它仍是**先验规则**，不是数据能自动推出的；必须用更多留出案例验证。
3. E 的 `no_confident` 说明“两结构门槛”需要放宽或补候选；F 说明缺口区上下沿要按“区间”而不是单点评分。
4. 下一步：用 **G/H 新 case**（不参与规则修改）做留出；如果还能 5/6，才考虑把这套写进生产 prompt。

一句话：**告诉他“先选当前段起点的结构线，均线/整数只作合流”，B/C/D 就顺了；但这条规则本身也要用新案例验证，不能又变成看着答案调参。**
