## 读法（P5a 结论）

1. **B3 硬闸确实压左尾，但代价不小**：最大回撤 −11.28% → −8.98%（recover 臂），总收益 28.53% → 17.14%；本质是保险，保费约 11pp。
2. **在 2025-2026 这段样本上，MA60 比 B3 更优**（+20.37% / −9.57% / Sharpe 1.32）：B3 的多级 level 触发更碎（40 次交易），不如单一 MA60 稳。
3. **norecover 臂不能当策略看**：一次 B3 后长期低仓（平均仓位 41% / 30%），收益低是因为“不再回来”，不是止损本身好。
4. **因此 P5a 不支持开启 `execute_index`**。P5b 至少要把：个股 B2（默认 alert）、as-of 浪型、点位→仓位表、以及“收回后恢复”的状态机纳入，再决定是否接线。

> 口径说明：仅指数级 B3 硬闸；不含个股 B2（个股默认 alert，P5b 单独做）；wave_op 固定 side（历史 wave_state 不连续）；不含滑点/停牌。
