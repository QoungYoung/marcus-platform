## 五天读出来的三件事

1. **我们的结论五天都是「不做」，而且都对——但这是资格审核的正确，不是交易的正确。**
   11/04 收盘上证 +2.16%、创业板 +6.40%；11/06 他的 PCB 吃到了超额。我们的「对」没有变成任何收益，也没有变成任何一条可执行的下一步。

2. **我们的理由全在资格层，而且开盘前就已确定。**
   wave 档位（11/03 判定、T+1 生效）+ L0 月度 weak + P3 无 probe——这三项在盘中都不会变。所以 14:20 的推送不是「盘中做出的决定」，是「把盘前结论补齐理由」。狼大的理由全在结构层：缩转放、双脚、二段跳、套牢盘成本、子链属性。

3. **唯一真正的分歧是 11/04，因为那天是唯一「结构成立、资格不成立」的日子。**
   11/05、11/06、11/09 两边都不加，区别只在「有没有下一步」。

## 如果只改一件小事

把推送的结论字段从 `做/不做` 改成五段式，哪怕结论仍是「不做」：

```text
action   : none | probe | push | trim | exit
trigger  : 什么条件成立才动手（具体到时点/量能/价位）
deadline : 最晚等到什么时候，过了就作废
size     : 动作用多少仓位（pending 也给上限）
invalid  : 什么情况下认错
```

11/04 那天，这样一张卡在 13:44 会写出 `push / 双脚+缩转放+二段跳 / 14:30 / 30% / 收盘跌回 3590`；
11/09 会写出 `none / 回踩半导体 / 收盘前 / ≤30% / 放量破 3650`——
两张都比「不做」多了一个东西：**明天还要不要做、做什么。**
