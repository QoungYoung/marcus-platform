## 1. 流程总览（自上而下）

【提炼】把语料里的散点拼起来，他的决策链是**五层漏斗 + 两个循环**：

```
        ┌─ ① 级别与浪型（月/周定格局，日线做动作）         ← 决定"能不能做"
        │      └ 输出：主基调 build / t_only / side / defense / exit
        ├─ ② 仓位档位（按基调给总仓位目标 + 现金底线）      ← 决定"做多大"
        ├─ ③ 方向（主线？板块容量够不够？拥挤不拥挤？）      ← 决定"做哪里"
        ├─ ④ 票（龙头/辨识度/位置；绝不后排）              ← 决定"做哪只"
        └─ ⑤ 线位与节奏（挂哪条均线买、兑现几个点、破哪条线止损）
              ↑                                                  ↓
        ┌─ 内循环：底仓不动 + T仓高抛低吸（做T降成本）──────────┘
        └─ 外循环：复盘 → 修正方向/仓位（错就认，不格局）
```

**关键点：这五层是"与"关系，不是"或"**。他反复强调的失败模式几乎都是"某一层没做"：方向对但买了后排、位置对但仓位太重、票对但没等确认、都对但止损没设。

## 3. 第一层：级别、浪型与主基调【命中 626 句】

### 3.1 多级别分工

- 月线/周线看格局，日线做动作（2016-03-15）。
- **均线对他不是指标，是"资金分层的地图"** —— 这是他最独特的一条：
  > 2021-07-14「做大级别的趋势票 离13线又那么近 **几条线就是分别不同的资金去接** 一般 **3日 5日 最多10日 都是些散户游资** 而**机构单子一般都是挂在 10日 13日 34、60 这些大级别的线附近的** 这就要看你想跟哪种」
  【提炼】→ 所以"挂哪条线低吸"取决于**你想接谁的单**；这解释了他为什么总说"看线买、挂线买"而不是说价格。

### 3.2 趋势线/均线的参数（**重要：此前我们误记为"语料无参数"**）

| 参数 | 用途 | 原话（日期） |
|---|---|---|
| **13 / 34 日** | 标记趋势线、做强弱分类 | 2016-03-30「趋势线用 **13和34天** 来标」；2021-01-28「用 **13日 34日做强弱分类**」 |
| **60 日** | 底线 | 2021-01-28「**60日是我的底线**」 |
| **没站稳 34 日且带量下穿** | 直接砍 | 2021-01-28「甚至有些**没站稳34日带量下穿的我都会砍掉**，这个东西我砍得很快」 |
| **55 日** | 持有纪律线 | 2016-09-05「只要**不跌破55日线**或者大盘崩，我就不加不减的拿着」 |
| **5 日** | 短期见顶信号 | 2026-01-12「收黑K **跌破5日线** 那就是短期见顶，而且只是短期，到时候减仓避一下就行」 |
| **趋势线本身** | 加仓/止损触发 | 2025-12-08「只要他**站稳下跌趋势线上** 我就开始加仓了」；2016-08-05「除非**跌破趋势线**或者大盘崩」（否则不动） |

### 3.3 浪型与"主基调"

- 2026 语料中他用 **level/sub_level/operation** 表达"当前该干什么"（d4-2 / 4-5 / 失败5 / B反 / C杀 / 衰竭 等）。
- **operation 是他自己的话**：build（建仓）/ t_only（只做T）/ side（观望调仓）/ defense（防御）/ exit（兑现降仓）—— 我们系统就是照这个建的。
- 2026-03-06「**已经成为趋势后**…转为我之前说的趋势波段止盈止损方法，也就是用**趋势线**的方法…**不是一个策略用到底的**」→ **同一波里止损口径要换**。

### 3.4 参与门槛（早期表述，需谨慎外推）

- 2016-02-04「我一般是有 **500点左右的反弹**才去做」——这是**2016 年指数点位口径**，不能直接搬到今天；但"**反弹级别不够就不参与**"这个思想是稳定的。

## 4. 第二层：仓位与资金【命中 618 句】

### 4.1 按市况分档（**决定性原话**）

> 2026-01-17（答"什么时候50%，什么时候75%，什么时候打满"）
> 「**主升趋势就75%以上** 然后盘中满仓滚动啊 **调整就50%** **有风险就30%** **下跌趋势就不做**」

### 4.2 条件式目标（判据我们已经在算）

> 2026-02-05「对啊 **只要当天收盘没有跌破前一天低点 都是70%仓位** 没走弱不用减仓」

### 4.3 下限

> 2025-08-11「这个位置 **仓位低于55%** 日内分时低于80%都是不太合适」
> 2026-09-03「我这里 **仓位不会低于65%收盘**，日内做T仓位20%」

【提炼】55%/65% 都带语境（"这个位置"、顶级突破预期），**不是恒定下限**；共同含义是：**结构完好时不要因为怕回撤而过度减仓**。

### 4.4 结构：固定仓位 + 现金做T（三分）

- 2025-02-11「**固定仓位50%，剩下的做T等突破或回踩打满**」
- 2025-04-17「**60%固定仓位** 其中20%地产 40%机器人半导体，**剩下的做当天的T 全出全进**」
- 2022-05-23「保持 **40%固定仓位**最好，其他的钱按照轮动和小级别机会去做正T…**必须保留一定现金进行操作成本**」
- 2026-08-04「你们始终分不清 **做T仓位和底仓的区别**」

### 4.5 为什么不要在没波动的地方堆仓

> 2021-01-29「股票**只要有波动就能套利**，所以为什么说**不要左右横跳**，因为横跳你是新仓，**没有套利空间**，只能祈求单边行情」
【提炼】仓位不是"看多就多"，而是"**这个方向有没有反复/波动供我套利**"。

## 8. 内循环：持仓与做 T【命中 478 句】

- **底仓 / T 仓分家**（2026-08-04，见 4.4）；**底仓不动**。
- **做 T 的定位（反直觉、极重要）**：
  > 2016-03-03「做 **T+0 和 T+1 只是为了练点位判断，不是靠 T 来赚钱的**，要 T 也是**周线、月线级别的 T 才有赚钱效应**，做 T 应该只是为了每次波段点位开始和结束做的动作，要么为了**降低成本**，要么为了更好的抓相对低点」
  【提炼】把 T 当成主要收益来源，方向就错了；它的作用是**降成本 + 保留仓位参与**。
- **T 的兑现幅度**：3-5 个点（2026-08-13 楼275/280）。
- **黄线（日内离场线，也是他的高频判据）**：2026-08-04「在这个半小时内有个**绝对不能破的点 就是日均线那条黄线，一旦突发跌破直接走**」。
  ⚠️ 术语澄清（此前的检索踩坑）：他说的"黄线"= **分时图均价线**、"白线"= **指数线**；全量计数 **黄线 197 条 / 白线 181 条**（"均价线""分时均线" **0 条**）——
  用"均价线"去搜会一无所获。
- **日内强弱判据（黄上白下）**：2026-01-20「而这样就有可能出现**二八分化的场景**，所以谨慎对小盘做加仓的T，特别是如果开盘后出现**白线在上**的情况下」；2026-01-23「第二天**大概率黄线在上** 那第二天开盘只用判断量能，缩量上冲是不是可以比平时快 15 分钟判断可以做正T」。
  【提炼】→ 开盘先看**白线在上还是黄线在上**，据此决定当天做 T 的方向与节奏（权重护盘 vs 小盘活跃）。
- **时段纪律**：14:45 后禁新开；**止损不放在 13:00–14:30**（2026-03-23「要么你早上卖 要么你尾盘卖」）。
