## 1. 流程总览（自上而下）

【提炼】把语料里的散点拼起来，他的决策链是**五层漏斗 + 两个循环**：

```
        ┌─ ① 级别与浪型（月/周定格局，日线做动作）         ← 决定"能不能做"
        │      └ 输出：主基调 build / t_only / side / defense / exit
        ├─ ② 仓位档位（按基调给总仓位目标 + 现金底线）      ← 决定"做多大"
        ├─ ③ 方向（主线？板块容量够不够？拥挤不拥挤？）      ← 决定"做哪里"
        ├─ ④ 票（龙头/辨识度/位置；绝不后排）              ← 决定"做哪只"
        └─ ⑤ 线位与节奏（挂哪条均线买、兑现几个点、破哪条线止损）
              ↑                                                  ↓
        ┌─ 内循环：底仓不动 + T仓高抛低吸（做T降成本）──────────┘
        └─ 外循环：复盘 → 修正方向/仓位（错就认，不格局）
```

**关键点：这五层是"与"关系，不是"或"**。他反复强调的失败模式几乎都是"某一层没做"：方向对但买了后排、位置对但仓位太重、票对但没等确认、都对但止损没设。

## 3. 第一层：级别、浪型与主基调【命中 626 句】

### 3.1 多级别分工

- 月线/周线看格局，日线做动作（2016-03-15）。
- **均线对他不是指标，是"资金分层的地图"** —— 这是他最独特的一条：
  > 2021-07-14「做大级别的趋势票 离13线又那么近 **几条线就是分别不同的资金去接** 一般 **3日 5日 最多10日 都是些散户游资** 而**机构单子一般都是挂在 10日 13日 34、60 这些大级别的线附近的** 这就要看你想跟哪种」
  【提炼】→ 所以"挂哪条线低吸"取决于**你想接谁的单**；这解释了他为什么总说"看线买、挂线买"而不是说价格。

### 3.2 趋势线/均线的参数（**重要：此前我们误记为"语料无参数"**）

| 参数 | 用途 | 原话（日期） |
|---|---|---|
| **13 / 34 日** | 标记趋势线、做强弱分类 | 2016-03-30「趋势线用 **13和34天** 来标」；2021-01-28「用 **13日 34日做强弱分类**」 |
| **60 日** | 底线 | 2021-01-28「**60日是我的底线**」 |
| **没站稳 34 日且带量下穿** | 直接砍 | 2021-01-28「甚至有些**没站稳34日带量下穿的我都会砍掉**，这个东西我砍得很快」 |
| **55 日** | 持有纪律线 | 2016-09-05「只要**不跌破55日线**或者大盘崩，我就不加不减的拿着」 |
| **5 日** | 短期见顶信号 | 2026-01-12「收黑K **跌破5日线** 那就是短期见顶，而且只是短期，到时候减仓避一下就行」 |
| **趋势线本身** | 加仓/止损触发 | 2025-12-08「只要他**站稳下跌趋势线上** 我就开始加仓了」；2016-08-05「除非**跌破趋势线**或者大盘崩」（否则不动） |

### 3.3 浪型与"主基调"

- 2026 语料中他用 **level/sub_level/operation** 表达"当前该干什么"（d4-2 / 4-5 / 失败5 / B反 / C杀 / 衰竭 等）。
- **operation 是他自己的话**：build（建仓）/ t_only（只做T）/ side（观望调仓）/ defense（防御）/ exit（兑现降仓）—— 我们系统就是照这个建的。
- 2026-03-06「**已经成为趋势后**…转为我之前说的趋势波段止盈止损方法，也就是用**趋势线**的方法…**不是一个策略用到底的**」→ **同一波里止损口径要换**。

### 3.4 参与门槛（早期表述，需谨慎外推）

- 2016-02-04「我一般是有 **500点左右的反弹**才去做」——这是**2016 年指数点位口径**，不能直接搬到今天；但"**反弹级别不够就不参与**"这个思想是稳定的。

## 4. 第二层：仓位与资金【命中 618 句】

### 4.1 按市况分档（**决定性原话**）

> 2026-01-17（答"什么时候50%，什么时候75%，什么时候打满"）
> 「**主升趋势就75%以上** 然后盘中满仓滚动啊 **调整就50%** **有风险就30%** **下跌趋势就不做**」

### 4.2 条件式目标（判据我们已经在算）

> 2026-02-05「对啊 **只要当天收盘没有跌破前一天低点 都是70%仓位** 没走弱不用减仓」

### 4.3 下限

> 2025-08-11「这个位置 **仓位低于55%** 日内分时低于80%都是不太合适」
> 2026-09-03「我这里 **仓位不会低于65%收盘**，日内做T仓位20%」

【提炼】55%/65% 都带语境（"这个位置"、顶级突破预期），**不是恒定下限**；共同含义是：**结构完好时不要因为怕回撤而过度减仓**。

### 4.4 结构：固定仓位 + 现金做T（三分）

- 2025-02-11「**固定仓位50%，剩下的做T等突破或回踩打满**」
- 2025-04-17「**60%固定仓位** 其中20%地产 40%机器人半导体，**剩下的做当天的T 全出全进**」
- 2022-05-23「保持 **40%固定仓位**最好，其他的钱按照轮动和小级别机会去做正T…**必须保留一定现金进行操作成本**」
- 2026-08-04「你们始终分不清 **做T仓位和底仓的区别**」

### 4.5 为什么不要在没波动的地方堆仓

> 2021-01-29「股票**只要有波动就能套利**，所以为什么说**不要左右横跳**，因为横跳你是新仓，**没有套利空间**，只能祈求单边行情」
【提炼】仓位不是"看多就多"，而是"**这个方向有没有反复/波动供我套利**"。

## 8. 内循环：持仓与做 T【命中 478 句】

- **底仓 / T 仓分家**（2026-08-04，见 4.4）；**底仓不动**。
- **做 T 的定位（反直觉、极重要）**：
  > 2016-03-03「做 **T+0 和 T+1 只是为了练点位判断，不是靠 T 来赚钱的**，要 T 也是**周线、月线级别的 T 才有赚钱效应**，做 T 应该只是为了每次波段点位开始和结束做的动作，要么为了**降低成本**，要么为了更好的抓相对低点」
  【提炼】把 T 当成主要收益来源，方向就错了；它的作用是**降成本 + 保留仓位参与**。
- **T 的兑现幅度**：3-5 个点（2026-08-13 楼275/280）。
- **黄线（日内离场线，也是他的高频判据）**：2026-08-04「在这个半小时内有个**绝对不能破的点 就是日均线那条黄线，一旦突发跌破直接走**」。
  ⚠️ 术语澄清（此前的检索踩坑）：他说的"黄线"= **分时图均价线**、"白线"= **指数线**；全量计数 **黄线 197 条 / 白线 181 条**（"均价线""分时均线" **0 条**）——
  用"均价线"去搜会一无所获。
- **日内强弱判据（黄上白下）**：2026-01-20「而这样就有可能出现**二八分化的场景**，所以谨慎对小盘做加仓的T，特别是如果开盘后出现**白线在上**的情况下」；2026-01-23「第二天**大概率黄线在上** 那第二天开盘只用判断量能，缩量上冲是不是可以比平时快 15 分钟判断可以做正T」。
  【提炼】→ 开盘先看**白线在上还是黄线在上**，据此决定当天做 T 的方向与节奏（权重护盘 vs 小盘活跃）。
- **时段纪律**：14:45 后禁新开；**止损不放在 13:00–14:30**（2026-03-23「要么你早上卖 要么你尾盘卖」）。

## 15. 他的成文流程（原文级，价值最高——建议以此为准，前面的章节都是它的注解）

语料里他**自己写下的完整流程**只有少数几篇，这三篇是核心。**它们比任何二手归纳都可靠。**

### 15.1 买卖/做T 方法（XLS 2025-04-15，全文约 1,500 字）

> **适用范围声明（关键）**：「这里说的买卖方法一般对应的 **单日或者 3 日内**，如果是**大级别的买入和卖出是另外一个方法**，那个牵扯到的消息面和情绪面更多一些」

**条件 1（环境与预判）**：确定前一日行情不会导致今日大幅波动、指数仍在箱体内 → 看前一日**流入前 5 / 流出前 3**（**避开三日都是流出前 3 的板块个股**）→ 看**融资盘**是否大量增减 → 看 **A50 / 沪深300 / 科创50 期货的多空单变化**（**用来分辨次日开盘是"黄线在上"还是"白线在上"**）。

**条件 2（时间窗）**：**当日只做上午 9:45–10:00、下午 14:00–14:30 这两个时间段**，尽量避免开盘直接买卖和平稳时段来回 T（**有消息刺激的个股例外**）。

**条件 3（黄白线 → 做T成功率）**：预判 **黄线高于白线** → 科技/消费这类主线强于银保地券商 → **做 T 成功率高**；预判 **白线高于黄线** → **减少做 T**（成功率低）。

**条件 4（量能，最重要）**：随时对比与前一日的量能。
- 现象 1：**低开 + 缩量 + 黄线高于白线 + 不破指数下支撑**
- 现象 2：**高开 + 放量 + 黄线高于白线 + 不接近上方压力 + 开盘 15 分钟不跌破当日跳空缺口下沿（= 昨日最高位）**
→ 这两种情况**加仓做进攻板块（大消费、泛科技）成功率较高**。

**条件 5（更极致）**：分时接近下方支撑位置、**缩量转放量**的时候进场。

**条件 6（想追高的替代做法）**：高开/低开快速拉升想追的 → **在 14:00–14:30 回补**，要求"**分时上涨放量、回调缩量**"，补进攻板块里**涨得还不多的**。

**不要加仓进场的 4 种情形**：① 黄线迅速下穿白线 + 放量；② 黄白线交织 + 缩大量；③ 白线迅速上穿黄线 + 缩量；④ 接近大指数级别压力位。

**当日卖出条件（清单）**：个股分时因消息刺激短时上涨；个股因板块消息短时上涨；个股在区间震荡时碰到自身各种压力位（**均线或 BOLL 上轨**）；指数碰到大级别压力位；个股分时被大量抛售；个股因黑天鹅事件资金出逃。

**七条要素（他的纪律清单）**：
1. 尽量不要在**非时间段内**激情交易
2. 尽量不要个股**短时激情操作**
3. 尽量不要同一价位附近因大盘/板块没到位置的小波动**激情来回交易**
4. 尽量不要在**板块快速轮动期间来回切换**
5. 尽量不要**抗**有明确利空风险的板块及个股
6. 尽量不要在明确有大级别利空时**重仓**
7. **尽量不要把做 T 的仓位变加仓**；「**如果三日内没有达到预期证明自己预期有问题**，超过自己预期的钱就不应该赚」

> 自述：「我自己就是不断的重复以上操作要点，逐渐的形成自己的操作流程。**在长时间的操作样本内已经达到盈利大于亏损**。」

### 15.2 每日复盘流程（XLS 2025-04-21）

> 「我对复盘的重视程度还是很高的…后来我**简化和固化**了一下我的操作」

1. 准备一张表（数据源：开盘啦/打板客网、同花顺/东财、金十数据/新浪财经）。
2. **前 8 项打分**：多方占优 +1、空方占优 +1；**空方分数两倍于多方 → 判空方占优**（反之判多方）→ 由此推断**明天指数前 2 小时的大致方向**。
3. 看第 5、6 项：**避开流出方向、关注流入方向**。
4. 看**龙虎榜** → 判断**资金结构**。
5. 看**第 10 项（涨停板方向）** → 看哪些梯队结构完整、哪些"集中毕业照"、哪些上板失败 → **判断板块强弱 → 推断接下来做的方向**。
6. 扫一圈**外围**（外围多空都按 0.1 分计）。
7. 对比总分 → **预判明天高开还是低开、是做黄线还是守白线、哪些板块有机会** → **做好计划**，第二天执行时按当天行情微调。

### 15.3 调整期怎么做（XLS 2026-01-27，用 1.14–1.27 共 10 个交易日的实盘讲）

> 赚钱核心 = **开源节流**：行情好多上仓位拉高盈利**增加利润垫**；调整期则：

1. **先减仓位** —— 「这个时候 3-2 垫出来的**利润垫**就大用处了…我前面赚了钱，**这个钱取一半还能留一半在里面**，这样其实仓位比例没变大，但是仓位就比没有利润垫要大了」
2. 找「**大家跌我跌少一点、大家反弹我抢先反弹**」的方向
3. **不要在没有突破重回上涨趋势之前，把已经减出去的仓位用不理智的操作加回去**（"万一不反弹这个方向呢，万一这个方向有龙头风向核心暴雷呢"）
4. 保持**趋势核心底仓** + 用**灵活仓位短期打野**做超额

> 「**做超额是第四，首先要做好 123 才有 4。你们就喜欢跳过 123 直接找 4，在调整阶段重拳出击，左右横跳。**」
> 「调整阶段，**除了在几百个板块里面找到唯一对的那个，其他都差不多**」
> 「小散就要有小散的生存之道，就是**苟**，苟到市场好了就赢了」

## 16. 冲突与适用条件（本轮交付：先把"互相打架"的规则理清）

**为什么必须先做这个**：同一族规则在不同语料期出现看似矛盾的说法，若直接落进系统会自相矛盾。逐条核对后发现，**绝大多数不是矛盾，而是"适用条件不同"**；只有一条是**真的缺口**。

### 16.1 冲突一：日内做 T ↔ 波段持有【他明说了分界】

- 2016-03-03：「做 T+0 和 T+1 只是为了练点位判断，**不是靠 T 来赚钱的**，要 T 也是**周线、月线级别的 T 才有赚钱效应**」
- 2026 语料：大量日内做 T（"日内做 T 仓位 20%"、"T 出昨天加的半导体 这波 3 个点"）

→ **适用条件**：2025-04-15 他明说「**这里说的买卖方法一般对应单日或者 3 日内，如果是大级别的买入和卖出是另外一个方法**」。
**结论：这是两套方法**（日内/3 日内 vs 大级别），各有独立的买、卖、仓位条件。**不能把两套的参数混在一张表里**。
另注：2016 那句是对**散户能力**的劝告（"没有超短把握能力就不要玩超短"），不是"他不做日内"。

### 16.2 冲突二：仓位水平（50 / 55 / 65 / 70 / 75）【= 市况分档 + 利润垫】

- 2026-01-17：主升 **75%以上** / 调整 **50%** / 有风险 **30%** / 下跌 **不做**
- 2026-02-05：**收盘不破前日低点 → 70%**
- 2025-08-11：**低于 55% 不太合适**；2026-09-03：**不低于 65% 收盘**
- 2022-05-23 / 2025-02-11 / 2025-04-17：固定仓位 **40% / 50% / 60%** + 其余做 T

→ **适用条件**：① **市况状态**（主升/调整/有风险/下跌）；② **利润垫**（2026-01-27：有利润垫才敢留更多仓）。
**结论：不是矛盾**。落地时必须**先定市况档位，再谈具体数字**；把 70% 当恒定上限或恒定目标都是误用。

### 16.3 冲突三：换股频率（"不要频繁换股" ↔ 高频轮动）【= 市场类型不同】

- 2016-02-04：「**尽量不要频繁换股**，严格按照自己策略操作」
- 2021-01-29：「**不要左右横跳**，因为横跳你是新仓，**没有套利空间**」
- 2025-04-15 要素四：「尽量不要在**板块快速轮动期间来回切换**」

→ **适用条件**：反对的是**没有套利空间/无逻辑的来回切**，不是"不许换票"。2026 语料里他在轮动市**主动换**（换股有 3% 阈值规则，见 9 节）。
**结论：一致**——换票要有理由（弱于换后标的 3%）与时机（不在快速轮动期乱切）。

### 16.4 冲突四：追高（"不要追高" ↔ "突破加仓/摁进去"）【= 时机不同】

- 2016-01-18：「**不要追高**，筑底行情没那么快的」
- 2026-09-03：「**高开不追是基本常识**」
- 2025-04-15 条件 6：想追的 → **在 14:00–14:30 等回调补**
- 2025-12-08：「只要他**站稳下跌趋势线上** 我就开始加仓了」

→ **适用条件**：**不追"当下那一根"**；加仓要等**回调/缩量转放量/突破确认**。
**结论：一致**——反的是"追"，不是"加"。

### 16.5 冲突五（**这一条是真的缺口，不是冲突**）：时间窗

- 他：**当日只做 9:45–10:00 与 14:00–14:30 两个时段**（2025-04-15 条件 2）
- 我们系统：09:30 起就能触发、14:45 后才禁新开；另有"止损不在 13:00–14:30"（2026-03-23）

→ 我们有**禁止区间**，却**没有他的正向时间窗**。**这是需要落地的缺口**（记入 §11 对照）。

### 16.6 造成"伪冲突"的最大来源：**语料本身有整年缺口**

XLS 逐年条数（实测）：

| 年 | 2016 | 2017 | 2018 | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 条数 | 4780 | **11** | **0** | **0** | **28** | 7198 | 3859 | **0** | **0** | 5795 | 4136 |

→ **2018–2019、2023–2024 完全缺失，2017/2020 近乎缺失**。
**后果**：任何"他什么时候改了口径"的判断，只能在 **2016 / 2021–2022 / 2025–2026** 三个可观测期之间比较；
中间演化**不可观测** → **不得断言"他突然改变"**，只能说"在我们能看到的样本里，A 期这么说、D 期那么说"。
（这也是 §16.1–16.4 全部按"适用条件"而非"改变"来解释的原因。）

### 16.7 冲突六：「不看波浪理论」↔「以浪型为框架」【= 两种工具各管一层 + 视角甄别】

**先看事实**（全量计数，"波浪"共 34 句）：他 2016 年**同时**说过两种话：
- 2016-03-05：「技术派…什么 KDJ 金叉死叉、MACD、CR、量价关系、费波纳奇黄金分割位、**艾略特的波浪理论**、江恩曲线…**但我做股票一般不看这个**，我一般只盯着今天我下多少单、大一些的户头在什么价位进出」
- 2016-01-19：「**我用的是波浪理论结合 13、34、60 K线和一些指标做波段目标操作**」
- 2016-02-29：「周线和月线具有连贯性和重复性，**我是用波浪理论来看的**」
- 2016-02-17：「我只不过把 1 次反弹的 **5 浪波段做成 2 段**而已」

→ **这两者不是前后矛盾，而是分工**：
【提炼】**波浪/均线用于定"波段目标与格局"，盘口与订单流用于定"当天怎么做"**。2016-03-05 那段是在跟论坛"指标派"做对比，强调他更依赖盘口——不是说他不看结构。
另注：2016 的"浪"多用于**波段目标**（"4 波反弹后还有最后 5 浪下跌"），2025–2026 的"浪"用于**主基调判定**（operation）。用法一致，粒度不同。

⚠️ **但这条冲突牵出一个更根本的问题**：2016-03-05 那段他站的是**操盘方**（见 §0.2 第 4 条）。
**引用 2016 材料时必须先判视角**：是"他的持仓策略"还是"他的做盘经验"？后者对我们的用途是**理解对手盘**，不是照做。

### 16.8 冲突七：止损「阶段切换」↔「止损预设」【= 不冲突，预设本身包含切换规则】

- 2026-03-06：「**已经成为趋势后**…这个就没意义了 更多应该转为我之前说的趋势波段止盈止损方法，也就是用趋势线的方法…**不是一个策略用到底的**」
- 2026-08-19（完整语境）：「这不都是我**提前预判**的吗？我肯定**按计划做**的 然后**设定好止损**就行了。**到位置不按计划做那和你们有什么区别**」
- 2026-03-05：「我说一下我用的 **买入有时间** 然后 13 日内跌破波段低点的 -3% 没有收回 直接止损」

→ 【提炼】**预设 = 在建仓时就把"这一阶段该用哪条线 + 时间窗"定死**；"阶段切换"是这个预设的**内容之一**（建仓时就知道 13 交易日内用波段低点 −3%，成趋势后换趋势线口径）。
**结论：不冲突**。真正的要求是：**预设必须是"带阶段的"**，而不是只写一条固定价。这也正是系统里 `resolve_stop()` 按持有交易日数切换口径的依据。

### 16.9 冲突八：早期「中长线不看消息」↔ 近期盯公告/新闻【= 按持有周期分层】

他在 2021-01-28 **自己就分层说清了**（这段是本条的决定性证据）：

> 「首先要分析自己的性格，然后把自己归属成 **超短 / 短线 / 波段 / 中线 / 长线** 投资者
> 然后比如**超短**，那就主要看 **MA1 MA3 5 日线和盘口 龙虎榜**，然后**止损放 13 日就完了**…
> 比如做**短线**，就要看 MA3 5 日 13 日，然后**更多看消息和盘口**，赌龙虎榜；止损一般我会放在这波起步的首个大红K的中位数。
> **我主要做波段**，这个是我的强项，所以我一般拿**周线看大趋势**，根据大盘趋势情绪和主线方向，**用 13 日 34 日做强弱分类，60 日是我的底线**…
> 至于**中线和长线**…**我根本就不看的，连消息有时候我都忘记看了**，除了大盘向下破趋势外我是不会动的。」

- 2026-02-25：「我**长线仓位喜欢放在没有利空基本逻辑的**」→ 中长线**在结构上规避利空**（选的时候就避开），但**不跟踪消息**。

→ **结论：不冲突，是按持有周期分层**：**短线看消息/公告；中长线不看消息**（但选股时规避有明确利空的标的）。
对我们的含义【提炼】：层①「无利空」公告判据只应作用于**短线/建仓初期**的仓位——与它现在的适用范围（建仓初期 ≤13 交易日）**恰好一致**，不需要扩大到中长线底仓。
