## 3 结论（能下的 / 不能下的）

**能下的**
1. **"+3% 小止盈"在两类样本上都抬胜率**（生产腿 51.5%→57.6%；428 腿 47.4%→52.6%），
   且在生产腿上同时抬均值（−0.13%→+1.29%）—— 与他的兑现风格一致；**这条已经在生产里**
   （profit_take 浮盈≥3% 减半 + roundtrip_sell 低吸后 +3% 卖回，2026-09-14 开启）。
2. **老尺子（持 T+5）在生产腿上是最差的一种**（胜率 24.2%、均值 −1.56%）→ 再次证明"尺子/兑现方式"
   才是胜率来源，买点本身中性。
3. **V4（无低吸仓不做 T）在样本上是"少做"而不是"做得更好"**：命中腿只有少数、其余计 0%
   → 均值被拉平（+0.04%）但样本里没有增益证据；他这句话的正确落点是**买点前置条件**，不是兑现规则。

**不能下的（必须写明）**
1. **V2 的"破黄线"是代理，且代理过宽**：我用"当日最低 < 当日 VWAP（amount/vol）"近似分时黄线，
   而**日内价格几乎总会跌破当日均价** → V2 触发 26/33、V3 因此退化成 V2。
   **真正的验收需要 m5/分时数据**（数据缺口 G6）；在补齐前，V2/V3 的"72.7% 胜率"**不可当结论**。
2. **V5（高低位分型）无结论**：高位腿只有 3 条；但方向与他的说法一致（高位腿用 V3 更好）。
3. **H1/H2 不一致**：V1 的 H1 +3.41% / H2 −1.97% —— 两段不同号，按验收纪律**不能算通过**。
4. 样本只有 9 个交易日、33 条腿，且集中在 2026-08 的半导体/AI 行情 → **外部效度很低**。
