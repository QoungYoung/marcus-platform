## 0. 第一原则（记在最前面）

> 2026-05-25：「你们知道 2015 牛市之后那波大跌亏损最大在什么时候吗？你以为是最高点？我告诉你们，**最大亏损是我图上圈出来的 B段**，因为我经历过。而 C段 就是给 B段 下的最后终章。那几天下跌根本没人跑得出来。**所以结论就是整个 B段，无论你做得多么好，都是没有意义的。**」

⇒ **B反 的第一目的不是赚价差，是别被 B段 收走。** 后面所有操作（一次性、不摊平、卖点前置、差 3.5% 也走）都是这条的推论。

## 4b. 案例 C（完整展开）：2026-09-15 → 10-22——**没有 B反 的那一个月**

这一段没有 B反，所以没有"起点/中段/顶/结束"，它有自己的四个阶段：
**下跌确认 → 级别下调 → 承接尝试（三次失败）→ 再破位**。
它的价值是：**告诉你什么情况下不该动，以及"承接"和"自救"怎么分。**

### 阶段 1 · 下跌确认（9/15 → 10/8）

- **他看什么**：「4-5 之后阴跌为主」；支撑位有没有买盘；机构是不是按纪律破位砍。

- **他做什么**：「继续等待」；不抄底，不做 T。

### 这一案新增的三条判据（前四段里没有的）

1. **同一个"放量"，在下跌段和在 B反 段读法相反。**
   下跌段：10/15 11:17「现在看盘要点就是**公墓割肉盘减少**，就是**不要继续放量，或者能缩量最好**」——放量＝还在割。
   B反 段：8/4「机构吃了割肉的筹码」、8/5「缩转放」——放量＋收上半区＝承接。
   ⇒ **判据不是"放量"，是"放量 × 收盘位置 × 次日有没有做上去"。**

2. **"承接出现" ≠ "B反 成立"。中间还差一道"做上去的意愿"。**
   10/9、10/13、10/15 三次放量收上半区，次日收位全部掉回 26–31%。他当时就说「不算好事，是一个现象」。
   ⇒ 我此前把"放量+收上半区"当成立条件，**少了一道次日确认**。

3. **级别是边走边改的，判据是"收盘收不收得回"。**
   10/15 一句话把级别从"4 浪调整"降到"主跌 1 浪"，触发条件只是"收盘没有收回跳空跌幅"。
   ⇒ 框架里"级别"那一行必须允许改，而且要写明改判的触发句（不是感觉，是"收回/收不回"）。

## 4c. 锚族补遗：**浪型结构点**（要人工标，不能读生产字段）

前面所有"目标位"的讨论（§3.5 的斐波那契/半分位/前高前低统计）漏了一整族：**他给的点位经常是浪型计数的拐点**，不是几何公式。

### 两个已验证的实例（都是他实际用过的）

| 他说的话 | 日期 | 对应的结构点 | 差 |
|---|---|---|---|
| 「哪怕是下跌 1 浪的最低点，当时也就判断到 **3674**」 | 10/15 | **1 浪顶** 3674.40（2024-10-08，924 行情后第一波顶） | **0 点** |
| 「如果今天收盘正式破了 **3764**，是不是就确认要开始走下跌 1 浪了」 | 10/22 | **4-3 低点** 3764.15（2026-07-17） | **0.15 点** |

生产 `wave_state_history/20261015.json` 的完整结构：

```
origin    2704.09 (2024-09-13)   ← 924 行情起点
1浪顶      3674.40 (2024-10-08)   ← 下跌1浪的目标位
4-1 down  3959.34 (2026-06-08)
4-2 up    4175.35 (2026-06-23)
4-3 down  3764.15 (2026-07-17)   ← 下跌1浪的确认位
4-4 up    3995.18 (2026-09-01)
前一轮顶    4258.86 (2026-05-14)   ← 他说「最终指数 4258 是高点」
```

⇒ **同一个结构框架里，一个点当目标（3674=1浪顶），另一个点当确认（3764=4-3低点）。** 这不是巧合，是他读图的基本单位。

### 为什么这一族必须人工标：生产字段自己不稳定

| 快照 | origin | 1 浪顶 |
|---|---|---|
| 2026-03-30 / 04-20 / 05-21 | 2702.19（2024-02-05） | **3174.27（2024-05-20）** |
| 2026-08-03 / 10-15 | 2704.09（2024-09-13） | **3674.40（2024-10-08）** |

**同一个指数，同一个 `wave1_top` 字段，4 月是 3174、8 月是 3674。** 说明生产的浪型锚点会随重算漂移——**当参考可以，当输入不行**。

（这也解释了为什么我前面做的自动回测里，`sub_level=4-3` 只值 +1/+2 分：它本身在漂。）

  38.2% 回撤 = 3664.9   与 1 浪顶 3674.40 差 9.5 点（0.26%）
  23.6% 回撤 = 3891.9   差 217 点
  50%   回撤 = 3481.5   差 193 点
```

**1 浪顶恰好落在 38.2% 回撤上（差 0.26%）。** 所以在统计上永远分不清他是「按浪型数」还是「按斐波那契算」——**这不是样本量问题，是两种解释在数值上纠缠在一起。**

⇒ 结论：锚族的正确写法是**先看结构点，再拿斐波那契/半分位做交叉验证**；两者一致时可信度高，冲突时以结构点为准（因为他嘴里说的是结构）。

### 人工标注怎么做（不写自动识别）

对每一段行情，只记六个点：

起点 / 1浪顶 / 主升顶（前一轮顶）/ 4-1低 / 4-3低 / 4-4高
```

每个点都记「日期 + 数值 + 当时他有没有引用它」。**没被他引用过的点，不进入判断。**

## 6. 读出来的八条

1. **第一目的是保命，不是赚价差。** 5/25 原话：B段 是亏损最大段，「无论你做得多么好都是没有意义的」。
2. **起点他从不"确认"。** 3/30 说「现在还是 B反」时，指数已经从 4182 跌到 3923；8/3 说「还在跌」时他 10:19 已经买了。**他在跌的过程里给标签，不在涨起来之后。**
3. **中段的判据是「市场转放量」，不是 ETF 量比。** 8/5 市场 12087 亿（1.03×）才是"新钱进来"；8/3 的 1.66× 只是"局部割肉"。
4. **顶的量能指纹随级别变。** 大级别（案例 A）= 放量高潮；小级别（案例 B）= 缩量新高。二者都对应他 4/20 那句「有量不是高点，缩量容易出高点」——但**要用对级别**。
5. **结束的指纹是「放量 + 收最低」。** 5/21 量 2.62×/收位 4%；8/19 量 1.08×/收位 14%；10/19 量 1.46×/收位 2%（仍在下跌）。这条跨案例最稳。
6. **同一个"放量"，在下跌段和在 B反 段读法相反。** 下跌段他求「**不要继续放量，能缩量最好**」（10/15，割肉盘减少）；B反 段他要「**缩转放**」（8/5，新钱进来）。
7. **「承接出现」不等于「B反 成立」，中间差一道「做上去的意愿」。** 10/9、10/13、10/15 三次放量收上半区（收位 83/83/82%），次日收位全部掉回 26–31%。他当时就说「不算好事，是一个现象」。
8. **反面案例最有用**：2026-10 一个月里市场额始终 0.81–0.95×，他一个字没提形态，只说「自救资金」「没有承接」「延伸浪没终结」——**框架的主要产出是"现在不该做"。**

## 7. 验收标准（改）

不问胜率，问三条，当场能答：

1. **四行写了吗？**（级别 / 长度 / 目标 / 失效）没写＝没做。
2. **预案 1/2/3 有吗？** 事后才想到的，一律记违规，无论盈亏。
3. **这段行为和我事前读的一样吗？** 一样 → 记经验；不一样 → 记「我读错了什么」。**不改规则，只改读法。**

**账本比回测有用**：回测给平均值，账本给"这一次为什么"；而交易是一次一次做的。

1. **B反 的门槛是时间**：大级别、**≥2 个月交易日**。不到这个长度的是**小级别反弹**，不能叫 B反。
