# B反：标签问题还是选龙问题？

> 2026-10-22；5 段 B反（wave 标签），看指数、老龙头、当期龙头。

均值：

```text
指数 5日 +0.80%   20日 -0.78%
老龙头 5日 -2.92% 20日 -4.96%
当期龙头 5日 +0.10% 20日 -1.80%
```

## 结论

```text
B反标签：5 段里 2 段指数5日为正，3 段为负
→ 标签有问题，但不是全错
选老龙头：平均 -2.92%，明显跑输指数
→ 选龙问题更大
```

拆分：

### 1. 标签问题

- B反标签来自 wave 层 `defense` 反抽；
- 不是“确认底部”；
- 2026-02-25、06-15、08-27 都是失败 B反/C杀；
- 标签太早，不能直接当买点。

### 2. 选龙问题

- “老龙头 + 回撤 30%”选法太粗；
- 2025-12-30 指数 +3.82%，老龙头 -0.73%；
- 2026-06-15 指数 +0.46%，老龙头 -4.70%；
- 即使 B反成立，老龙头也不一定先反弹。

## 谁的问题更大

```text
B反标签      部分有效（2/5）
老龙头选择   明显跑输（5日均 -2.92%）
```

所以：

> **两边都有问题，但“老龙头低吸”是更大的问题。**

## 正确做法

### 标签端

```text
B反阶段开始 ≠ 买点
必须等：
  止跌
  放量
  站上 MA5/10
  不破前低
```

### 选龙端

不要：

```text
所有回撤 30% 的老龙头
```

要：

```text
老龙头 + 止跌确认
或当期龙头/龙2 + 右侧
```
