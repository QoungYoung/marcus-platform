# 狼大式龙头选择规则

> 目标：选“题材龙头”，不是选“当日涨幅第一”。  
> 每个判断都要能回到：主属性、位置、领涨、带动、排除项。

## 1. 龙头不是涨幅第一

错误：

```text
今日涨幅最高 → 龙头
20CM 封板 → 龙头
概念内 leader 字段 → 龙头
```

正确：

```text
主属性对
位置对
先动/领涨
能带动
不是主线下跌板块
```

涨幅只是结果，不是定义。

## 2. 主属性优先于概念标签

一个股票可能同时挂：

```text
半导体
AI眼镜
机器人
商业航天
```

但龙头要看：

```text
主营业务
行业归属
核心产品
题材辨识度
```

不是看它有没有被贴上该概念。

反例：

```text
300613 富瀚微
标签有 AI眼镜
但主属性是半导体/芯片设计
半导体是主线下跌方向
→ 不能当 AI眼镜的干净龙头
```

## 3. 位置：低位先动，不是高位加速

龙头应该：

- 在题材启动初期先动；
- 不是已经连续加速/高位一致；
- 不是开板多次的高位脉冲；
- 首日/首板优先；
- 低位核心优先于高位弹性。

反例：

```text
688818 电科蓝天
+15.9%
但 open_times=3、未封板、高位脉冲
→ 是弹性标，不是商业航天龙头
```

更像龙头：

```text
600118 中国卫星
601698 中国卫通
涨幅不高，但低位、辨识度、核心属性
```

## 4. 领涨：最早转强，不是最后补涨

看：

- first_time 是否早；
- 是否先于板块其他票；
- 是否在关键时点（早盘/13:30）先动；
- 不是尾盘偷袭；
- 不是后排补涨。

## 5. 带动：龙头动，二哥/中军要跟

狼大：

> 大哥先涨，二哥不掉。

检查：

- 龙头动时，风向是否跟；
- 中军是否守住；
- 不是龙头独涨、其他全跌；
- 不是只有一只票的“伪龙头”。

## 6. 成交额：要能承载，不是一根脉冲

看：

- 成交额是否在题材内前列；
- 是否有持续量；
- 不是缩量加速；
- 不是单日爆量后无承接。

## 7. 排除主线下跌板块

外溢/题材龙头，不能选：

- 主线正在下跌的板块；
- 大科技/半导体/CPO 等下跌趋势方向；
- 高位补跌方向；
- 只是概念标签重叠、主属性不在目标题材的票。

原因：

```text
主线下跌时，概念标签会被主线 beta 拖累
看起来是外溢，实际是补跌
```

## 8. 第一波/第二波

狼大：

> 先涨的都不是之前的人气标，后涨的一定是之前一批人气标。

第一波：

- 新面孔先涨；
- 不要硬套老龙头；
- 看谁先转强。

第二波：

- 老龙头/人气标接力；
- 不要忽略老龙头。

不要混：

```text
第一波拿老龙头当必然龙头
第二波拿新面孔当接力
```

## 9. 评分卡

每个候选打：

```text
main_attribute      主属性是否属于目标题材
low_position        是否低位/首日
first_move          是否最早转强
lead_others         二哥/中军是否跟
volume_capacity     成交额是否承载
not_mainline_down   是否避开主线下跌
recognizability     辨识度
```

优先级：

```text
main_attribute + low_position + first_move
> 当日涨幅
```

## 10. 输出

必须写：

- 为什么它是龙头；
- 为什么不是涨幅第一；
- 主属性是什么；
- 位置；
- 谁跟它；
- 排除了谁，为什么；
- 反证。

## 11. 反例清单

- 300613：半导体主属性，不能当商业航天/AI眼镜干净龙头。
- 688818：高涨幅但开板 3 次，弹性标，不是商业航天龙头。
- 002636：PCB/覆铜板，不是机器人双属性。
- 000678：机器人高位 5 板，是源题材高潮龙头，不是外溢目标龙头。

## 12. 一句话

> 龙头是“主属性对、低位先动、能带动”的那只，不是“今天涨得最多”的那只。
