## 1. 结果：15/27 = 56%（vs 代理 60%）

重放并未优于资金/动量代理，但**失败模式完全不同**——这本身就是最重要的发现。

## 2. 失败模式：研报催化 ≠ 狼大主线判断

| 类型 | 案例 | 原因 |
|---|---|---|
| 狼大说非主升/非主线，研报催化高 | 2026-08-05 半导体B反(catalyst 0.7)、2026-08-13 科技自救(0.8)、2025-11-04 PCB/CPO非主升(光 0.9)、2026-05-26 新能源非主线(0.75)、2025-12-11 AI应用非爆发(0.8) | 机构研报持续看多，但狼大判断基于市场资金+结构（B反/自救/资金未进） |
| 狼大说是主线，研报催化不足 | 2025-11-04 银行主升(金融 0.6)、2026-07-24 半导体下半年主线(0.6)、2026-02-25 半导体涨价主线(0.6) | 银行/半导体研报被 AI/消费研报淹没，或窗口内研报少 |
| 研报覆盖偏置 | 2025-10-21/24/27 狼大说科技主线，重放判半导体/芯片(研报多) | 半导体研报数量远多于光模块/AI应用，agent 被研报量带偏 |

**本质**：main_line_judge 只靠研报催化（基本面），而狼大的主线 = 资金抱团 + 产业催化 + 市场结构的复合判断。
研报催化是**充分非必要**——AI 产业研报一直有，但狼大只在资金认可时才认定主线。

## 3. 命中案例（15 条）特征

集中在 2025-11-24 ~ 2026-08-12 的 AI/科技主线期：狼大说 AI/科技/光芯存算是主线，
研报催化也强（0.7-0.95）→ 一致 ✓。说明**产业催化+资金共振期**研报有效。

## 6. 三信号融合（2026-09-01）：研报catalyst + 资金持续性 + 相对强度

**实现**（apps/main_line/fusion_mainline.py）：main_line_score = w1*研报catalyst + w2*主题资金持续性(5日净流入,9主题间百分位) + w3*主题相对强度(r20,9主题间百分位)。

**网格搜索结果**：

| 方案 | 命中率 |
|---|---|
| 纯研报 catalyst | 15/27 = 56% |
| 纯资金 fund | 10/27 = 37% |
| 纯强度 rel | 12/27 = 44% |
| 等权 (1/3,1/3,1/3) | 16/27 = 59% |
| **最优 (0.4, 0.3, 0.3)** | **17/27 = 63%** |

**结论**：
1. 融合 56%→63%（+7pp），研报为主(0.4)、资金/强度为辅(0.3+0.3)——资金/强度单独用很差(37%/44%)，说明**研报是主线的基本盘，资金/强度只能修正边界**。
2. 未达 75% 预期的原因：①研报量偏置(2025-10 半导体研报多被判主线, 狼大说科技——但两者同属科技大类, 是标注粒度问题); ②科技子类粒度(AI硬 vs 半导体, 融合信号无法细分); ③非AI主线(银行主升/半导体下半年)资金强度信号不足。
3. 研报量归一化试验(63%→59%)失败: 研报多≠错, 归一化引入新偏置, 弃用。
4. **建议**：匹配规则改为科技大类合并(AI/算力/科技+半导体/芯片 任一命中即算)预计可 +4条(2025-10系列)；主线标注补充非AI主线案例。

## 7. 成交集中度信号（2026-09-02）：融合 63%→74%

**数据**：22 个标注日期各抓 1 次 moneyflow_ind_dc(概念, 含 net_amount_rate) + index_daily(000001.SH) → data/replay_concentration.json。
**集中度定义**：concentration(theme) = Σ主题概念反推成交额(net_amount/rate) / 全市场成交额(index amount)，9 主题间百分位。
**注意**：全体概念反推成交额求和=8.2万亿 vs 全市场1.7万亿(5倍重叠)——分母必须用指数，不能用概念求和。

**4 信号融合结果**：

| 方案 | 命中率 |
|---|---|
| 纯研报 catalyst | 15/27 = 56% |
| 纯资金 fund | 10/27 = 37% |
| 纯强度 rel | 12/27 = 44% |
| **纯成交集中度 conc** | **19/27 = 70%** |
| 等权 4 信号 | 17/27 = 63% |
| **最优 (0.3, 0.2, 0.1, 0.4)** | **20/27 = 74%** |

**结论**：
1. **成交集中度是狼大主线判定的最强信号（单独 70%）**——验证狼大依据分析（"半导体占全天1/4成交""光+半导体占45%"），他的主线核心确实是资金/成交集中。
2. 最优权重 conc=0.4 + catalyst=0.3 + fund=0.2 + rel=0.1——研报退居辅助，与狼大原话优先级一致。
3. 剩余 7 条失手：3 条科技大类合并可修(2025-10-27/2026-06-05 半导体, 预期→81%)、2 条标注粒度(银行vs券商、AI应用vs硬件)、1 条长期vs当日(7-24下半年主线)、1 条结构判断(8-5 B反非主升, 需wave结构信号)。

## 8. 银行行业主题（2026-09-02）：申万/东财行业补充 → 78%→81%

**背景**：东财概念体系无"银行"（银行属行业分类），11-4 银行主升标注（原映射金融=券商）测不到。

**实现**：
- moneyflow_ind_dc(content_type="行业") 有"银行"(BK0475.DC)，22 日期抓取 → replay_bank_industry.json（509 行业/日）。
- fusion 加第 10 主题"银行"，信号独立：fund=净流入排名百分位、conc=fund、rel=银行涨幅归一化。
- **银行主升硬条件**：净流入全市场行业第一(rank==1) 且 涨幅≥1%——区分"主升"(11-4 银行+1.81% net第一) vs "护盘"(6/5 rank9、8/12 rank39，净流入强但非主线)。
- 标注修正：2025-11-04 金融 → 银行。

**结果**：最优权重 (0.0, 0.3, 0.2, 0.5) → **22/27 = 81%**（78%→81%）：
- 11-4 银行主升 ✓ rank1（原 rank9 垫底）；6/5 光/半导体 ✓（银行护盘不再挤占）
- 剩余 5 条失手：3 条科技子类粒度(AI硬/算力 vs 半导体, 12-24/8-12/11-28)、1 条标注映射(AI应用 12-11)、1 条时间尺度(7-24 长期vs当日)

**银行信号要点**：银行净流入第一+上涨=主升（狼大 11-4"只有银行和抱团妖股好"）；净流入强但非第一=护盘（指数托底），不给主线分。
