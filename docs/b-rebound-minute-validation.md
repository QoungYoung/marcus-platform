# B反低点分钟规则验证 v1

> 2026-10-22；6 个正样本 + 15 个低区负样本；588170。

## 规则

### rebound_confirm

```text
低点后 30 分钟反弹 >= 1.5%
且 收盘位置 >= 0.5
```

结果：

```text
TP 2（2026-03-24、2026-08-04）
FP 1（2026-09-14）
precision 0.67
recall 0.33
```

### shrink_stop

```text
低点量比 <= 1.0
且 收盘位置 >= 0.8
且 30 分钟反弹 >= 1.0%
```

结果：

```text
TP 1（2026-03-24）
FP 0
precision 1.0
recall 0.17
```

### panic_late

```text
低点时间 >= 14:00
且 低点量比 >= 1.5
且 收盘位置 <= 0.1
```

结果：

```text
TP 1（2026-08-03）
FP 2（2025-05-23、2026-03-17）
precision 0.33
recall 0.17
```

## 结论

```text
缩量止跌：高精度、低召回
日内反转：中等精度、低召回
尾盘恐慌：低精度、低召回
```

所以：

> **分钟规则能识别部分 B反 低点，但不能覆盖全部，不能宣称“精准识别开始”。**

## 当前可用的

```text
shrink_stop：
  只对缩量止跌低点有效
  精度 1.0，但只覆盖 1/6

rebound_confirm：
  对日内反转有效
  精度 0.67，覆盖 2/6

panic_late：
  只对尾盘恐慌有效
  精度 0.33，误报多
```

## 不能做

```text
不能用一个规则覆盖全部 B反
不能把 8/3 和 3/24 混为一类
不能直接接生产
```
