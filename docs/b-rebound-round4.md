## 发现

### 1. 低点不是一种形态

```text
恐慌长黑：2025-09-04、2026-08-03
缩量止跌：2025-11-24、2026-03-24
温和反转：2025-05-28、2026-08-04
```

### 2. 共同点

```text
接近 20 日低
收盘低于 MA20
r20 为负
```

但“触发日”完全不同。

### 3. 两段式触发

规则：

```text
低区：close <= lo20*1.05 且 close<ma20 且 r20<0
确认：close>ma5 且 pos>=0.5 且 amount>=a20*0.8
```

588170 结果：

```text
n=3
5日胜率 33%
20日均值 +6.2%
```

样本太少，不能验收。

## 结论

```text
低点可以找到
但低点形态不统一
单一触发规则无法覆盖
```

B反 开始识别需要：

```text
低区 + 形态分类 + 触发
```

不是：

```text
一个 panic 规则
或一个 MA5 规则
```
