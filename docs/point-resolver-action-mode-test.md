# 动作模式修正后的 G/H 复测

> 这轮先让 agent 判断 `action_mode`，再按模式选点；输入补了 15min 候选（`m15_*`）、`setup_context`，无狼大具体点位/原话。
> G：2025-12-11，三买失败/前低+3×15min，他的第一档 3876.47。
> H：2026-01-14，已按 4161 减过一次，再破盘中位/放量/3×15min，他的第一档 4141.03。

## 1. 结果

| case | 他的一档 | agent mode | agent risk | 偏差 | 判定 |
|---|---:|---|---:|---:|---|
| G | 3876.47 | `intraday_confirmation` | **3876.47** | 0.00% | ✅ 精确 |
| H | 4141.03 | `intraday_confirmation` | **4126.23** | -0.36% | ⚠️ 近位，不是同一档 |

- **动作模式 2/2 正确**：两条都被判为盘中确认，没有再按“结构性破位/更高已破结构”去选 3936/4034。
- **G 精确命中 3876.47**：日线 prior_day_low 与 15min prev_low 同价，没有歧义。
- **H 选了 4126.23**：这是 **1/13 的日线低点**，而他的 4141.03 是 **1/13 09:30 的 15min 首个低点**。两者差 14.8 点 / 0.36%。

## 2. H 为什么还差一层

- `setup_context` 写的是“已按 4161 减过一次；观察再破盘中位、放量、3 个 15min 确认”；
- 候选里同时有：
  - `prior_day_low 4126.23`（日线前低）
  - `m15_prev_first_low 4141.03`（前一日 15min 首低）
- agent 按“最近的前一日低点”选了 4126.23，因为 4126.23 比 4141.03 更接近收盘 4126.09；
- 但 3×15min 的确认语境下，“前一日低点”指的是 **15min 结构的首个低点/盘中低点 4141.03**，不是日线低点。

**这不是模式错，是粒度错：**
`前一日低点` 在日线/15min 两个口径下是两个数；对 3×15min 的 setup，应该优先 `m15_prev_first_low` / `m15_prev_swing_low`，而不是 `prior_day_low`。

## 3. 结论

- **动作模式分类这一层有效**：G 修好了，H 也不再跑去找 4034。
- **还差一条粒度优先级**：`intraday_confirmation` 下，`m15_prev_first_low`/`m15_prev_swing_low` > `prior_day_low`，尤其当 setup 明确写“3×15min/盘中位”时。
- H 的 0.36% 不是“差一点点”，是**不同口径的两个位**；如果只看 ±0.5% 容差会误判成“命中”，必须同时看 type。

## 4. 下一步

给 `setup_context` 增加一个粒度标签，或在 intraday 模式下加：

```
若 setup 含 3×15min/盘中位 → 第一档优先 m15_prev_first_low / m15_prev_swing_low；
只有没有 m15 候选时，才退回 prior_day_low。
```

再跑 G/H；预期 G 仍 3876.47，H 回到 4141.03。
