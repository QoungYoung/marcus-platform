# 狼大式龙头选择规则

> 目标：选“题材龙头”，不是选“当日涨幅第一”。  
> 每个判断都要能回到：主属性、位置、领涨、带动、排除项。

## 1. 龙头不是涨幅第一

错误：

```text
今日涨幅最高 → 龙头
20CM 封板 → 龙头
概念内 leader 字段 → 龙头
```

正确：

```text
主属性对
位置对
先动/领涨
能带动
不是主线下跌板块
```

涨幅只是结果，不是定义。

## 2. 主属性优先于概念标签

一个股票可能同时挂：

```text
半导体
AI眼镜
机器人
商业航天
```

但龙头要看：

```text
主营业务
行业归属
核心产品
题材辨识度
```

不是看它有没有被贴上该概念。


## 3. 位置：低位先动，不是高位加速

龙头应该：

- 在题材启动初期先动；
- 不是已经连续加速/高位一致；
- 不是开板多次的高位脉冲；
- 首日/首板优先；
- 低位核心优先于高位弹性。


## 4. 领涨：最早转强，不是最后补涨

看：

- first_time 是否早；
- 是否先于板块其他票；
- 是否在关键时点（早盘/13:30）先动；
- 不是尾盘偷袭；
- 不是后排补涨。

## 5. 带动：龙头动，二哥/中军要跟

狼大：

> 大哥先涨，二哥不掉。

检查：

- 龙头动时，风向是否跟；
- 中军是否守住；
- 不是龙头独涨、其他全跌；
- 不是只有一只票的“伪龙头”。

## 6. 成交额：要能承载，不是一根脉冲

看：

- 成交额是否在题材内前列；
- 是否有持续量；
- 不是缩量加速；
- 不是单日爆量后无承接。

## 7. 排除主线下跌板块

外溢/题材龙头，不能选：

- 主线正在下跌的板块；
- 大科技/半导体/CPO 等下跌趋势方向；
- 高位补跌方向；
- 只是概念标签重叠、主属性不在目标题材的票。

原因：

```text
主线下跌时，概念标签会被主线 beta 拖累
看起来是外溢，实际是补跌
```

## 8. 第一波/第二波

狼大：

> 先涨的都不是之前的人气标，后涨的一定是之前一批人气标。

第一波：

- 新面孔先涨；
- 不要硬套老龙头；
- 看谁先转强。

第二波：

- 老龙头/人气标接力；
- 不要忽略老龙头。

不要混：

```text
第一波拿老龙头当必然龙头
第二波拿新面孔当接力
```

## 9. 评分卡

每个候选打：

```text
main_attribute      主属性是否属于目标题材
low_position        是否低位/首日
first_move          是否最早转强
lead_others         二哥/中军是否跟
volume_capacity     成交额是否承载
not_mainline_down   是否避开主线下跌
recognizability     辨识度
```

优先级：

```text
main_attribute + low_position + first_move
> 当日涨幅
```

## 10. 输出

必须写：

- 为什么它是龙头；
- 为什么不是涨幅第一；
- 主属性是什么；
- 位置；
- 谁跟它；
- 排除了谁，为什么；
- 反证。

## 11.5 低位核心/辨识度，不打板

选龙头不是选“今天封板的那只”。

低位核心：

- 主属性属于目标题材核心；
- 位置低/首日；
- 辨识度高；
- 能带动板块；
- 不需要今天涨停。

辨识度：

- 公司是不是该题材的核心标的；
- 不是概念标签多；
- 不是封单最大；
- 不是涨幅第一。

不打板：

```text
龙头可以今天没涨停
可以在回踩/次日低吸
不追封板
```

如果一只票：

```text
今天涨停/封单最大
但位置高、主属性偏、只是弹性
→ 不是龙头
```

反过来：

```text
今天没涨停
但低位、核心、辨识度高、能带板块
→ 可以是龙头
```

## 11.55 龙头必须是“题材核心段”，不是好公司

先分角色：

```text
核心段：
  终端产品
  总体/总装
  运营
  平台
  主设备

配套段：
  连接器
  电源
  结构件
  轴承
  材料
  加工设备
```

规则：

```text
核心段 + 低位 + 辨识度
→ 可以当龙头

配套段 + 低位
→ 只能是中军/风向
→ 不能当龙头
```

例子（商业航天）：

```text
卫星总体、火箭总体、卫星运营、载荷
→ 核心段

连接器、电源、结构件、轴承
→ 配套段
```

所以：

```text
航天电器（连接器）→ 中军，不是龙头
中国卫星（卫星总体）→ 可以当龙头
```

“低位核心”不是：

```text
低位 + 好公司
```

而是：

```text
低位 + 题材核心段
```

## 11.6 买不了龙头怎么办

如果龙头是：

```text
创业板 300/301
科创板 688
北交所 8/4
```

而账户没有权限：

```text
不买龙头
不等于买杂毛
```

三种处理：

1. 买主板确认中军：主属性对、有量、二哥跟、不是后排。
2. 买 ETF：接受 beta，不追超额。
3. 不做。

禁止：

```text
买不了龙头 → 随便买一个同题材主板票
```

如果主板中军没有确认强度：

```text
不做
```

## 12. 一句话

> 龙头是“主属性对、低位先动、能带动”的那只，不是“今天涨得最多”的那只。
