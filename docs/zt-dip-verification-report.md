# 正T买点验证报告：大盘跳水低吸（纯规则, 2026-09-02）

> 承接 T1 语义修正（docs/t1-stock-verification-report.md）：狼大正T买点是『利用盘中大盘带下来的机会做正T』（1-12）『无利空跳一下就买』（8-12）。本报告纯规则验证该信号。

## 1. 信号规则化

- 信号：指数(000001.SH) 5min 当日盘中最大回撤 >= 阈值（从当日高点回撤，逐bar更新）
- 低吸：信号日收盘买入个股（第一版简化口径；盘中口径待扩）
- 卖出：T+1/T+2/T+3 收盘
- 对照：全交易日买入基线
- 数据：指数5min 184天 + 个股5min（2025-12~2026-09）

## 4. 关键发现

1. **跳水越深低吸效果越好**（2.0% > 1.5% > 1.0%），2.0% 是甜点区：T+1 +3% hit0.72。
2. **dd>=3.0% 失效**（唯一信号日 T+1 -2.31%）——深跌=系统性风险/利空日，符合狼大『无利空跳一下才买』：利空跳水不能买。
3. dd>=2.0% 信号日（9天）：2026-01-30, 02-02, 03-23, 05-21, 06-23, 06-26, 07-17, 07-20, 08-19；T+1 分布 min -9.99% max +10.01% med +2.46%——个别利空日仍会大亏（2-02），需要利空过滤。
4. 结论：**『大盘盘中回撤2%+ 且未跌破3%』= 正T低吸信号**，方向成立、分半稳定、与狼大原话吻合。
