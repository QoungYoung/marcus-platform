# 狼大兑现层语料取证（结构化 1,105 条，dsh 逐条精读）

> 目的：把**出场 / 兑现**相关的原话从三份逐日语料里**专门抽取一轮**，作为
> docs/plan-exit-alignment.md 阶段 1（R1–R5）与阶段 3（R8）的**唯一设计依据**。
> 本文是**证据层**（原话+日期+条数）；策略归纳见 docs/wolf-exit-playbook.md；
> 与我们系统的逐条落差见阶段 1 开工前的落差审计。

---

## 1 做法（与项目既有纪律一致）

| 项 | 内容 |
|---|---|
| 抽取方式 | **dsh 网关语义精读**（POST http://marcus-dsh:3001/chat，仅容器网络内可达）→ 脚本 jobs/wolf_exit_evidence.py 在 marcus-backend 容器里跑 |
| 语料来源 | /app/data/corpus/wolf-daily-log-{nga,xls2026,xls2025}.md，**md5 与仓库 docs/ 完全一致**（脚本把 md5 写进产物 _corpus） |
| 切片 | **只做版式处理**：日块（NGA/xls2026）按日块打包、表格（xls2025）按行打包，每片 ≤ 40,000 字符 → **11 片，无遗漏** |
| 未做 | **不做关键词/正则语义提取**；**不手打转写**；抽取值一律照抄原文 |
| 类别 | E1 做T兑现 / E2 离场触发 / E3 减仓 / E4 止盈保护 / E5 避险兑现 / E6 止损 / E7 尾段与结束 |
| 并发 | 3 分片（dsh 并发上限≈3），逐片写盘 + 断点续跑；**失败片必须显式记录**，不得当"他没说过" |

## 3 各类要点（原话+日期，全部可在产物里按 date/kind 检索）

### E1 做T兑现（203 条）
- **幅度锚是区间不是点**：「看吧 做大科技方向 **最低套利也是 3 个点 最多可以 10 个点**」（2026-08-04）；但**2 个点也认**：「我药都T卖出去了 **T+0 2 个点我就够了** 下来再买」（2025-04-03）；反抽另设目标：「做反抽 我的目标就是 **5 个点** 目前药已经达到了 我就撤了 **卖飞总比亏损好**」（2025-04-01）。
- **不留隔夜**：「**盘中做T尾盘必须出场，不加仓隔夜，确保安全**」（2025-06-04）。
- **手慢就吃第二波**：「拉升的时候跑 我今天第一波就是手慢了没出去，等**第二波 2%** 的时候出了一部分，这东西就是比手快」（2025-05-27）。
- **底仓不动**：「好了 我T了一把 **底仓不动**」（2025-05-27）。
- **三日未达预期=认错**：「**尽量不要把做T的仓位变加仓。如果三日内没有达到预期证明自己预期有问题**」（2025-04-15 成文流程要素七）。
- **出现上影线就停手**：「任何时候 看见机器人板块出上影线 **立马停止做T**，保持 30% 机器人底仓就别动了」（2025-07-17）。

### E2 离场触发（170 条）
- **破线且收不回才走**：「这种只有**跌破线收不回来才会一刀** 其他时间看都不看」（2025-01-24）——与"收盘确认破位"一致。
- **破前低直接删票**：「我说一下机器人排除法 包含今天在内的三天内 **如果破之前新低的，直接删票**」（2025-04-03）。
- **时间周期 + 放量长上影 = 撤退**：「连阳时间到明天就 **13 天**了…**13 天后如果哪天冲了放量长上影 我就撤退**」（2025-04-23）。
- **突破失败/诱多即离场**：「如果 1.3 以下突破 **直接判定诱多离场**」（2025-06-05）。
- **黄线不对先减后清**：「今天**看黄线不对先减仓后清仓**」（2025-03-13）。

### E3 减仓（305 条）
- **日内节奏**：「**大涨之日少买票，多卖票，大跌之日多买票 少卖票**」（2025-01-23）。
- **腿数上限**：「**一个票最多买 2 笔 卖 2 笔** 后面如果是主升浪的话越动收益越低」（2025-02-07）。
- **高潮减**：「机器人**高潮 丢一部分 退回 50% 仓位**」（2025-02-19）；「冲高大减机器人 继续补电池轮动」（2025-02-26）。
- **到压力位分档减**：「**144 线附近清一半金融**」（2025-04-11）；「**3221 如果任何时候到这个点，我会想办法卖到 40% 仓位以下**」（2025-04-09）。
- **双头/反包位置减**：「那些到**双头位置**的泛科技类，我开始**逢高减仓** 切到还没反包的上面」（2025-04-23）。
- **减完留底仓、杂票清干净**：「趁这波拉涨 **减仓到总仓位 60%** 结构不变 **杂票全清**」（2025-03-07）。

### E4 止盈保护（162 条）
- **顶部阶段中轨全止盈**（已落系统）：「**顶部阶段**…当天收盘前要是破了，收盘不管中间加了多少做T都是止损出来 **全止盈的位置就放在日线 BOLL 中轨附近，放量跌破收盘完全止盈**」（2025-05-13）。
- **被动止盈位只上移**：「持仓，下方**被动止盈位提高到 3373，不破不卖**」（2025-06-09）；「**不破被动止盈根本不会卖**」（2025-07-17）。
- **通道/BOLL 法**：「机器人如果**回 BOLL 中轨就买一点，上轨就卖一点**，突破就继续拿住」（2025-07-14）。
- 🆕 **个股止盈点 = 前一波拉升幅度的 0.618**：「如果手上的泛科技票 如果超过或者到了 **个股的前一波拉升幅度的 0.618 位 就是我的止盈点了**」（2025-04-23）——**他给过量化口径，我们系统里没有**。
- **加速位分档减**：「科创 50 第一加速位到了 按我之前的做法 这里 **减 1/4 或者 1/3** 的仓位」（2025-07-25）。

### E5 避险兑现（64 条）
- **节假日反 T 时点**：「以后是节假日出今日 甭管当时指数什么行情，尽量做到 **早盘卖 尾盘买的反T**」（2025-04-29）。
- **过节降仓**：「趁今天拉升 **我降仓位到 10%**，剩 1 个稀土 1 个免税过节」（2025-04-29）；「下周再砸一次 就 **1 层仓位过节**」（2025-04-25）。
- 🆕 **避险结束要补回来**：「你出于什么原因出去避险 **那这个避险逻辑结束后 是不是应该补回来** 在个股逻辑没变的情况下」（2025-09-24）——我们的周末避险**只有减半、没有回补腿**。
- **长线仓不避**：「**长线仓位我不避的**，为何不避 **因为不怕**」（2025-08-01）。
- **周末仓位档**：「3808 收复 继续 **70% 仓位过周末**」（2025-09-05）／「总共 **20% 仓位过周末**」（2025-05-16）。

### E6 止损（128 条）
- **破线就卖+删票**：「这些我都是**定线**的 **最下面那根线一旦破了 卖出然后删票**」（2025-02-06）。
- **止损锚在关键位（指数/结构），不是个股百分比**：「**3344 小底 就是做多可能性的底线 3338 破了 就是做多的止损**」（2025-03-13）；「**3334 是多头趋势最后防守**…下面 **3303 是多头止损**」（2025-03-31）；「收盘**跌破日线中轨清仓** 也就是 3316」（2025-05-15）。
- **不在杀跌里割**：「这里**不要杀跌 哪怕止损也要上去再止损**」（2025-03-26）；「前面被套很久的 **千万别这两天割肉**，怎么也得等这波反弹结束或者自己的票冲高再说」（2025-05-26）。

### E7 尾段与结束（73 条）
- **顶部现象（可观察）**：「出现了之前说过的**顶部现象**时，一定要停下操作多看看，比如**金融类猛拉**，是"猛"，然后还有很多**不知所谓的小票开始连板**，最后就是**亲戚朋友开始鼓吹进市场**」（2025-02-21）。
- 🆕 **放量上影线 2 倍 10 日均量**：「**放量上影线，2 倍 10 日均量以上 不出这个就很难见顶**」（2025-05-06）；「银保证券**出长上影，放量，然后大盘缩量**，这就是**顶部结构形成的重要条件**」（2025-05-15）。
- **鱼尾轻仓**：「这种鱼尾一定要**轻仓做**」（2025-05-22）；「**我不在行情末端潜伏补涨**」（2025-08-18）。
- **见好就收**：「我见好就收…**剩下的不再作为自己的操作指导**」（2026-06-29）；「我已经**减半了 等加速结束然后清仓**」（2025-09-09）。

## 4 这一轮**新增/补强**的判据（此前 playbook 未收或有遗漏）

| # | 新判据 | 原话日期 | 对我们的意义 |
|---|---|---|---|
| N1 | **个股止盈点 = 前一波拉升幅度的 0.618 位** | 2025-04-23 | 我们只有 BOLL 上轨/压力位代理 → 多了一个**他有明确口径**的候选（需先可算化再验收） |
| N2 | **避险结束后要补回来**（个股逻辑没变） | 2025-09-24 | G9 只做了"减半"，**没有回补腿** → 缺一半 |
| N3 | **放量上影线 ≥2×10 日均量 = 见顶信号**；银保长上影+放量+大盘缩量=顶部结构 | 2025-05-06 / 05-15 | 我们"顶部阶段"只用指数 120 日分位 → 可用量价补齐 |
| N4 | **破线卖出后"删票"**（移出观察池） | 2025-02-06 / 2025-04-03 | 我们只卖不清池 → 会反复买回同一个坏票 |
| N5 | **一个票最多买 2 笔、卖 2 笔** | 2025-02-07 | 与 WOLF_REFILL_MAX_PER_DAY=2 语义不同（那是单日回补上限）→ 属"腿数上限" |
| N6 | **节假日反 T：早盘卖、尾盘买** | 2025-04-29 | 周末避险的**具体时点**（我们现在是 14:30 一档） |
| N7 | **大涨日多卖、大跌日多买**（日内节奏） | 2025-01-23 | 与"只在下跌里买"同源，但是**卖出侧**的节奏规则 |
| N8 | **出现上影线 → 停止做 T** | 2025-07-17 | 可算化的停机条件 |

## 5 仍需人工判断 / 暂不可算化

- **口径冲突未消解**：同一族规则在不同语料期说法不同（例：长线仓位不避 ↔ 过节降到 10%；不杀跌再止损 ↔ 破线一刀）→ 引用时必须带语境与日期，**不得择一当通则**。
- **"关键位"数字**（3344/3338/3334/3303/3221/144 线…）是**当期点位**，不能直接当参数，只能作为"锚=结构位"的证据。
- **E7 的"顶部现象"**里只有量价部分可算化，情绪部分（小票连板、亲友鼓吹）不可算。

## 6 复现

抽取（容器内，dsh 仅容器网络可达；3 分片并发）：

    docker cp jobs/wolf_exit_evidence.py marcus-backend:/tmp/
    docker exec -d marcus-backend sh -c "cd /app && python /tmp/wolf_exit_evidence.py --shard 0/3 > /tmp/wolf_exit_0.log 2>&1"
    docker exec -d marcus-backend sh -c "cd /app && python /tmp/wolf_exit_evidence.py --shard 1/3 > /tmp/wolf_exit_1.log 2>&1"
    docker exec -d marcus-backend sh -c "cd /app && python /tmp/wolf_exit_evidence.py --shard 2/3 > /tmp/wolf_exit_2.log 2>&1"
    docker exec marcus-backend python /tmp/wolf_exit_evidence.py --merge

真实性校验（逐条回原文查子串）：

    docker cp jobs/verify_exit_evidence.py marcus-backend:/tmp/
    docker exec marcus-backend python /tmp/verify_exit_evidence.py --evidence /app/data/wolf_exit_evidence.json --corpus /app/data/corpus

产物：/app/data/wolf_exit_evidence.json（1,105 条 + 每片 raw reply，可逐条复核）、
/app/data/wolf_exit_evidence.json.verify.json（校验结果）。
**这两个文件不进 git**（data/*.json 被 ignore）→ 需要时按上面命令重跑（脚本已入库）。
