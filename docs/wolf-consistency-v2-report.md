## 5. 失手分析（23 条 ✗）

**A. 主线代理限制（~6 条，模块固有）**：负例但资金强（机器人 5/15、半导体B反 8/5、电池 1/15、AI应用 12/11）、
正例但资金弱（半导体产业级定性 2/25、科技调仓 5/15）——当日资金/动量代理 ≠ 狼大产业级主线定性（已知，需研报历史重放）。

**B. 标注语义/粒度问题（~7 条，模块判得不一定错）**：
- 个股 vs 板块：机器人 1/16「落后我4大机器人50%」指持仓个股，模块看板块（人形机器人 3-3 主升 HIGH，合理）；半导体 5/21「跳的都是相对低位票」指板块内低位股。
- 「低位起来」定义：CPO 3/16、液冷 4/10 狼大指相对前期低点的涨幅落后，模块按 30 日箱体/1 年距高判 HIGH。
- 预判 vs 现状：半导体 5/22「先看震荡筑底」是未来预判，模块看当下（刚跌 2 天仍在高位区）。

**C. 模块真实缺口（~4 条，可改进）**：
1. **t_only 缺「趋势破位→减仓」**（AI硬 2025-11-23：跌破趋势线反抽减仓，模块 MID 观望）——模块没有趋势线/破位规则。
2. **dip_buy_strong 在非 build 宏观不触发**（AI硬 2026-03-03：狼大调整期埋伏长期趋势上游，模块 macro=t_only 压制）——「长期趋势低位埋伏」不应被宏观一刀切。
3. **结构高位 vs 回踩低吸边界**（软件 2026-03-03：AI软连跌十几天狼大说错杀可埋伏，模块判结构高位→减仓）——回踩低吸与结构高位冲突时的优先级需校准。
4. **macro 严格覆盖板块级买入**（PCB 2026-05-22：狼大说机构加强 PCB，模块宏观压制判减仓）——「小级别服从大级别」的边界：板块有独立资金逻辑时是否允许例外。

**D. 规则阈值（1 条）**：机器人 3/17 dip_buy_oversold fund_in 33%<40% 阈值 miss。

## 6. 结论与建议

1. **v2 的 75% 是当前真实一致性**（v1 100% 有过拟合，不可作为对外指标）。
2. **v2 缺口修复完成（2026-09-01，75%→79%）**：
   - ①趋势破位→减仓（MID + vm60<-5% + 资金未流入 → 减仓/只做T；AI硬 11/23 ✓，生产 MID 仅 10/312 触发）；
   - ②长期趋势回踩低吸（MID + vm60>0 + r20∈[-10,0) + 非防御 + 非结构高位 → 回踩低吸；AI硬 3/3 ✓，生产新增 9 个全部 rel=low 白马/消费板块，合理）；
   - ③深跌结构高位不追杀（新高回落 + r20<-8% + 资金流出 → 观望；软件 3/3 ✓，8月半导体资金流入仍减仓不受影响）；
   - ④PCB 5/22 判定为标注粒度问题（概念新高 vs 板块内个股修复），模块 HIGH 减仓与狼大"情绪修复强于逻辑"的谨慎一致，不修。
   - v1 回归 100% 保持，生产分布合理（回踩低吸 9 / 相对低位启动 16 / 减仓 154）。
3. 主线 60% 受代理限制为主，唯一出路是 research_report 历史重放（已确认接口有历史数据，待改造 main_line_judge）。
4. 标注集仍需第 3 轮校准：个股/板块粒度拆分、"低位起来"统一口径。
5. 双标注一致率 45% 说明标注任务主观性强——建议下次标注给每个候选标注"确信度"，低确信的剔除。
