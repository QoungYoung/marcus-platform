# T出执行改进方案（位置门 vs 放量撤销）— 离线验证 2026-09-07

## 结论先行
3357 个 m5.t_sell 触发点(43 标的, stock_5m_bt 2025-11~2026-07 + recent_sync 至 09-03)：

| 策略 | 卖飞(触发后当日剩余最高−卖价) 均值 | 说明 |
|---|---|---|
| A 现状·立即按现价卖 | 2.38 | 基准 |
| B 位置门(≥0.99×段高立即, 否则挂段高×0.998, 尾盘兜底) | 2.39 | **无改进(-0.02)** |
| C **放量撤销**(触发后出现 vol>1.3×前8均量 且 close>段高 → 撤销不卖) | 未撤销组 1.44 | **40% 触发被撤销**, 撤销样本后续平均再创新高 +3.28 → 撤销正确 |

## 关键发现
1. **纯位置门无效**：多数 t_sell 触发时价格已在段高附近(≥0.99×hi 直接卖=同 A)；真正"回落较多才触发"的少数，挂单 hi×0.998 常常当日触不到 → 尾盘兜底卖更低。
2. **放量撤销才是主菜**：40% 的 t_sell 触发点后续出现"放量+创段高新高"——正是 588170 09-07 午后 0.941 那种"主升还没完"场景；此刻立即卖=平均卖飞 3.28。撤销后继续持有等新高后的新停量确认，才符合狼大 7-29 形态（**放量二次过前高=还没到顶，不该卖**；停量+不过前高才卖）。

## 落地设计（改为撤销式, 位置门退为细节）
- m5.t_sell 信号成立 → 进入 **pending T出**(可立即按现价执行, 与现状一致)；
- 但在**未成交前**持续监视：若随后出现 放量(vol > 1.3×前8均量) 且 close > 段高点 hi → **撤销本次 T出**(解除 pending, 标记"放量过前高, 主升未完, 继续持有");
- 撤销后：等新高出现后再按 7-29 停量二次不过前高形成**新的** t_sell 才卖(同一形态重复)。
- ~~尾盘 14:45 兜底~~ **已删(2026-09-07)**：day_end(未确认→必卖) 经分析降级(确认制T出 82%/+4.30% vs day_end 55%/+0.84%, 未确认必卖那批几乎全亏, 系统已降级为'卖出只靠确认制/defensive')。
  撤销式下被撤销的 T仓 = **继续持有**, 等新高后的新停量确认再卖, 允许跨日; 无 14:45 强制卖出。
- 位置门(≥0.99×hi 才执行)可选：无统计增益，默认不加。

## 风险/边界
- 撤销会**延后/错过**部分当日 T出(40% 撤销中, 若当日尾盘回落则未兑现) → 用"撤销样本后续新高 +3.28"证明平均正确, 但仍需尾盘兜底纪律兜住；
- 样本为 5min 档案(非逐秒), 撤销判定用 m5 bar 粒度；m1 粒度可能更优(待验证)。
- 上线前先 DRY: data/t_sell_pending_log.jsonl 记录 撤销/成交 对照 A。
