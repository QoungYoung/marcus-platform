## Context

现有黄金坑 DCA 监测 18 个指数（核心/卫星/防御/半导体增强）+ tech7/prod10 板块选筹，信号是"单个指数深度超跌"这类稀缺事件，坑间空窗期资金长期闲置。arkvol `funds-greed/sectors` 已提供 30+ 行业贪婪数据（2025-01 起），且每个行业都有代表基金可作收益代理，具备扩展为"全行业监测 DCA"的数据条件。本设计把 DCA 触发从指数级扩展为"指数 + 全行业双轨"，并引入资金池优先级裁决解决并发坑位挤占资金的问题。

## Goals / Non-Goals

**Goals:**
- 全行业（A 股行业池，首版 ~15-20 个有数据可回测的行业）独立监测贪婪分位 + 超跌，触发即开独立 DCA 窗口。
- 资金池裁决：每日计划金额超可用现金时，按（tier 优先级 → priority → 权重）比例裁剪，保证高优先级坑优先吃到资金。
- 坑间资金持续轮动：行业出场 → 防御承接（现有 `DEFENSE_TAKEOVER_WEIGHTS`），新坑 → 从防御赎回回补（扩展 `_sell_defense_on_reentry`）。
- 现金下限（默认 20%）防摊大饼，保留抄底弹药。
- 全部参数（行业池、priority、max_total、现金下限、开关）集中到 `golden_pit_etf_config` / `golden_pit_sector_config`，页面弹窗可改。

**Non-Goals:**
- 不逐行业寻参（行业贪婪历史仅 2025-01 起，样本过短，统一参数 + 仅行业级 priority/max_total 差异）。
- 首版不含港股/美股/债券行业，不做行业轮动"趋势腿"（只做贪婪超跌 DCA 腿）。
- 不改现有指数级黄金坑逻辑（双轨并行，开关控制）。

## Decisions

### D1: 行业信号 = 贪婪分位 + 价格超跌双条件（AND）
- 触发：`250日贪婪分位 <= pit_pct(默认0.15)` 且 `价格距N日(默认60)高点回撤 >= 20%`。
- 入场过滤：贪婪分位 <= `entry_cap(默认0.85)`，防过热追新仓；贪婪历史 <20 天时只按价格超跌触发（2025-01 数据刚上线时）。
- 理由：行业贪婪历史短，单一分位信号在早期不可靠；价格超跌是黄金坑定义本身，两者 AND 可过滤浅坑假信号。
- 替代方案：仅贪婪分位（数据不足时无信号，2025-01~2025-03 会空窗）→ 否决；仅价格超跌（与现指数逻辑重复，丢贪婪信息）→ 否决。

### D2: 资金池裁决 = 优先级比例裁剪，而非"全有全无"
- 每日先算所有 in-pit 行业当日计划金额 `plan_i = max_total_i × dca_weight_i × trend_factor_i`。
- 可用资金 = 账户净值 × (1 - 现金下限)；若 `Σplan > 可用`，按 `score_i = (tier_rank, priority_i, 1/max_total_i)` 从高到低逐个分配，直到现金耗尽；未分到的当日跳过、额度保留。
- 理由：DCA 是摊投不是梭哈，比例分配避免"高优先级全买、低优先级完全饿死"的突变；裁剪粒度=日，次日重新计算，坑位自然让位。
- 替代方案：严格优先级队列（并发时低优先级整窗口让位）→ 现金利用率低，否决。

### D3: 行业收益代理 = 场内 ETF 优先（tushare `fund_daily`），无 ETF 用场外 `fund_nav`
- 贪婪数据来自 `funds-greed/fund/{code}`（场外代表基金），但收益回测与实盘买入需要场内 ETF 或场外净值。
- 规则：行业池配置 `proxy_type=etf|nav`；`etf` 用 `fund_daily` 收盘价，`nav` 用 `fund_nav` 单位净值。两者在 DCA 金额换算上等价（金额买入，按价格/净值折算份额）。
- 理由：部分行业（创新药/白酒等）无主流场内 ETF，场外净值是唯一代理；统一用金额建仓避免份额口径差异。

### D4: 坑间资金流转 = 复用现有防御承接/回补
- 出场：行业 DCA 结束出场（P 分位止盈/兜底）→ 资金按 `DEFENSE_TAKEOVER_WEIGHTS` 等权轮入防御（红利/银行/黄金/国债/有色）。
- 新坑：行业触发 DCA 且现金不足 → 按防御持仓比例赎回回补（复用 `_sell_defense_on_reentry`，扩展为按目标金额卖）。
- 理由：防御组合是"坑间不停工"的现有机制，复用避免新造一套轮动逻辑；防御标的本身有独立行情，坑间仍有收益。

### D5: 配置集中管理与兼容
- `golden_pit_etf_config` 新增行业行：`fund_code=industry_<id>`（如 `industry_innovative_drug`），`etf_code`/`nav_code`=代理，`max_total_amount`/`priority`/`min_days_in_pit` 复用现有字段。
- `golden_pit_sector_config` 新增键：`industry_pool_enabled`(bool)、`industry_pool`(json 行业清单+priority+代理)、`cash_min_pct`(number 默认0.2)、`industry_pit_pct`/`industry_drawdown_pct`/`industry_entry_cap`。
- DCA 日志 `strategy` 前缀 `industry/...`，与现有 `exit/`、`defense_rotation/` 并存，解析器向后兼容。

## Backtest Validation (2025-01-02 ~ 2026-08-12, 390 交易日)

### 口径与数据
- 24 行业池（半导体/人工智能/5G通信/大数据/通信设备/科创芯片/创业板50/计算机/软件/消费电子/新能源车/医药/军工/白酒/光伏/化工/有色/银行/煤炭/电力/创新药/房地产/传媒游戏/券商）；贪婪历史 2025-01 起（~390 天，arkvol `funds-greed/fund/{code}`），收益代理用场内 ETF（tushare `fund_daily`，2024-01 起）。已知缺口：计算机/软件贪婪数据截止 2026-07-09（之后仅价格触发）。
- 信号：250 日贪婪分位 <= 0.15 AND 60 日回撤 >= 20%（贪婪历史 <20 天仅价格触发）。
- DCA：连续 in-pit >= 2 天开窗，15 天窗口前 5 日等权（20%/日）；单行业 max_total = 起始资金 12%，未分配额度滚动次日。
- 资金池：现金下限 20%；现金不足按优先级（半导体>科创芯片>创新药>...）从防御组合（红利/黄金/国债等权）赎回回补；出场资金轮入防御。
- 出场：窗口完成后 +15% 止盈 / 窗口结束+60 交易日时间止损 / 满仓后跌破成本 -10% 止损。

### 结果（基准参数）
- 组合：总收益 **+36.14%**（年化 +21.29%），最大回撤 **-9.3%**，资金利用率 80.7%，活跃窗口天数 263/390（67%），完成坑 24 次，胜率 54%。
- 分年：2025 **+19.86%**（MDD -7.1%）；2026（至 08-12）**+13.58%**（MDD -9.3%）。
- 对照（同期躺平）：科创50 **+81.67%**（MDD -30.2%）；沪深300 **+21.46%**（MDD -10.1%）；24 行业等权 **+7.03%**（MDD -35.2%）；防御组合 **+1.90%**（MDD -2.4%）。
- 结论：组合显著跑赢沪深300/行业等权/防御，回撤与沪深300 相当、远小于科创50/等权；但本样本（科创 50 大牛 +81.7%）中跑输科创50 躺平——全行业 DCA 是"低回撤 + 坑间不停工"的稳收益腿，不是牛市收益最大化腿。

### 敏感性（单因子，其余保持基准）
| 参数 | 收紧档 | 基准 | 放宽档 | 观察 |
|---|---|---|---|---|
| 回撤阈值 | 15% → +53.2%（37 坑） | 20% → +36.1% | 25% → +22.6%（14 坑，MDD -14.5%） | 浅坑参与反而增厚收益 |
| 止盈 | 10% → +43.8%（胜率 67%） | 15% → +36.1% | 20% → +44.7%（胜率 38%） | 快进快出优于长持 |
| 止损 | 5% → +56.2%（31 坑） | 10% → +36.1% | 15% → +32.6% | 止损收紧显著改善 |
| 贪婪分位 | 0.10 → +38.3% | 0.15 → +36.1% | 0.20 → +50.7%（27 坑） | 放宽分位多抓坑 |
| 单行业上限 | 8% → +23.7% | 12% → +36.1% | 15% → +46.6% | 上限越高收益越高（风险同升） |
| 现金下限 | 10% → +25.4% | 20% → +36.1% | 30% → +38.9% | 样本内高现金下限反而更好（防御期间少踏空） |

- 激进组合（回撤 15% + 止盈 10% + 止损 5%）：总收益 **+55.84%**（年化 +31.99%），MDD -9.8%，44 坑，胜率 64%；2025 +26.99%，2026 +22.71%。
- 过拟合警示：样本仅 19.5 个月且含一段科创大牛，敏感性选出的"最优参数"未必外推有效；生产先按基准参数 dry-run，观察 1-2 个坑再决定是否调参。

## Risks / Trade-offs

- [样本过短] 行业贪婪仅 2025-01 起（~19 个月），回测窗口小 → 统一参数、不逐行业寻参；结论标注区间与过拟合风险；上线先 dry-run 观察。
- [场外净值口径] `fund_nav` 为日频单位净值，与场内价格存在申赎折价/延迟 → 优先场内 ETF；NAV 代理的行业在报告中标注，实盘金额上限保守。
- [假信号增多] 全行业监控会引入浅坑 → 双条件 AND + `min_days_in_pit` + 飞刀保护/假信号制动复用；`industry_pool_enabled` 可一键关停回滚。
- [资金池裁决复杂化] 并发裁剪逻辑增加调度复杂度 → 裁决纯函数化（输入计划金额+现金→输出实际金额），单元测试覆盖；失败回退"按当前逻辑各自执行"。
- [与现有指数 DCA 抢占资金] 双轨并发时行业与指数抢同一现金池 → 裁决统一作用于指数+行业全部标的，优先级同表可配（默认指数核心 > 行业核心）。

## Migration Plan

1. 先落地"全行业贪婪监测面板"（只读，不改调度）验证数据与信号质量。
2. 资金池裁决纯函数 + 单测，dry-run 输出"计划 vs 实际"比对一周。
3. 开关 `industry_pool_enabled=true` 灰度，行业 max_total 从低额起步；异常直接关停。
4. 回滚：置 `industry_pool_enabled=false`，恢复原指数级 DCA（双轨中行业轨整体关闭，指数轨不受影响）。

## Open Questions

- 行业池最终取 ~15-20 个还是全部 30+？取决于回测数据可得性（有贪婪 + 有收益代理的行业数量）。
- 行业优先级排序默认值：按历史收益弹性（半导体/创新药高弹性优先）还是按行业权重？（回测对比后定）
- 是否需要"行业级 P 分位出场"（现有 500 天分位）还是统一用 DCA 窗口兜底出场？（回测对比）
