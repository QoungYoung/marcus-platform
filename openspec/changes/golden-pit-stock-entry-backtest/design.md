## Context

黄金坑策略 `GoldenPitService` 在 ArkVol 贪婪指数跌破阈值时发出入坑信号，当前只买入宽基 ETF。系统同时维护了一套完备的个股入场过滤体系 `check_entry_filters`（三层过滤：技术面+主力行为+超买），用于个股建仓决策。本回测将两者结合：黄金坑提供宏观择时，入场过滤提供微观选股。

约束：
- 入场过滤是实时 API 端点，内部耦合了 Xueqiu 行情、实时技术指标、资金流向三个外部调用，无法直接用于离线回测
- 本地有完整的 parquet 历史数据：日线（stock_daily.parquet, 1.2GB）、分钟线（stock_1min/, 每标的单独文件）、资金流向（moneyflow.parquet, 1.1GB）
- 资金流向是日终数据，盘中只有 14:55 时刻接近最终值，因此回测只在 14:55 模拟
- 数据库 `golden_pit_snapshots` 表有 2020-01 至今的每日贪婪值快照

## Goals / Non-Goals

**Goals:**
- 回测黄金坑入坑日买入通过入场过滤的成分股 vs 纯买 ETF 的收益差异
- 离线运行，不依赖 Xueqiu、实时 API
- 可复现、可参数化（不同持有期、不同过滤严格度）

**Non-Goals:**
- 不修改生产系统的入场过滤逻辑
- 不做实时交易信号生成
- 不覆盖海外指数成分股（道琼斯、纳斯达克、恒生、韩国）—— tushare `index_weight` 仅支持 A 股指数

## Decisions

### 1. 入场过滤适配策略：抽取纯函数

将 `check_entry_filters` 的核心三层逻辑抽取为独立函数 `evaluate_entry_filters_offline()`，接受预计算的指标字典作为参数，返回过滤结果。

**替代方案考虑**：直接复制代码修改 → 会导致两套逻辑分叉，后续维护成本高。

**选择理由**：抽取为独立函数后，回测脚本和实时 API 共享同一套过滤规则，规则变更时只需改一处。

### 2. 回测时刻：14:55

使用 14:55 分钟 K 线数据模拟交易，因为资金流向是日终数据，14:55 时已接近最终值。

**替代方案考虑**：用前一日资金流向代理 → 会丢失当日资金态度变化。

### 3. 成分股数据获取：tushare index_weight + 本地缓存

`index_weight` 是月度数据（每月一条记录）。入坑日所在月份的月初/月末数据即为有效成分股列表。首次拉取后缓存到 `data/backtest/指数数据/index_weight/` 目录的 parquet 文件。

**替代方案考虑**：用 `index_member` 接口 → 仅返回成分股代码，无权重信息，不如 `index_weight`。

### 4. 无法适配的指标处理

| 指标 | 原因 | 处理方式 |
|------|------|----------|
| RSR | 雪球专有指标，无法从 OHLCV 推算 | 跳过，不影响核心过滤（RSR 只是降级因素之一，不是硬阻断） |
| 板块资金净流入（当日） | 无盘中板块资金流数据 | 使用昨日板块资金流数据作为代理 |
| 资金效率 | 需要实时成交额和资金流向比例 | 用日线数据近似计算：`net_mf_amount / amount * 100` |

### 5. 脚本结构：单文件脚本，直接运行

回测脚本放在 `scripts/backtest_golden_pit_stocks.py`，使用 `if __name__ == "__main__"` 模式，无命令行参数（或简单的日期范围参数），直接输出结果表格。

**替代方案考虑**：集成到 `backtest_engine.py` → 过度工程化，这个回测的目标是回答一个具体问题，不是构建通用框架。

## Risks / Trade-offs

- [成分股数据不完整] 部分指数（如科创50 000688.SH）的 tushare `index_weight` 历史可能较短 → 回退使用当日 `stock_basic` 中的全市场股票池 + 按市值/行业筛选近似
- [海外指数成分股不可用] 道琼斯、纳斯达克、恒生、韩国 KOSPI 的成分股不在 tushare 覆盖范围 → 回测只覆盖 6 个 A 股宽基指数
- [14:55 时刻资金流向仍有偏差] 最后 5 分钟可能有集中成交 → 偏差在可接受范围（< 5% 日总成交额）

## Open Questions

- 龙头股 vs 全部通过检测的股票：两者都回测，对比结果
- 等权配置 vs 市值加权：两者都回测
- 持有期：15 日、20 日、30 日，对应黄金坑的回测预期收益窗口
